# 按键绑定

Tasty 的按键绑定可通过预设更改，也可为常用操作指定所需的组合键。按键绑定位于 **设置** <!-- en: Settings --> > **按键绑定** <!-- en: Keybindings -->。

## 表示规则

Tasty 按 **按键的物理位置** 保存按键绑定。因此，同一配置在三种操作系统上的按法不同。

| 配置中使用的名称 | Windows · Linux | macOS |
|-------------------|-----------------|-------|
| `ctrl` | Ctrl | Control (⌃) |
| `alt` | Alt | **Command (⌘)** |
| `shift` | Shift | Shift (⇧) |
| `option` | Win (Windows) · Super (Linux) | Option (⌥) |

macOS 的 ⌘ 与 Windows · Linux 的 Alt 位置相同，因此配置值 `alt+t` 在 Windows 上按 `Alt+T`，在 macOS 上按 `Cmd+T`。同样，Windows 的 Win 键和 Linux 的 Super 键与 macOS 的 Option 位置相同，因此录制 `Win+K` · `Super+K` · `⌥+K` 时，都会保存为 `option+k`，在三种操作系统上均通过该位置的按键执行。Windows · Linux 的设置界面将此键显示为 `Win` · `Super`。下表按此规则填写两列。

Windows 保留的组合键，如 `Win+L` · `Win+D`，以及 GNOME · KDE 使用的 Super 组合键（单独的 Super、许多 Super+字母组合），会先被操作系统截获，无法传给 Tasty。这些组合无法录制，即使写入配置文件也不会生效。

配置文件仅使用 `ctrl` · `alt` · `option` · `shift` 四个名称。不识别 `cmd` · `super` · `win` · `meta` 等按键名称。

**非拉丁键盘也按位置匹配。** 即使使用俄语、希腊语等非拉丁字母布局，也会按键帽上的拉丁字母位置识别按键绑定——在俄语布局中，将 `H` 位置的按键（输入俄语 `Р` 的键）与修饰键一起按下，仍会触发 `Ctrl+Shift+H` 按键绑定。切换布局后无需重新录制按键绑定。在 Markdown 和网页预览界面中也相同。

在 macOS 上，如需将设置界面的表示方式改为 `⌘` `⌥` `⇧` 符号，请更改 **设置** > **常规** <!-- en: General --> > **显示** <!-- en: Display --> 中的 **Cmd 键显示** <!-- en: Cmd key display --> · **Option 键显示** <!-- en: Option key display --> · **Shift 键显示** <!-- en: Shift key display -->。保存的值不变。

**刷新** 向当前查看的 Surface 请求刷新。Markdown 重新读取文件（远程文件则读取远程原文），文件浏览器重新读取文件夹，终端中不执行任何操作。即使与文件浏览器的刷新键相同，也只重新读取一次。在 Windows · Linux 的 Markdown · HTML 界面中，使用 `F2` 等功能键且不带修饰键的快捷键也会生效。若刷新键也被指定为复制、粘贴等编辑键，则在网页及其中的输入框、HTML 地址框中只执行编辑，不刷新。在 HTML 地址框中输入时，即使与转到地址栏的按键重叠，该按键也优先于刷新。只要刷新指定为 `F5`，终端内的程序（mc · htop 等）就不会收到 `F5`。如需在终端程序中使用 `F5`，请在 **设置** > **按键绑定** > **Surface** <!-- en: Surface --> 中清空刷新键或改为其他键。

`Ctrl+C` 在有选中文本时执行复制，否则照常中断正在运行的程序。

在 Markdown · HTML 界面的正文及其中的输入框、HTML 地址栏中，复制、剪切、粘贴、全选键也只对当前焦点所在处生效。在输入框中，全选仅选择该输入框的文本；在正文中则选择整个文档。只读框和正文不会因剪切、粘贴而改变。在 Windows · Linux 的网页界面中，已绑定的 `Ctrl+C`、`Ctrl+X`、`Ctrl+V`、`Ctrl+A` 会作为 Tasty 命令执行。从快捷键设置中删除后，按键将按网页界面的默认方式处理。在 Linux 上，未选择内容时，已绑定的 `Ctrl+C`、`Ctrl+X` 会传递给页面。网页的撤销、重做可与文件浏览器分开更改；在 Mac 上删除这些键后，网页中的 `Cmd+Z` 也不再生效。若同一按键也指定给插件命令，在网页中优先执行编辑。按词移动使用网页界面和输入框的默认按键。在 Linux 上，若页面无响应期间积压了过多编辑请求，该界面的编辑键可能不再生效。此时仍可输入字符，关闭并重新打开该界面后，编辑键会恢复。

**复制链接** 没有默认按键。指定按键后，将鼠标悬停在终端链接上并按下该键，即可直接复制链接文本。此操作不出现在命令面板中。

## 预设

**设置** > **按键绑定** > **预设** <!-- en: Preset --> 中有四种预设。预设只是推荐的组合，不受操作系统限制——在 Windows 上也可使用 Mac 预设。

| 预设 | 依据 | 与 Tasty 预设的区别 |
|--------|------|------------------------|
| **Tasty**（默认） | 自有 | 见上表。复制、粘贴、缩放集合了三种操作系统的惯用组合 |
| **Mac** | iTerm2 · Terminal.app | 以 `Cmd` 为主。设置 `Cmd+,` · 通知 `Cmd+Shift+I` · DAG 列表 `Cmd+Shift+G` · 侧边栏 `Cmd+Shift+B` / `Cmd+B` · 退出 `Cmd+Q` · 后台 `Cmd+M` · 关闭窗格 `Cmd+Shift+W`。包含多个组合的操作只保留 `Cmd` 组合——复制 `Cmd+C` · 粘贴 `Cmd+V` · 剪切 `Cmd+X` · 全选 `Cmd+A` · 搜索 `Cmd+F` · 缩放 `Cmd+=` · `Cmd+-` · `Cmd+0` · 命令面板 `Cmd+Shift+P` · 在代码输入框中应用 `Cmd+Enter`，文件浏览器的回收站 `Cmd+Backspace` · 撤销 `Cmd+Z` · 重做 `Cmd+Shift+Z` · 隐藏文件 `Cmd+Shift+.`。**关闭活动项** 和 **关闭工作区** 为空 |
| **Windows** | Windows Terminal | 拆分窗格 `Alt+Shift+E` / `Alt+Shift+D`，拆分 Surface `Alt+D` / `Alt+E` · 新建窗口 `Ctrl+Shift+N`。包含多个组合的操作只保留 `Ctrl` 组合，移除 `Alt` 组合——复制 `Ctrl+C` · 粘贴 `Ctrl+V` · 剪切 `Ctrl+X` · 全选 `Ctrl+A` · 搜索 `Ctrl+F` · 缩放 `Ctrl+=` · `Ctrl+-` · `Ctrl+0` · 命令面板 `Ctrl+Shift+P` · 在代码输入框中应用 `Ctrl+Enter`，文件浏览器的回收站 `Delete` · 撤销 `Ctrl+Z` · 重做 `Ctrl+Shift+Z` · `Ctrl+Y` · 隐藏文件 `Ctrl+Shift+.` |
| **Linux** | GNOME Terminal | 与 Windows 预设相同，但复制／粘贴／剪切为 `Ctrl+Shift+C` / `Ctrl+Shift+V` / `Ctrl+Shift+X` · 退出为 `Ctrl+Q` |

应用步骤：

1. 在 **设置** > **按键绑定** > **预设** 列表中点击预设行。当前使用的预设带有 **使用中** <!-- en: Active --> 标记。
2. 在详情界面的 **操作** <!-- en: Action --> / **当前** <!-- en: Current --> / 预设三列表格中查看发生变化的行。
3. 点击右上角的 **应用** <!-- en: Apply -->。此时尚未保存到文件。
4. 点击窗口底部的 **保存** <!-- en: Save -->。

应用预设后，所有手动修改的按键绑定都会恢复为预设值。

## 迁移到其他计算机——导入／导出

通过 **设置** > **按键绑定** 左侧列表最底部（分隔线下方）的 **导入 / 导出** <!-- en: Import / Export -->，可将整套按键绑定配置迁移为单个文件。包含通用按键绑定、编号切换规则、脚本按键绑定和插件按键绑定。

导出：

1. 点击 **导出…** <!-- en: Export… -->。
2. 选择保存文件夹，在下方的 **文件名** <!-- en: File name --> 框中指定名称，然后点击 **保存**。默认名称为 `tasty-keybindings-<日期>.toml`。点击列表中的现有文件会将其名称填入输入框；若名称已存在，会显示警告，按钮变为 **覆盖** <!-- en: Overwrite -->。
3. 保存后，通知中会显示文件路径。尚未保存的编辑也会包含在内。

导出期间，**导出…** 按钮保持名称和宽度不变并禁用，按钮旁显示进度指示和 **正在导出…** 文本。无法再次启动同一导出，但可继续编辑其他设置。若关闭设置窗口或更改要导出的按键绑定配置，则不会显示先前任务的成功或失败提示。已受理的文件写入会继续进行。

若无法保存（如文件夹只读），**导出** 行内会显示 **导出内容未写入** <!-- en: The export wasn't written -->。通过 **重试** <!-- en: Try again --> 写入同一位置，或通过 **选择其他位置…** <!-- en: Choose another location… --> 选择其他位置。此提示显示期间，无法点击 **导出…** 按钮。提示中间的句子会分别说明文件夹只读、没有写入权限、磁盘已满这三种情况。若均不属于，则显示“写入未完成”，并在下方以灰色小字附上操作系统返回的原文（过长时截断，悬停可查看全文）。

若无法确认结果，会显示 **导出结果未知** 提示。检查目标文件后再手动重试。不会自动重新写入。**重试** 会导出当前正在编辑的配置。文件通过同一文件夹中的临时文件替换，并保留受支持的现有访问权限，但不保证保留所有文件属性或抵御断电。

导入：

1. 点击 **导入…** <!-- en: Import… --> 并打开迁移过来的文件。不会立即应用，而是显示比较界面。
2. 当前值和待导入值按 **通用按键绑定** <!-- en: General bindings --> · **快速切换（按组）** <!-- en: Quick switch (by group) --> · **脚本按键绑定** <!-- en: Script bindings --> · **插件覆盖设置** <!-- en: Plugin overrides --> 四组并排显示。最初仅显示发生变化的行，可通过右上角的 **显示全部 N 项** <!-- en: Show all N --> 查看全部。
3. 取消勾选不想导入的行。组标题的复选框可启用或禁用整组。
4. 点击右上角的 **应用** <!-- en: Apply -->。此时尚未保存到文件。
5. 点击窗口底部的 **保存**。若点击 **取消**，导入内容也会全部丢弃。

注意事项：

- 快速切换按标签页、工作区、分类分别导入。各组的修饰键和编号键会一起应用。
- 仅在此计算机上存在的插件按键绑定，不会因文件中缺少而被删除。反之，此计算机上未安装的插件的按键绑定不会导入，比较界面中会用一行说明。
- 若读取文件时跳过了部分内容（由更新版本的 tasty 写入的文件、此版本不识别的操作等），会在比较界面上方的 **读取完成，有警告** <!-- en: Read with warnings --> 框中逐行汇总显示。四行及以上时仅显示三行，其余通过 **再显示 N 项** <!-- en: Show N more --> 展开。
- 若导入的按键绑定包含可能先被操作系统使用的组合，如 Windows 的 `Win+L` · `Win+D` · `Win+E` · `Win+R` · `Win+I` · `Win+Tab`，同一框中会附加类似“Windows 可能先使用 Win+L，因此可能无法传给 Tasty。”的提示。这只是警告，仍会正常导入。Linux 上适用于仅按 `Super` 的按键绑定。
- 若选择的不是按键绑定文件，会显示 **无法将此文件读取为按键绑定** <!-- en: This file can't be read as keybindings -->，而不显示比较界面，也不会更改任何内容。通过 **选择其他文件** <!-- en: Choose another file --> 重新选择。

### 导入在其他操作系统上创建的文件时

按键绑定文件可在任意操作系统上原样导入。在 Mac 上用 `Option` 创建的按键绑定，在 Windows 上按 `Win`、在 Linux 上按 `Super` 即可执行，反之亦然。**文件浏览器拖动切换修饰键** <!-- en: Explorer drag flip modifier -->（位于 **设置** > **按键绑定** > **常规** 最底部）的默认值在 Mac 上为 `Option`，在 Windows · Linux 上为 `Ctrl`，因此导入 Mac 导出的文件后，在 Windows · Linux 上需按住 `Win` · `Super` 拖动，才能切换移动与复制。

## 修改单个按键绑定

1. 打开 **设置**（`Ctrl+,`）> **按键绑定**。左侧子标签页按操作对象划分——**常规** · **工作区** · **窗格** <!-- en: Pane --> · **标签页** · **Surface** · **剪贴板** · **缩放** · **文件浏览器** · **运行脚本** <!-- en: Run Scripts --> · **预设** · **插件** · **导入 / 导出**。
2. 点击要修改的操作的按键按钮，按钮会变为 **按下组合键…** <!-- en: Press key combination... -->。按下所需组合键。
3. 如需为同一操作再添加一个组合键，点击 **添加绑定** <!-- en: Add binding -->。
4. 录制期间按 `Esc` 会清空该槽位。
5. 若组合键已被其他操作使用，会显示 **快捷键已被占用** <!-- en: Shortcut already in use --> 弹窗。选择 **覆盖** <!-- en: Overwrite --> 后，会从原操作中删除该组合键，并移至此操作。
6. 点击 **保存**。若点击 **取消** <!-- en: Cancel -->，则全部丢弃。

录制规则：

- 字母、数字、空格等输入键必须与至少一个修饰键（Ctrl/Alt/Shift）一起按下才能注册。单独按 `W` 会被忽略。
- `F1`~`F24` · `Tab` · `Enter` 等按键无需修饰键也可注册。
- 快速按两次修饰键的双击（如按两次 `Shift`），仅可为工作区、标签页、Surface 的打开、关闭、拆分、移动，以及打开设置、通知、退出等操作录制。在无法通过双击执行的槽位（命令面板、脚本、插件命令、编号切换等）中，值不会改变，并显示提示。配置文件中已写入但无法执行的双击不会被删除，而会在界面底部显示警告。macOS 的 `alt+alt` 表示按两次 ⌘，按两次 ⌥ 不用作双击。
- `Esc` 保留用于“清空槽位”，无法录制为按键绑定。如需恢复默认值为 `Esc` 的 **退出全屏舞台** · **在代码输入框中取消**，请重新应用预设。
- 插件按键绑定（**插件** 子标签页）与本体按键绑定重叠时，**插件优先** 执行。

## 修改插件按键绑定

在 **插件** 子标签页中，通过顶部的 **插件：** <!-- en: Plugin: --> 下拉框选择插件后，会逐行显示该插件的命令。

- 在方式下拉框中选择 **继承** <!-- en: Inherit -->，会沿用某个 Tasty 操作（如 `clipboard.paste`）的按键。行下方显示当前沿用的按键。
- **自定义** <!-- en: Custom --> 以与其他子标签页相同的方式录制按键。点击按键按钮并按下组合键，可通过 `+` 添加按键。录制期间按 `Esc` 会删除该按键；删除所有按键后，该命令将没有快捷键。录制期间切换插件、方式或点击 **重置**，会取消录制。按键较多或窗口较窄时，按键按钮和 **重置** 会换到下一行，所有按键仍可见。
- 若直接编辑配置文件，写入了无法匹配任何输入的按键（如 `ctrl+shft+h`），该按键按钮会原样显示文本并带有错误边框，行下方显示 **无法识别的按键：** <!-- en: Unrecognized key: -->。该按键无法执行命令。
- 若写入 `cmd+k`·`super+k`·`win+k`·`meta+k` 等操作系统按键名称，则会改为显示“Win·Super·Option 请写为 `option`，Cmd 请写为 `alt`。”的提示。配置文件仅接受按键位置名称，以确保在各操作系统上含义相同。
- 若配置文件中的按键是可能先被操作系统使用的组合，如 Windows 的 `Win+L`，行下方会显示“Windows 可能先使用 Win+L，因此可能无法传给 Tasty。”警告。仍可正常保存。
- **无** <!-- en: None --> 表示不设置按键绑定。
- 有未保存更改的命令会在名称后显示一个点。**重置** <!-- en: Reset --> 会清除单独设置并恢复插件默认值；没有单独设置时无法点击。
- 更改仅在通过底部的 **保存** 关闭时应用；取消或关闭窗口会丢弃更改。

## 修改编号切换规则

标签页、工作区、分类的“转到第 n 个”和“下一个／上一个”按 **一个修饰键 + 一个按键** 的规则分组。在 **标签页** 子标签页底部和 **工作区** 子标签页底部更改。

- **标签页切换修饰键** <!-- en: Tab switch modifier --> · **工作区切换修饰键** · **分类切换修饰键** 下拉框——默认分别为 `Ctrl` · `Alt` · `Ctrl+Shift`。更改后，该组的所有编号键（标签页 10 个、工作区 9 个、分类 10 个）会一起更改。
- **第 1 个标签页：** ~ **第 10 个标签页：** 等槽位按钮——不带修饰键，只按一个键（**按下一个按键（不带修饰键）…** <!-- en: Press a key (no modifier)... -->）。例如，将第 1 个槽位改为 `Q` 后，`Ctrl+Q` 会转到第 1 个标签页，按住修饰键时标签页上显示的编号也会变为 `Q`。
- **下一个标签页：** · **上一个标签页：** 等——同样只按一个键。默认使用 vi 风格的 `L`/`H`（标签页）、`J`/`K`（工作区、分类）。
- 在下拉框中选择 **自定义** <!-- en: Custom --> 后，不再使用公共修饰键，而是为每个槽位录制不同的组合键（如 `Ctrl+Alt+1`）。此时不显示编号。重新切回规则方式后，该组会重置为默认值。

<a id="弹窗获得焦点时按键绑定不生效"></a>

## 在弹窗中输入时的按键绑定

搜索栏、文件选择、命令面板等接收输入的弹窗 **拥有焦点期间，按键绑定
不生效。** 这是为了防止输入搜索词时，`Alt+W` 等按键关闭 Surface。若弹窗只是打开但没有焦点，按键绑定仍照常生效。

如需返回终端操作，可使用以下任一方式。

- **`Esc`**——释放当前获得焦点的弹窗。若属于点击外部会关闭的弹窗，也会一并关闭，
  否则保持打开，仅释放焦点。其他已打开但没有焦点的弹窗
  保持不变。
- **点击弹窗外部**——结果与 `Esc` 相同。

设置窗口或通知面板打开时，`Esc` 会先关闭它们。

## 无需记忆按键绑定的两种方式

- **修饰键提示**——按住 `Ctrl` · `Alt` · `Shift` 等至少 0.5 秒（单独按 Shift 时为 1.2 秒），侧边栏下方会显示以该组合开头的按键绑定列表。松开后消失。在 Windows · Linux 上，`Win` · `Super` 仅在至少有一个按键绑定使用该键时显示列表。可通过 **设置** > **常规** > **辅助功能** <!-- en: Accessibility --> > **显示修饰键提示** <!-- en: Show modifier key hints --> 关闭，面板可拖动或调整大小。
- **命令面板**——按 `Ctrl+Shift+P`，或点击状态栏右侧的命令面板快捷键键帽。输入操作名称，按 `Enter` 执行。可搜索按键绑定标签页中的操作和已启用插件的全局命令。但不包含命令面板自身、**退出全屏舞台**、以鼠标下的链接为目标的 **复制链接**、代码输入框按键，以及文件浏览器的项目间移动、扩展选择、打开、取消选择按键（包含文件浏览器的重命名、移到回收站）。脚本按键绑定也不出现在命令面板中。搜索词输入框即使没有焦点，也会通过背景和边框区分，输入时显示焦点边框。

## 直接编辑配置文件

按键绑定保存在 `~/.tasty/config.toml` 的 `[keybindings]` 节中。值使用与操作系统无关的名称，因此将文件迁移到其他操作系统后也可原样使用。

```toml
[keybindings]
new_tab = ["alt+t"]
copy = ["ctrl+c", "alt+c", "ctrl+shift+c"]
quit = []                      # 留空表示无按键绑定
tab_switch_modifier = "ctrl"   # 也可使用 "ctrl+shift" 等组合
tab_switch_slot_keys = ["1", "2", "3", "4", "5", "6", "7", "8", "9", "0"]
tab_switch_next_key = "l"
tab_switch_prev_key = "h"
```

`+` 键本身写为 `ctrl++` 或 `ctrl+plus`，`-` 写为 `ctrl+-` 或 `ctrl+minus`，`=` 写为 `ctrl+=` 或 `ctrl+equals`。文件编辑的通用说明见 [设置](settings.md)。
