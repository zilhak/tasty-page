# 创建和复用工作布局

Tasty 可将实现、测试和文档分别放在不同窗格中，并将布局保存为预设，供后续任务复用。各窗格的标签页独立切换，因此可以在查看文档时，让其他窗格的测试日志保持可见。

<!-- tasty-diagram: workflow-layout -->
```
左侧窗格：实现终端 | 右侧窗格：测试终端
各窗格的标签页独立切换。
```

## 1. 划分工作空间

1. 打开项目的工作区，在终端中切换到项目目录。
2. 按 `Alt+E` 将窗格左右拆分。这是 Tasty 的默认快捷键。如果已修改，请查看[按键绑定设置](../customize/keybindings.md)。
3. 在一侧编写实现，在另一侧运行项目的测试命令。

各窗格的标签页可以独立切换，便于保留测试日志，同时在另一侧查看文档。如果想将多个画面放在同一标签页中一起切换，请使用 [Surface 拆分](panes-tabs-splits.md)。

## 2. 将文档放在旁边

右键点击用于查看文档的窗格中标签栏的空白处，选择 **新建 Markdown…**，打开项目的 README。返回终端时，点击同一窗格的终端标签页即可。其他窗格的测试画面保持不变。

也可以使用[文件管理与查看](files.md)中介绍的查看器查看图片或 HTML 结果文件。工作布局用于将运行与结果查看放在相邻位置，并不替代文件编辑器或浏览器的全部功能。

## 3. 将当前布局保存为预设

1. 右键点击侧边栏中的工作区。
2. 选择 **保存为工作区预设**。
3. 在 **工具 > 预设** 中查看已保存的工作区预设。
4. 在 **编辑** 中查看各区域的种类、工作目录和启动命令。结构更改会自动保存，区域设置需要点击 **确定** 才会保存（[编辑](panes-tabs-splits.md#编辑)）。

启动命令会在新终端打开时运行。不需要自动运行的区域，将启动命令留空。如果要在其他项目中使用此布局，先调整路径和命令。

区域设置中目录、文件字段旁的 **浏览…** 会打开预设内的 Tasty 选择器。选择文件夹时，确认选中的子文件夹或当前文件夹；选择文件时，确认从列表中选中的文件。结果仅填入该字段，点击 **确定** 后才会保存。在选择器中按 Esc 只会关闭选择器，正在编辑的设置会保留。

## 4. 在新任务中复用

右键点击 **新建工作区** 按钮，选择 **从预设创建工作区...**。选好已保存的预设后，检查各终端是否在预期目录中启动。

预设会复用布局和启动设置，不会复制正在运行的进程。重新打开应用时的[布局与记录恢复](workspaces.md)是独立功能。

<a id="在所有操作系统上使用相同环境"></a>

## 在其他操作系统上使用布局时

在 Windows、macOS、Linux 上，通过工作区、窗格和标签页构建布局的方式相同。文件路径、Shell 命令和已安装的工具需根据各环境设置。

## 与智能体配合使用

在一侧连接 [Claude Code 或 Codex CLI](../agents/claude-codex.md)，在另一侧继续自己的工作。即使智能体创建后台标签页，当前画面的焦点、选区和滚动位置也不会改变。

如果想稍后查看完全不使用标签页运行的任务，请参阅[将后台任务带入标签页](../agents/background-tasks.md)。
