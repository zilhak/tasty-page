# 공통 요소와 개인정보

## 사이트 공통 구성

- 사이트 소스: [공통 레이아웃](../../src/layouts/Base.astro) · [가이드 레이아웃](../../src/layouts/Guide.astro) · [갤러리 레이아웃](../../src/layouts/GalleryPage.astro) · [공통 문자열](../../src/lib/strings.ts) · [메타 정보](../../src/lib/meta.json) · [검색](../../src/lib/search.ts) · [가이드 데이터](../../src/lib/guide.ts)
- 역할: 방문 위치와 무관하게 필요한 안내로 이동하고 언어·번역·검색 범위를 이해하게 하는 공통 길찾기.
- 보여 줄 항목: 가이드·설치·다운로드·디자인·변경 이력으로 가는 헤더, 현재 위치, 본문 건너뛰기, 테마·언어 선택, 문서 목차·이전·다음·원문 링크, 푸터의 가이드·프로젝트 링크.
- 언어: 사이트의 언어별 경로, 한국어 가이드 정본, 영어 번역 없음과 오래된 번역의 구별, 원문 진입을 보여 준다. 디자인 구역은 첫 페이지의 제목·소개·안내만 선택한 언어로 번역하고 언어가 늘면 함께 번역한다. 토큰·갤러리·왼쪽 메뉴·이전·다음·표본은 영어로 고정하고 경로는 언어별로 둔다. 헤더·푸터·검색·언어 전환은 선택한 언어로 보여 주며, 언어 전환은 같은 디자인 페이지의 다른 언어 경로로 이동한다. 앱 내장 언어와 사이트 언어를 구별한다.
- 검색: 가이드 대상 검색, 기존 입력과 결과 상태, 언어별 제목·분류·본문 앞부분을 이용하는 검색 범위를 보여 준다. 관련 기능·명령을 각 가이드 도입에서 찾을 수 있게 구성한다.
- 검색·공유 소개: 랜딩의 제품 범위, 가이드별 도입 첫 문장, 디자인 첫 페이지의 언어별 소개, 토큰·갤러리의 영어 소개를 해당 페이지의 메타 설명으로 연결한다. 제목·본문·공유 소개의 역할을 맞춘다. 링크 미리보기에는 페이지 언어에 맞는 공유 이미지를 연결한다.
- 버전과 링크: 공개 릴리스 정보에 따른 버전 표시, 설치 파일·변경 이력·릴리스·이슈의 기존 목적지, 소스 열람 링크를 둔다.
- 넣지 않을 항목: 검색 보조 설명 슬롯, 자동완성·오타 교정·새 필터, 사이트 전체 전문 검색 약속, 검색 서비스 노출 보장, 번역 완료일 추측, 미제공 지원 채널·요금·뉴스레터.

## 개인정보 페이지

- 사이트 소스: [영어 진입점](../../src/pages/privacy/index.astro) · [한국어 진입점](../../src/pages/ko/privacy/index.astro) · [본문](../../src/components/Privacy.astro) · [통계 구성](../../src/components/Analytics.astro)
- 역할: 방문자가 웹사이트 통계 처리의 범위와 주체, 정책·문의 경로를 찾는 페이지.
- 보여 줄 항목: 방문 통계의 목적·수집 항목·식별 방식·처리 주체·조회 기간, 사이트 선호 저장과 통계 수집의 구별, 앱과 외부 도구에 대한 적용 경계, 현재 정책 링크·수정일·문의 경로.
- 넣지 않을 항목: 앱·플러그인·외부 에이전트 전체의 데이터 무전송 보장, 새 동의 UI, 법률 적합성 보장, 조회 가능 기간을 모든 서버 기록의 삭제 기간으로 확대하는 설명.
