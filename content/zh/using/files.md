# 管理和查看文件

在文件浏览器中查找和管理文件，在终端旁查看 Markdown、图像和 HTML。通过 Git 视图查看更改。查看器和 Git 视图需要启用对应插件。

## 打开方式

| 位置 | 操作 |
|--------|--------|
| 侧边栏 **工具** <!-- en: Tools --> > **打开文件…** <!-- en: Open File… --> | Tasty 自带的文件选择窗口。在当前查看的终端或文件浏览器所在文件夹中打开；在远程工作区中显示远程文件，选中的远程文件在该远程工作区中打开 |
| 将文件拖到窗口上 | 出现 **放下以打开** <!-- en: Drop to open --> 时松开。放到文件浏览器区域上时，将复制到该文件夹，不会打开（[拖动移动](#拖动移动)） |
| 文件浏览器 Surface | 双击文件 |
| 终端 | `Ctrl+单击`，或选择路径后右键 > **打开文件** <!-- en: Open File -->（[使用终端](terminal.md#打开链接和路径)） |
| 右键单击标签栏空白处 | **新建 Markdown…** <!-- en: New Markdown... --> · **新建文件浏览器** <!-- en: New Explorer --> · **新建 HTML…** <!-- en: New HTML... --> · **新建图像** <!-- en: New Image --> |
| `Alt+'` | 将当前 Surface 改为其他种类（[更改种类](panes-tabs-splits.md#更改种类)） |
| CLI | `tasty new tab --pane 1 --type markdown --file README.md` 等 |

文件扩展名决定打开时使用的 Surface：`.md` 使用 Markdown，图像文件使用图像，`.html` 和 `.svg` 使用 HTML，文件夹使用文件浏览器。无法确定打开方式时，会显示 **打开文件的方式…** <!-- en: Open file with… --> 窗口供选择，选择记录保留在 **最近使用** <!-- en: Recent --> 中。扩展名映射和处理器可在 **设置** > **处理器** <!-- en: Handler --> 标签页中更改。

处理器标签页中的文件类型和关联设置在单击 **保存** 后立即生效，并在后台保存到文件。保存失败时，警告和通知会显示原因，更改仅保留到 Tasty 退出。不会覆盖被外部编辑或损坏的原文件，因此请检查文件，重新启动 Tasty 后再更改。启动时若无法读取此设置，日志会记录文件名和问题种类，不记录文件内容。

**打开文件的方式…** 窗口显示文件路径、识别出的类型和可选处理器。每个处理器都显示图标、名称和来源（**内置** <!-- en: built-in --> · **你** <!-- en: you --> · **plugin**）。

**最近使用** 显示此前使用的处理器和使用时间。先显示刚刚、几分钟前、几小时前、昨天、几天前，超过一周后改为 `2026-09-13` 这样的日期。窗口保持打开并跨过午夜时，显示也会更新。

单击选择处理器，双击打开文件。此选择 **仅限本次**，不会注册为该文件类型的默认处理器。再次打开同一文件时，可能仍会显示选择窗口。默认处理器请在 **设置** > **处理器** 中指定。按 `Esc` 或单击 **取消** <!-- en: Cancel --> 关闭窗口。

通过上述方式直接打开的文件会在新标签页中打开，并 **切换到该标签页。** AI 智能体代为打开时，只增加标签页，当前查看的标签页保持不变，以免正在使用的界面突然切换。

若打开请求指定了来源 Surface，即使等待期间切换到其他窗口，也会在原 Surface 所属窗格中以新标签页打开。查看其他窗格时从文件浏览器打开文件，也会在文件浏览器所在窗格中打开。若原 Surface 已关闭，不会改在其他窗口中打开。

由文件打开的 Surface 与其他 Surface 一样，可以拆分、移动、关闭，并在重新启动时恢复。标签页名称为文件名。

拖动文件选择窗口最上方的一行（带标题和 ✕ 的一行）可移动窗口。通过 ✕、**取消** <!-- en: Cancel --> 或 `Esc` 关闭时，不会打开任何文件。

文件选择窗口的列表上方有名称、大小、修改日期列标题，选中行的最左侧带有色条。长文件名以 `…` 缩短显示，避免与大小、修改日期重叠。缩短显示不会改变选择或打开的文件。

若打开时限定了文件种类（例如导入按键绑定时仅限 `.toml`），名称栏右侧会有一个显示扩展名的区域，如 `*.toml`。扩展名较多时末尾以 `…` 缩短，悬停可查看完整列表。该区域仅用于说明，不能单击更改。未限定种类时，不显示此区域。

在列表中单击文件或文件夹都会选中该行；双击文件夹会进入，双击文件会打开。选中文件夹后单击 **打开** <!-- en: Open --> 会进入该文件夹，这是通过键盘进入下级目录的方式。选择保存位置时，文件夹不能作为保存目标，因此选中文件夹后名称栏保持不变，下方会显示一行灰色说明。保存时双击文件只会填入名称，不会保存，以便留出阅读覆盖警告的机会。

文件选择正在进行时，新的选择请求会被拒绝并显示说明。请在现有文件选择窗口中完成选择或取消后再打开。

## 文件浏览器

Tasty 内置的文件管理器。在终端中通过 `Alt+'` > **文件浏览器** 切换，会以该终端的当前目录为根目录打开。也可使用 `tasty new tab --pane 1 --type explorer --path ~/proj` 打开。用 `--cwd ~/proj` 替代 `--path` 时，也会以该文件夹为根目录打开。

### 界面

- **左侧**：**文件** <!-- en: Files --> 树（根目录固定）及下方的 **收藏夹** <!-- en: Favorites -->。
- **顶部**：**后退** <!-- en: Back --> · **前进** <!-- en: Forward --> · **向上** <!-- en: Up --> · **刷新** <!-- en: Refresh -->、地址栏、**新建文件夹** <!-- en: New folder --> · **新建文件** <!-- en: New file --> 按钮，以及 **查找** <!-- en: Find --> · **预览面板** <!-- en: Preview panel --> · 隐藏文件（眼睛图标）开关、视图切换（**网格** <!-- en: Grid --> · **列表** <!-- en: List --> · **详细信息** <!-- en: Detail -->）。文件浏览器区域宽度小于 440px 时，命令按钮折叠为一个 **更多** <!-- en: More -->（`…`）按钮，单击后以菜单显示相同命令。菜单中的查找和预览项会写明单击后的操作（**查找** ↔ **关闭查找** <!-- en: Close find -->、**显示预览** <!-- en: Show preview --> ↔ **隐藏预览** <!-- en: Hide preview -->、**显示隐藏文件** <!-- en: Show hidden files --> ↔ **隐藏隐藏文件** <!-- en: Hide hidden files -->）。显示隐藏文件时，隐藏文件开关呈按下状态，悬停会同时显示操作和快捷键（例如 **显示隐藏文件 (Ctrl+Shift+.)**）。
- **右侧**：当前文件夹中的项目。网格视图中，本地图像文件（不超过 1 MiB）会显示小缩略图来代替图标。顶部的 `..` 用于进入上级文件夹。详细信息视图中，单击 **名称** · **大小** · **修改日期** · **类型** 列标题可排序。类型列以文字显示种类，如“Markdown”“PDF 文档”“压缩文件”“PNG 图像”（表中未列出的类型显示为“RS 文件”），链接则显示目标的种类，如“Markdown 链接”。属性弹窗和预览标题也使用相同文字，按类型排序时，同一种类会排在一起，.gz 和 .zip 等压缩文件会相邻排列。
- 可在 Surface 内创建多个 **新建标签页** <!-- en: New tab -->，分别查看文件夹。与窗格的标签页相互独立。

切换内部标签页后再返回时，选中项目、列表和左侧文件树的滚动位置、查找栏中的搜索词及子文件夹搜索结果都会保留。即使两个标签页打开同一文件夹，也分别记忆。在其他标签页停留期间完成的读取和搜索，只更新发起操作的标签页。关闭标签页会丢弃这些状态；重新打开应用时，只恢复文件夹、视图和排序，选择和查找从头开始。

远程文件浏览器在同一连接中，若服务器文件夹未变，工作区更新后也会保留内部标签页和浏览位置。若服务器更改文件夹或重新建立连接，则在服务器报告的文件夹中以新标签页开始。

将包含文件浏览器的布局保存为预设后再应用，会按原样打开文件浏览器内每个标签页此前查看的文件夹、视图和排序，窗格标签页标题为活动标签页打开的文件夹（根目录）名称。若在预设编辑中指定了工作目录，则只打开该文件夹，代替已保存的标签页。若已保存的文件夹现在不存在，该标签页会显示读取错误说明。

拖动分隔线缩小文件浏览器区域时，会停在仍能容纳工具栏、状态行和约两行列表的高度（180px）。拆分文件浏览器区域或通过拆分新建文件浏览器时，也会将分隔线向一侧移动，使文件浏览器区域保持 180px。其他种类的区域使用剩余高度，但不会拆分到小于容纳标签栏和一行内容的高度（56px）。若没有足够空间使两个文件浏览器区域都保持 180px，或使其他区域保持 56px，则不拆分；拆分菜单和快捷键会短暂显示“空间不足，无法拆分此面板”通知，`tasty split` 则将原因作为错误返回。区域较低、左侧侧边栏高度小于 240px 时，会隐藏收藏夹，只显示文件树。缩小窗口时，可以低于此高度。内容区域高度小于 120px 时，空文件夹、权限被拒绝和读取错误说明会改为图标、标题、按钮组成的一行，悬停标题可查看详细原因。

无法读取文件夹时（路径已消失、不是文件夹或远程读取失败），列表位置会显示 **无法读取此文件夹** <!-- en: Can't read this folder --> 及操作系统返回的原因。**重试** <!-- en: Retry --> 会重新读取同一文件夹，**转到上级目录** <!-- en: Go up --> 会进入上一级文件夹。若上级文件夹也已消失，则进入仍然存在的最近上级文件夹。没有权限时，会单独显示 **权限被拒绝** <!-- en: Permission denied -->。

在文件浏览器中粘贴、重命名或移到回收站后，其他正在查看已更改文件夹的文件浏览器（即使位于其他窗口）也会重新读取列表和左侧树。若当前查看的文件夹已删除或重命名，会在原处显示读取错误说明，不会自动转到其他文件夹。其他程序在文件夹中创建、删除或重命名项目时，当前使用的 Tasty 窗口中，获得焦点的标签页里的文件浏览器会在 2 秒内检测到，并重新读取列表及树中展开的文件夹。选择和滚动位置保持不变。其他标签页中的文件浏览器，或使用其他应用期间保留的文件浏览器，会在返回该标签页或 Tasty 窗口时立即检查。仅文件内容、大小、权限发生变化的情况，以及远程（attach）文件浏览器，不会自动更新，请单击 **刷新**（`F5`）。若还要自动更新已打开文件夹中文件的大小和修改时间，请启用 **设置** <!-- en: Settings --> > **常规** <!-- en: General --> > **文件浏览器：自动刷新文件详细信息** <!-- en: Explorer: refresh file details -->。启用后，大小、日期列及预览、缩略图会在几秒内更新，但每次检查都会读取该文件夹中的全部项目，因此在较慢的驱动器或项目极多的文件夹中，最好保持关闭。默认关闭，即使启用，也不会检查树中已展开文件夹内部的文件。若展开了大量树文件夹，会分几轮轮流检查，而非一次全部检查，因此深层文件夹中的更改可能稍晚才显示。刷新也会重新读取已展开的树。本地文件浏览器正在显示文件夹列表时，不会清空列表，因此选择和滚动位置保持不变。远程（attach）文件浏览器、错误说明中的 **重试**，以及读取期间执行的刷新，会清空列表并从头重新读取。重新读取后，若选中的项目已消失，也会从选择中移除。

单击地址栏可直接输入路径，最近访问的文件夹会作为自动补全候选显示。单击候选项，或用方向键选择后按 `Enter`，即可进入该文件夹。按 `Enter` 或单击 **转到** <!-- en: Go --> 执行。左侧树固定在根目录，右侧列表则可转到任意位置。输入文件路径时，不会打开文件，而是进入该文件所在文件夹并选中该文件。远程文件浏览器也相同。

以分离字母或重音符号存储的名称，会在界面上合成显示。编辑以这种方式显示的地址时，会选中完整原始路径。即使两个文件看起来相同，复制和移动时仍分别使用各自的实际名称。

- 相对路径以当前查看的文件夹为基准。`..` 表示上一级。
- `~` 和 `~/文件夹` 位于主文件夹下。
- 在 Windows 上，仅输入 `C:` 这样的驱动器名会进入该驱动器顶层，也可使用 `\\服务器\共享` 这样的网络路径。
- 输入不存在的路径时，不会移动，会通过通知显示原因。目标已消失的链接按文件处理，进入链接所在文件夹并选中链接。
- 在远程工作区的文件浏览器中，会在远程计算机上查找输入的路径。本地不存在的文件夹，只要远程存在即可打开；若远程无法读取，会在列表位置显示原因。`~` 表示远程计算机的主文件夹，`.` 和 `..` 也按远程路径解析。刚连接后，若尚未获取远程主文件夹，会提示输入完整远程路径来代替 `~`。检查远程路径是否为文件期间，地址栏保留输入的路径；检查耗时较长时，地址栏末尾会显示旋转指示器。此时按 `Esc` 会停止检查，地址栏恢复为当前文件夹。

在 Linux X11 上，输入韩文等文字的组合输入期间，按列表导航、打开、取消选择、重命名或回收站快捷键时，会先处理组合输入。同一次按键不会移动或打开文件。组合输入结束后再次按键，会正常执行。查找输入框中，用于结束组合输入的 `Esc` 也不会清除搜索词，下一次 `Esc` 才按通常方式执行。在文件浏览器项目的重命名弹窗中，用于结束组合输入的 `Enter` 只确认文字，弹窗保持打开。要重命名，请再次按 `Enter` 或单击 **保存** <!-- en: Save --> 按钮。查找中的其他按键和路径输入框，使用各自输入框的按键处理方式。

因未设置 `DISPLAY` 或无法连接 X 服务器而使用 Linux 原生 Wayland 运行时，结束韩文组合输入的按键（`Down`、`Delete`、`Enter`、`Esc`）仍可能在同一次按键中触发列表操作；查找中的 `Down`、`Esc` 也可能继续触发项目选择、清除搜索词。重命名时，在输入框中按 `Enter` 或单击 **保存** <!-- en: Save --> 按钮确认，按 `Esc` 取消。应用首次打开后，也无需切换到其他窗口再返回，即可直接确认。

### 新建文件夹和文件

从工具栏的 **新建文件夹** · **新建文件**、空白处右键菜单或文件夹右键菜单开始（在该文件夹内创建）。列表顶部会打开名称输入行。从文件夹右键菜单开始时，会在该文件夹正下方（网格中为文件夹后一个单元格）打开，输入行略微缩进，输入框后附有 **在 {文件夹} 中** <!-- en: in {folder} -->，并突出显示该文件夹。当前查看的文件夹不变。输入行中，“新建文件夹”会选中完整名称，“无标题.txt”会选中扩展名之前的部分。若有同名项目，会以“新建文件夹 2”这样的编号名称开始。

- 按 `Enter` 创建，按 `Esc` 取消。取消不会在磁盘上创建任何内容。
- 单击输入行外部时，名称有效则创建，名称为空或无效则取消。
- 名称为空（包括仅含空格）、含不可用字符（`/`，Windows 上还包括 `\ : * ? " < > |`）、以空格开头或结尾、为 Windows 保留名称（`CON`、`NUL` 等），或在 Windows 上以点结尾时，输入框下方会立即显示原因。名称已存在时，会在按 `Enter` 时提示（macOS、Windows 上仅大小写不同也视为同名），输入行保持打开并保留文字。不会覆盖。
- 新建项目会移至排序后的位置并被选中。若期间已转到其他文件夹或选中其他项目，则选择不变。
- 在不可写入的文件夹中，两个按钮会变灰，悬停显示 **无法写入此文件夹** <!-- en: Can't write to this folder -->。通过文件夹右键菜单尝试在不可写入的文件夹中创建时，不会打开输入行，而是显示相同说明（Windows 上会在创建时报告错误）。远程工作区的文件浏览器中也可使用。若远程计算机上的 Tasty 版本较旧，则没有这些按钮和菜单项。

文件浏览器获得焦点时，按 `F7` 新建文件夹，按 `Shift+F4` 新建文件。macOS 默认将 F 键用作媒体键，需要同时按 `Fn`。可在设置 > 按键绑定 > **文件浏览器** <!-- en: Explorer --> 中更改按键。

### 查找和搜索子文件夹

通过工具栏的 **查找** 开关（区域较窄时在 **更多** 菜单中），或在文件浏览器获得焦点时按 `Ctrl+F`，可在工具栏下方打开查找栏。`Ctrl+F` 与终端搜索使用相同快捷键，在文件浏览器中则打开此查找栏。

- 输入时，当前文件夹中只保留名称包含该文字的项目。不区分大小写，匹配部分以强调色显示。右侧显示可见数和总数，如“2 / 6”。没有匹配名称时，列表位置显示“没有与‘…’匹配的名称”。过滤时，进入上级文件夹的 `..` 行仍保留。
- 被过滤隐藏的项目会从选择中移除。全选也只选择可见项目。
- 启用 **子文件夹** <!-- en: Subfolders --> 后，会搜索当前文件夹下的全部内容。搜索期间，结果会随找到随填入，可用 **停止** <!-- en: Stop --> 终止（已找到的结果保留）。详细信息视图中，**文件夹** <!-- en: Folder --> 列替代种类列，显示相对于当前文件夹的位置；列表和网格视图中，悬停项目可查看。选中一条结果后，下方状态行也会显示位置。无法读取的文件夹会被跳过，并提示“已跳过 1 个文件夹”等信息，悬停可查看这些文件夹。结果达到 5,000 个时停止搜索，显示“找到 5,000 个以上 · 已停止”。结果保留，可继续输入搜索词来缩小范围。不会进入文件夹链接。无论在哪个文件浏览器中重命名、移动或删除结果项目，都会从头重新搜索以更新结果。
- 在查找框中按一次 `Esc` 清除文字，再按一次关闭查找栏。单击 × 或转到其他文件夹（后退、向上、地址栏、打开文件夹）也会关闭。
- 在查找框中输入文字期间，输入字符查找和文件浏览器快捷键不生效。
- 要按扩展名查找，在同一输入框中输入 `ext:rs`。`ext:rs ext:md` 查找 rs 或 md 文件，`note ext:rs` 查找名称包含 note 的 rs 文件。排除文件夹，只检查最后一个扩展名。不区分大小写，`EXT:.RS` 效果相同。扩展名使用字母、数字、下划线和连字符。空的 `ext:`、`ext:*`、`ext:rs,md` 会作为普通名称文字搜索，不支持通配符或引号语法。与扩展名条件一起输入的其余名称，会将单词以一个空格连接后作为子字符串查找。只突出显示名称条件。
- 搜索期间，通过工具栏或空白处菜单新建文件夹、新建文件或普通粘贴时，会放入开始搜索的文件夹。若符合搜索条件，会重新出现在结果中。指定文件夹的菜单或 **粘贴（到此文件夹）** 则使用指定文件夹。
- 远程工作区的文件浏览器只过滤当前文件夹，不支持搜索子文件夹。

### 预览面板

单击工具栏的 **预览面板** 按钮，会在列表右侧打开面板，显示一个选中的文件。文本文件以等宽字体显示开头部分（64 KB），图像适应面板显示（不放大到超过原始大小）。其他类型或文件夹显示 **此文件类型不支持预览** <!-- en: No preview for this file type -->，大于 1 MiB 的文件，以及单边超过 16384 像素等解码后过大的图像，显示 **文件过大，无法预览** <!-- en: Too large to preview -->。图像超过像素上限时，也会显示其实际尺寸。选中多个文件时，会显示选中数量，并提示只选择一个。拖动面板左边缘，可在 200~460px 之间调整宽度。每个文件浏览器分别记忆启用状态和宽度，重新打开 Tasty 后仍保留，保存为预设时也会包含。文件浏览器区域过窄、无法与列表并排显示时，按钮保持启用，仅暂时隐藏面板。面板标题下方剩余高度不足 120px 时，只保留文件名、种类和大小，隐藏正文及标题下方分隔线。远程工作区的文件浏览器不支持预览。通过键盘移动的当前项目边框显示在文件列表内，不会侵入预览面板。

### 隐藏文件

名称以点（`.`）开头的文件和文件夹，以及 Windows 上带隐藏属性的项目、macOS 上设有隐藏标记（`chflags hidden`）的项目，最初不会显示在列表中，下方状态行会以 **已隐藏 {n} 项** <!-- en: {n} hidden --> 等形式显示隐藏数量。按 `Ctrl+Shift+.`（macOS 为 `Cmd+Shift+.`），或在 **更多** 菜单中选择 **显示隐藏文件**，即可一并显示，隐藏项目的名称和图标使用较淡的文字颜色。用相同方式可再次隐藏。每个文件浏览器分别记忆启用状态，重新打开 Tasty 后仍保留，保存为预设时也会包含。左侧文件夹树使用相同设置。子文件夹搜索也使用此设置。关闭隐藏项目显示时，不会进入隐藏文件夹；更改设置会从头重新执行同一搜索。远程工作区的文件浏览器也遵循远程计算机的隐藏属性和隐藏标记。若远程计算机上的 Tasty 版本较旧，则只检查名称开头的点。

### 属性

选择右键菜单底部的 **属性** <!-- en: Properties -->，会在文件浏览器区域内打开弹窗。文件和文件夹会显示类型、大小、修改日期、创建日期、路径和权限。**路径** <!-- en: Path --> 为项目自身的绝对路径，可用旁边的复制按钮复制。文件夹在后台统计子项目数量和大小时，会显示旋转进度指示器；若有无法读取的文件夹，会在大小下方显示 **部分文件夹无法读取** <!-- en: Some folders couldn't be read -->。关闭弹窗会停止统计。时间使用本计算机的时区，可在 **设置** > **常规** 的 **属性中的时间格式** 中选择精确到分钟、精确到秒或秒 + UTC 偏移量。

查看单个项目时，下方的 **打开** <!-- en: Open --> 按钮会像在列表中按 Enter 一样打开该项目。文件遵循处理器设置，文件夹在该文件浏览器中进入，弹窗保持打开。失效链接的按钮会变灰。

对于本计算机上的单个文件或文件夹，可通过 **权限** <!-- en: Permissions --> 旁的 **编辑** <!-- en: Edit --> 更改权限。macOS、Linux 上可勾选所有者、组、其他用户的读取、写入、执行权限，Windows 上只更改 **只读** <!-- en: Read-only --> 属性。单击 **应用** <!-- en: Apply --> 后才会更改，只应用于该项目，文件夹内的项目保持不变。setuid、setgid、sticky 等特殊位也保持不变。无法更改时，框中会显示原因，并重新读取和显示实际权限。文件浏览器区域较窄时，会将角色名称移至复选框上方一行，避免框被截断；更窄时，读取、写入、执行会改为带名称的复选框，逐行排列。若不是所有者（以管理员权限运行时除外），则不显示编辑按钮，改为提示只有所有者才能更改。不能更改链接、多个项目或远程项目的权限。

链接会显示链接目标及目标的种类、大小、修改时间，以及链接自身的路径。链接目标也可复制。目标不存在的链接显示为 **失效链接** <!-- en: Broken link -->，并在目标下方显示 **未找到目标** <!-- en: Target not found -->。链接下方会说明，删除或重命名链接不会影响目标。因权限错误等原因无法读取时，会显示原因和 **重试** <!-- en: Retry --> 按钮。

选中多个项目时，显示数量、种类、总大小和共同位置；右键单击空白处时，显示当前文件夹。若部分选中项目无法读取，只统计并显示可读取项目，并在种类下方显示 **部分项目无法读取** <!-- en: Some items couldn't be read -->。全部无法读取时，会显示上述重试界面。同时选择文件夹及其内部项目时，内部项目只统计一次；通过硬链接连接的同一文件，其大小也只累加一次。远程文件浏览器只显示列表中已有的类型、大小、修改日期和路径；远程列表没有文件夹大小，因此包含文件夹的总大小显示为 —。

右键菜单中，所有已指定快捷键的项目都会在右侧显示第一个快捷键。**撤销**、**重做** 也遵循相同规则，在设置中更改或清空快捷键后，菜单显示也会随之更新。

### 输入字符查找

列表获得焦点时，输入文件名的首字母，会选中以该字母开头的项目并滚动到该位置。网格、列表、详细信息视图中均相同。连续按相同字母会逐个切换候选项，最后一个之后返回第一个。连续输入不同字母时，会进行 `co`、`con` 这样的前缀搜索。不区分大小写，停顿约 1 秒后再输入，会开始新搜索。没有匹配名称时，选择保持不变。

编辑地址栏或打开弹窗时，输入的文字会进入对应位置。打开多个文件浏览器时，只有当前获得焦点的一个会响应。

若已将不带修饰键的单个字符直接指定为快捷键，该字符只执行快捷键操作，不用于此功能。默认设置中没有此类快捷键。

### 右键菜单

重命名时，若有同名项目，不会覆盖，而是报告失败。复制时，符号链接保留为链接，文件保留原权限和修改时间，文件夹保留原权限（包括只读）。不复制所有者、扩展属性和 ACL。也不能将文件夹粘贴到实际为自身或其子目录的路径。文件操作失败时，通知会显示错误。

指向文件夹的链接像文件夹一样打开，地址栏保留链接路径。重命名链接或将链接移到回收站，只处理链接，目标文件夹保持不变。打开目标已消失的链接时，会通知目标不存在。列表中的链接会在名称后附加小链接图标；目标已消失的链接，其图标位置会显示警告色链接图标，悬停会显示未找到的目标路径。远程文件浏览器显示方式和通知相同，但悬停不显示目标路径。若远程 Tasty 版本不发送链接状态，则不区分链接，显示为普通项目。

因未设置 `DISPLAY` 或无法连接 X 服务器而使用 Linux 原生 Wayland 运行时，项目和空白区域的右键菜单以及工具栏的 **更多** <!-- en: More --> 菜单不会打开，也不会显示说明。使用可见工具栏按钮和文件浏览器快捷键。**属性** 等没有默认快捷键的功能，可在 **设置** > **按键绑定** > **文件浏览器** 中指定按键。

- **打开** <!-- en: Open -->：右键单击一条子文件夹搜索结果时，显示在最前面。与双击相同，文件夹会进入，文件会打开。远程文件浏览器中不显示。
- **在所在文件夹中显示** <!-- en: Show in enclosing folder -->：右键单击子文件夹搜索结果（位于 **打开** 之后）或单个链接时，显示在前面。沿用当前浏览的路径，打开该项目实际所在的文件夹（链接则为目标所在文件夹），选中项目并滚动到可见位置。目标已消失的链接和远程文件浏览器中不显示。
- **新建文件夹** <!-- en: New folder --> · **新建文件** <!-- en: New file -->：位于空白处菜单最前面，以及文件夹菜单的文件操作组中。参见上文“新建文件夹和文件”。
- **复制路径** <!-- en: Copy Path -->：选中多个项目时，菜单名称改为 **复制多个路径** <!-- en: Copy Paths -->，用换行连接各路径。
- **撤销** <!-- en: Undo --> · **重做** <!-- en: Redo -->：位于空白处菜单中，名称会注明目标操作，如“撤销：移动 3 项”“撤销：重命名”。即使没有可撤销或重做的操作，**撤销**、**重做** 两行也会以灰色保留在 **属性** 前。每个文件浏览器记忆最近 10 次操作（复制、移动、重命名、新建文件夹、新建文件）。部分完成的复制、移动只记忆已完成项目。撤销后的操作可重做，执行新操作会清除可重做内容。重做会再次执行相同操作；复制、移动遇到同名项目时再次询问，重命名、新建项目遇到同名项目时则不覆盖并报告失败。撤销重命名会恢复原名称（若原名称已被其他项目占用，或之后修改过该项目，则保持不变）；撤销新建文件夹、新建文件会将其移到回收站（若创建后已放入内容或做过修改，则保留）。最近一次操作无法再撤销时（例如复制件已删除、移动后的文件又被修改），该行变灰，悬停可查看原因（Windows 上相同原因显示在行名称中）。撤销后，若原位置的项目消失或发生变化，重做也以相同方式变灰，因此重做不会移动从未撤销过的文件。该文件浏览器的文件操作仍在等待或执行时，两行都会变灰，快捷键只显示说明，因此不会跳过刚开始的操作而撤销更早的操作。移到回收站不计入此记录（从回收站恢复）。
- **复制** <!-- en: Copy --> · **剪切** <!-- en: Cut --> · **粘贴** <!-- en: Paste --> · **粘贴（到此文件夹）** <!-- en: Paste (into) -->：存在同名项目时，会询问处理方式（[进度和结果](#进度和结果)）。所有 Tasty 窗口共享复制、剪切列表，因此可在其他窗口中粘贴。此列表也会放入操作系统剪贴板，可粘贴到其他文件管理器；在文件管理器中复制、剪切的文件，也可粘贴到文件浏览器中。两者不同时，粘贴较晚复制的内容；若之后在其他应用中复制了文字，文件浏览器中就没有可粘贴内容。剪切的文件移动一次后，会从剪贴板中清除。远程文件浏览器中复制的文件不放入操作系统剪贴板；剪贴板中若有非本计算机文件的项目（其他计算机的路径或网址等），则不粘贴。其他应用持有剪贴板但不响应时，也视为该应用较晚复制，不执行粘贴，并通过通知说明。macOS Finder 中复制的文件始终按复制方式粘贴。Linux 上的文件复制、剪切和粘贴使用 X11 剪贴板；在设有 `DISPLAY` 且能连接 X 服务器的 Wayland 会话中，通过 XWayland 使用。因未设置 `DISPLAY` 或无法连接 X 服务器而使用原生 Wayland 运行时，无法使用操作系统文件剪贴板。包括此情况在内，无法更新系统剪贴板时，会提示文件列表仅保存在此 Tasty 实例内部。粘贴内部列表时，若无法检查系统剪贴板，也会提示。没有可用内部列表时执行粘贴，会提示无法访问。仅打开菜单不会显示通知。
- **移到回收站** <!-- en: Move to Trash -->：无需确认，直接移到操作系统回收站。要撤销，请从回收站恢复。若该驱动器没有回收站，不会删除任何内容，并显示说明。
- **重命名** <!-- en: Rename -->。新名称遵循与新建文件夹、新建文件相同的规则（空名称、不可用字符、首尾空格、保留名称），不符合时会在输入框下方显示原因，不会保存。
- **在系统中打开** <!-- en: Open in system -->：选中的文件使用操作系统默认应用打开，文件夹使用操作系统文件管理器打开。选中多个项目时会全部打开。
- **在 Finder 中显示** <!-- en: Show in Finder -->（macOS）· **在文件资源管理器中显示** <!-- en: Show in File Explorer -->（Windows）· **在文件管理器中显示** <!-- en: Show in File Manager -->（Linux）：选中单个项目时，打开其所在文件夹并选中该项目。Linux 上若文件管理器不支持选择项目，则只打开文件夹。
- **在新标签页中打开** <!-- en: Open in New Tab -->：在窗格中再打开一个以该文件夹为根目录的文件浏览器标签页。
- **设为根目录** <!-- en: Set as Root -->：更改左侧树的根目录。
- **添加到收藏夹** <!-- en: Add to Favorites -->：右键单击一个文件夹或空白处时显示。为其命名后放入左下方列表。所有文件浏览器共享收藏夹，保存在 `~/.tasty/explorer-favorites.toml`。其他窗口中添加或删除的收藏夹也会立即更新。文件保存于后台执行，保存期间可继续操作。保存失败时，会显示警告通知，列表在本次运行期间保留。若收藏夹文件被外部更改，则不会覆盖，请检查文件后重新启动 Tasty。右键单击左下方收藏夹项目，会显示 **在新标签页中打开** · **设为根目录** · **从收藏夹移除** <!-- en: Remove from Favorites -->（远程文件浏览器不显示在新标签页中打开）。移除不会影响文件夹本身。
- **属性** <!-- en: Properties -->：打开上文的[属性](#属性)弹窗。远程文件浏览器中也会显示。

最后选择的视图方式会被记忆，并应用于新文件浏览器。文件浏览器字体在 **设置** > **外观** <!-- en: Appearance --> 的 **文件浏览器** <!-- en: Explorer --> 项中单独指定。远程工作区的文件浏览器也支持新建文件夹、新建文件、重命名、移到回收站、复制、剪切、粘贴和拖动移动。实际操作由远程计算机上的 Tasty 执行，进度显示、名称冲突询问和结果卡片与本地相同。回收站为远程计算机的回收站。远程操作不计入 **撤销** 列表，请使用结果卡片中的 **还原**。每条远程连接一次执行一个操作，因此进度行和等待列表最前面会显示远程计算机名称。区域较窄时，会按剩余宽度缩短名称和字节数显示，避免与等待数量、取消按钮重叠。即使名称文字不可见，悬停主机图标仍可查看完整名称；悬停缩短的字节数可查看完整数值。等待列表也会在区域内适应显示。区域极窄时，等待列表会隐藏操作图标，优先显示取消、移除按钮。若连一个完整按钮也无法容纳，按钮也会隐藏，请扩大区域后使用。远程计算机上的 Tasty 版本较旧时，更改文件的项目和按钮会变灰禁用，工具提示（通过快捷键调用时为通知）会要求更新该计算机上的 Tasty。操作期间连接中断时，会提示远程操作已停止，但无法得知已执行到何处，请重新连接后检查文件夹。该连接中等待的操作不会执行，并会提示未执行的数量。远程文件浏览器不显示在系统中打开、在文件管理器中显示、在新标签页中打开。菜单中会显示 **添加到收藏夹**，但单击只会通知尚不支持，不会添加。

不能在本地与远程之间，或不同远程计算机之间粘贴或拖放文件。不会显示粘贴菜单，使用粘贴快捷键时只显示说明。不会改为复制另一台计算机上相同路径的文件。双击 Markdown 文件时，会在远程计算机上打开该文件的标签页；若默认处理器无法在远程使用，则只显示可在远程使用的处理器供选择；若该类型没有此类处理器，则只显示说明。

### 拖动移动

将项目拖到文件夹行、文件夹单元格、左侧树的文件夹或收藏夹项目上，会移至该文件夹。放到文件或空白处时，会放入该文件浏览器当前查看的文件夹。也可拖到旁边打开的其他文件浏览器。拖动项目期间，靠近列表或左侧树的上下边缘会自动滚动。越靠近边缘越快，移出区域后保持每秒 20 行的速度。多个文件浏览器上下拆分时，只有鼠标所在区域滚动；在区域外时，只有最近的文件浏览器滚动。

- 同一磁盘内 **移动**，不同磁盘间 **复制**。放下时按住 `Ctrl`（macOS 为 `Option`）可反转操作。此按键可在 **设置** > **按键绑定** > **常规** 底部的 **文件浏览器拖动切换修饰键** <!-- en: Explorer drag flip modifier --> 中更改（与 `config.toml` 中 `[keybindings]` 的 `explorer_drag_flip_modifier` 为相同值）。
- 拖动期间，指针旁的提示会以 **移动到（文件夹）** <!-- en: Move to --> · **复制到（文件夹）** <!-- en: Copy to --> 等形式预先说明操作。无法放置的位置会显示 **无法放置** <!-- en: Can't drop --> 及原因（放入自身、已在该文件夹中、不同计算机、此远程无法更改文件、无写入权限）。通过符号链接进入的文件夹，按链接指向的文件夹判断。
- 在远程文件浏览器内部拖动时，只在远程计算机报告为同一磁盘的文件夹之间 **移动**，其余情况均 **复制**。
- 在折叠的树文件夹上停留 800ms 后，即使不再移动鼠标也会展开。等待期间，目标文件夹边框保持显示。按 `Esc` 取消拖动。
- 从操作系统文件管理器拖到文件浏览器区域的文件，会 **复制** 到该文件夹（不会移动）。不能放到远程文件浏览器中（因为文件位于其他计算机上）。Linux 上的文件拖入支持 X11/XWayland。在 Linux（X11）上，拖动期间会显示整个窗口的说明，而非区域提示。放下文件时，若 Tasty 尚未收到该窗口上的指针位置，文件不会复制，且会被忽略，不显示说明。从文件管理器拖入的常见操作也会遇到此情况。已收到指针位置时，放到文件浏览器区域上会复制到该文件夹。

在 Windows、macOS、Linux 上，可将本地文件浏览器中的项目拖出窗口，**复制** 到其他应用。Linux 支持 X11 和原生 Wayland，文件图标和指针提示由操作系统提供。原件保持不变，外部复制不计入 Tasty 的撤销列表。返回原窗口后放下，也不会同时执行内部移动。远程项目不能拖出。在 X11 上，使用文件浏览器的 **取消选择** 按键（默认 `Esc`）取消拖动。Windows、macOS、Wayland 使用操作系统的拖动取消键。

不能发送到同一 Tasty 进程的其他窗口。单独运行的 Tasty 可能像普通外部应用一样接收，但 Tasty 窗口之间拖动文件不属于受支持功能。启动错误或通信错误会显示说明，不会仅因开始拖动就显示复制完成。

### 进度和结果

粘贴、拖放、移到回收站会按顺序逐个处理。复制、移动会先统计目标文件。此时显示 **正在统计要复制的项目** 或 **正在统计要移动的项目**，并更新找到的数量，不显示进度条。统计结束后，会显示包含文件夹内部文件的进度数量及当前文件名。进度条按字节计算，若全部为空文件或无法得知总大小，则按文件数量计算。结果中的数量为最初请求的项目数。但若同时选择文件夹及其内部项目（例如在子文件夹搜索结果中），内部项目会随文件夹一起处理，不单独计数。链接指向的项目即使与链接一起选中，也会单独处理。  发起操作的文件浏览器下方状态行会显示进度条、当前处理的文件和大小，可用 **×** 停止。停止后保留已完成项目，不处理剩余项目。有等待操作时，会显示 **+1 项排队中** <!-- en: +1 queued -->，单击可打开列表并移除等待操作。若等待操作过多，或一次选中的项目过多，会拒绝操作，并在该文件浏览器中显示警告卡片。队列已满时，可通过卡片中的 **显示队列** <!-- en: Show queue --> 打开列表。

存在同名项目时，会在该文件浏览器获得焦点时弹出询问弹窗。若正在查看其他位置，请单击状态行的 **显示** <!-- en: Show -->。

- **两者都保留** <!-- en: Keep both -->（`Enter`）：默认值。在新项目名称后附加 `(copy)`。现有项目不变。
- **跳过** <!-- en: Skip --> · **替换** <!-- en: Replace -->（仅文件）· **取消其余操作** <!-- en: Cancel the rest -->（`Esc`）。
- 不合并同名文件夹。文件夹只能选择跳过或两者都保留。
- 仍有其他冲突时，可启用 **对其余 n 个冲突执行相同操作** <!-- en: Do this for the other conflicts -->，一次回答。

完成后，文件浏览器右下方会显示结果卡片。全部完成的卡片会在片刻后消失；存在失败或跳过项目的卡片会保留到关闭，并显示对应路径。通过 **×** 停止的操作，若仍有未执行项目，卡片也会保留到关闭。若无法删除复制期间使用的隐藏临时文件夹（名称以 `.tasty-copy-` 开头），卡片会改为警告卡片，同时显示该路径和“无法删除临时文件夹”的原因，并保留到关闭，请解决原因后手动删除该文件夹。

- **重试** <!-- en: Retry -->：只重新处理失败、跳过以及停止后未执行的项目。已完成项目不会重复处理。对于仍有原件的移动项目，只重试删除原件。
- **复制路径** <!-- en: Copy paths -->：将卡片中的路径放入剪贴板。
- **撤销** <!-- en: Undo -->：复制、移动全部完成后，在卡片显示期间提供。将移动的项目放回原处（若原处已有其他项目则保持不变），将复制件移到回收站。复制后修改过的复制件会保留。通过替换覆盖的文件无法恢复。

跨磁盘移动时，若无法删除全部原件（例如子文件夹无写入权限），会显示警告卡片，说明原件全部或部分保留，直到关闭。此时复制件是完整数据，因此不提供还原。解决阻碍原因后，单击 **重试** 只会删除剩余原件。若期间复制件消失或被替换，或原文件被修改，则不删除原件，并显示原因。若复制件路径通过链接等方式指向与原件相同的文件，也不会删除。对于文件夹，只删除复制件中内容也完全相同的项目（比较大文件时会显示进度，可取消；取消后，仍保留的原件会重新留在警告卡片中，以便稍后重试），移动后添加到原文件夹或修改过的项目会保留，并显示数量。比较期间状态行显示正在检查，删除期间显示正在删除原件；全部删除后，会短暂显示卡片，说明已删除的原件数量。即使一次重试同时执行删除原件和重新移动，也只显示一张结果卡片。

## Markdown

渲染显示 `.md` 文件。文件更改后，会在 1 秒内自动重新绘制。

- 表格、复选框、脚注、代码高亮、`mermaid` 图表、`$…$` 公式、`> [!NOTE]` 提示块（包括 Obsidian 风格的 `[!tip]-` 折叠）、隐藏顶部 frontmatter。
- 有标题时，正文上方会附有可折叠的 **目录** <!-- en: Table of contents -->。单击条目会在当前文档内滚动到对应标题，再次单击同一条目也会重新跳转。
- 悬停代码块时显示 **复制代码** <!-- en: Copy code --> 按钮。
- 文档获得焦点时，使用[快捷键](../customize/keybindings.md)设置中的 **搜索** 键（默认 `Ctrl+F` · `Alt+F`，macOS 为 `Ctrl+F` · `Cmd+F`），执行 **在文档中查找** <!-- en: Find in document -->。更改搜索键后，也会立即应用于已打开的文档。
- 全选、复制键只作用于获得焦点的位置。在正文中全选时，只选择文档内容，不包含地址框和搜索框的文字；在地址框或搜索框中，只选择该输入框的内容。
- 在顶部地址栏输入其他文件路径，按 `Enter` 或单击 **转到** <!-- en: Go --> 跳转。最近打开的文件会作为自动补全候选显示。同一 Tasty 实例其他窗口中打开的文件也会一起显示，按最近打开顺序最多显示 10 个。Surface 较窄时会隐藏转到按钮，但仍可按 `Enter` 跳转。
- 单击地址栏左侧的文件夹按钮（**打开文件…** <!-- en: Open a file… -->），会在当前文档所在文件夹中打开文件选择窗口。选中的文件在同一 Surface 中打开，不新建标签页。取消后文档保持不变。若文件选择窗口已经打开，不会再打开新的，请先完成选择或取消。macOS 上通过键盘按下文件夹按钮时，文件选择界面可能被文档遮挡，请用鼠标单击。远程工作区的 Markdown 地址栏参见[远程工作](../remote/attach.md)。
- 文档中的链接：其他 Markdown、文件在同一窗格的新标签页中打开，Linux 上会立即切换到该标签页（macOS 上仅鼠标单击的链接会切换到新标签页。通过键盘打开的链接只会在后台新增标签页）；`http(s)://` 则交给浏览器。相对路径以文档所在文件夹为基准。若没有可打开文件的处理器，会显示 **打开文件的方式…** 窗口供选择（远程工作区中只显示可在远程打开的处理器，没有可用处理器时显示通知）。`#标题` 这样的文档内链接，以及脚注编号、返回箭头，只跳转到对应位置。
- 按 **刷新** 键（默认 `F5`）会只重新读取并绘制当前查看的文档。在地址框或搜索框中输入时也可使用。但由于会重新绘制文档，地址框中正在输入的内容、已打开的搜索框和搜索词、选择都会清除，只尽可能恢复原滚动位置。远程工作区中的文档会重新获取远程原文，连接断开时会保留断开标记。大文件会经过下述确认。
- 超过 1 MiB 的文件会通过 **打开大文件？** <!-- en: Open large file? --> 询问一次。确认弹窗显示在该 Markdown Surface 中央；Surface 比弹窗窄时，显示在窗口中央。原本较小的文件后来增长到超过 1 MiB 时，重新读取前也会显示相同确认，回答前保留原内容。取消后，正文位置显示 **此文件大于 1 MiB，尚未加载** <!-- en: This file is larger than 1 MiB and has not been loaded -->。单击下方的 **打开文件…** <!-- en: Open file… --> 按钮会再次显示相同确认。取消过的文件即使更改，也不会自动读取；也可用 `tasty markdown reload --surface <ID>` 再次询问。选择 **打开** 后，不会再询问该文件。

**新建 Markdown…** 或 `Alt+'` > **Markdown** 会打开 **打开 Markdown 文件** <!-- en: Open Markdown File --> 窗口。输入路径，或通过 **浏览…** <!-- en: Browse… --> 选择。浏览从当前查看终端的当前文件夹开始，输入的相对路径也以该文件夹为基准打开。此弹窗显示在该 Surface 区域中央，切换到其他工作区或标签页时会暂时隐藏，返回后保留原输入内容重新显示。通过浏览打开的文件选择窗口也会一同隐藏和返回，并保留选中的文件和正在浏览的文件夹。隐藏期间不会阻止其他界面的单击和键盘输入。

```sh
tasty markdown recent
tasty markdown reload --surface 5
```

## 图像

查看 PNG、JPEG 等图像，并进行简单绘制。**新建图像** 从空白画布开始。即使在已打开图像时创建，也独立于原文件，因此 **保存** 时会询问保存路径。保存到新路径后，标签页名称改为该文件名，重新启动后也会打开该文件。文件被外部更改时，会在 1 秒内自动重新读取，但 **编辑期间会推迟**，直到结束编辑时再更新（避免绘制期间底图变化）。

- 工具栏：**上一张图像** <!-- en: Previous image --> / **下一张图像** <!-- en: Next image -->（在同一文件夹内切换，切换后标签页名称也改为该文件。编辑期间不能切换，请先保存或取消，此时 `tasty image next`、`prev` 也会返回错误）、**刷新** <!-- en: Refresh -->、**编辑** <!-- en: Edit -->、**新建图像** <!-- en: New image -->、缩放 **适应大小** <!-- en: Fit --> / `+` / `-`。
- 单击 **编辑** 后，选择 **笔刷粗细** <!-- en: Brush --> · **颜色** <!-- en: Color -->，即可在图像上绘制。使用 `Ctrl+Z` / `Ctrl+Shift+Z` 撤销和重做。**保存** <!-- en: Save --> 会写入 PNG。修改 JPEG 等非 PNG 文件并保存时，会保留原文件，在同一文件夹中创建同名 `.png`，并切换到该文件。若该 `.png` 已存在，不会覆盖，而是询问保存路径。此时输入框上方会显示文件已存在的说明，输入框中会填入 `名称-1.png` 这样尚不存在的名称，并选中名称部分。
- **另存为** 中的文件夹按钮会打开 Tasty 文件选择窗口。选择 PNG 文件或输入名称并确认后，会填入保存路径。已有文件名会显示覆盖警告。实际文件在图像的 **另存为** 中单击 **保存** 时才写入，取消浏览会保留已输入的路径。
- 无法读取文件时，画布会显示原因：**未找到图像** <!-- en: Image not found -->（显示路径）、**权限被拒绝** <!-- en: Permission denied -->、**无法打开此图像** <!-- en: Can't open this image -->（损坏或不支持的格式，显示解码器消息）、**图像过大，无法打开** <!-- en: Image is too large to open -->（单边超过 16384px，或解码所需内存超过 512MiB 的图像不会打开，并显示实际尺寸）。除过大图像外，其他情况均可单击 **重试** <!-- en: Retry --> 重新读取。文件恢复或更改后，也会自动重新读取。
- 在图像中按粘贴快捷键（默认 `Ctrl+V`），会将剪贴板图像粘贴为浮动选区。剪贴板中没有图像时，不执行操作。`tasty image paste --surface <ID>` 也相同。
- `tasty image list` 会显示 **所有窗口中** 打开的全部图像。
- `tasty image reload --surface <ID>` 无需等待，会立即重新读取。

```sh
tasty image list
tasty image open --surface 5 shot.png
tasty image export --surface 5 out.png
```

## HTML

启用继承当前文件夹时，从 HTML 文件标签页新建标签页或拆分，会以该文件所在文件夹为基准。网址标签页保留原工作文件夹。

无界面服务器上也可用 `tasty html open` 更改 HTML 标签页的请求地址。无界面服务器不绘制页面，远程连接中尚不支持显示 HTML 正文。

使用操作系统的 WebView 显示本地 HTML 文件或 URL。右键单击标签栏空白处 > **新建 HTML…**，会在该窗格的当前文件夹中打开文件选择窗口，只显示文件夹和 `.html`、`.htm`、`.svg` 文件。选择文件后，会在该窗格中打开 HTML 标签页；取消则不创建标签页。远程工作区中不会打开文件选择窗口，而是通知尚无法打开。

- 加载时显示 **正在加载…** <!-- en: Loading… -->，失败时显示 **加载失败** <!-- en: Failed to load --> 和 URL。
- 菜单或弹窗打开期间，Linux 上的 HTML、Markdown 页面保持可见。桌面启用窗口合成（合成器）时，弹窗会按通常样式叠加在页面上，包含圆角、阴影和后方变暗遮罩。未启用合成，或窗口管理器无法对齐弹窗位置时，只有弹窗框所在位置会被直角矩形遮住。全屏或窗口部分位于屏幕外时，可能出现这种情况。Windows 和 macOS 上页面也保持可见，弹窗框使用相同的直角样式。此时单击页面或滚动滚轮，会视为单击弹窗外部，不会传递到页面，按键输入也不会进入页面。Linux 上若 X 服务器不支持形状扩展（SHAPE、XFixes），弹窗打开期间页面会暂时隐藏，只显示空面板。通知卡片出现时，只有与卡片重叠的页面会隐藏，直到卡片消失，其他页面保持可见。正在输入文字的页面不会隐藏，因此其上方的通知卡片会被遮住。
- **设置** > **外观** 中的 **HTML** 项：**默认缩放** <!-- en: Default zoom --> · **配色方案** <!-- en: Color scheme -->（**跟随主题** <!-- en: Follow theme --> / 浅色 / 深色）· **允许远程内容** <!-- en: Allow remote content --> · **在沙箱中运行脚本** <!-- en: Sandbox scripts -->。默认阻止远程内容和脚本。该功能用于查看本地生成的预览，因此打开外部网站时，需要启用 **允许远程内容** 并关闭 **在沙箱中运行脚本**。

### 地址栏

HTML 界面顶部有地址栏。从左到右为 **后退** <!-- en: Back --> · **前进** <!-- en: Forward --> · **重新加载** <!-- en: Reload --> 按钮和地址框。本地文件显示为文件路径（主文件夹显示为 `~`），网页文档显示为 URL。

- 在地址框中输入文件路径或 `file://`、`http://`、`https://` 地址，按 `Enter` 打开。没有单独的转到按钮。
- 相对路径以当前文档为基准解析。本地文件以所在文件夹为基准，网页文档以其地址为基准。空 HTML 标签页使用该标签页的工作文件夹；没有基准时，不会打开，并显示说明。
- 输入不存在的文件时，不会打开，地址框下方会显示 **未找到文件** <!-- en: File not found -->。原页面和输入文字保持不变，输入下一个字符或按 `Esc` 后，说明消失。
- 编辑时按 `Esc` 会取消输入，恢复当前文档地址。在 HTML 地址框中输入期间，按键用于地址输入，不会传递到页面、终端或其他 Tasty 快捷键。但指定为复制、剪切、粘贴、全选、网页撤销或重做的按键，会对地址输入执行相应编辑；转到地址栏和刷新的按键也会生效。同一按键有多项绑定时，按编辑、转到地址栏、刷新的优先顺序，只执行一项。
- 在地址框中按 `Tab`、`Shift+Tab`，会在可用的 **后退**、**前进**、**重新加载** 按钮和地址框之间依次切换，按钮会显示边框。按 `Enter` 或 `Space` 激活该按钮，按 `Esc` 退出。移至按钮时，正在输入的文字会恢复为原地址；返回地址框时，会选中完整地址。按下的按钮变灰或变为加载指示器时，按钮会失去焦点。
- 按 `Alt+L`（macOS 为 `Cmd+L`）会将焦点移至当前获得焦点的 HTML 界面的地址框，并选中完整地址。在页面内输入时也有效。按键可在 **设置** > **按键绑定** > **Surface** 的 **将焦点移至地址栏** <!-- en: Focus the address bar --> 中更改，与文件浏览器地址栏使用相同按键。
- 加载期间，重新加载按钮位置会显示旋转指示器；加载失败时，地址框保留尝试打开的地址。
- 位于历史记录起点时后退按钮变灰，位于终点时前进按钮变灰。HTML 界面宽度小于 440px 时，前进按钮隐藏。
- 空 HTML 标签页会同时显示地址框说明和快捷键。通过地址栏打开的文档，重新启动后会恢复为创建时的地址（空标签页则恢复为空标签页）。智能体通过 `tasty html open` 打开的地址也相同。
- 远程工作区的 HTML 标签页没有地址栏。

### 远程内容被阻止的文档

关闭 **允许远程内容** 时，查看使用网络样式表、图像、字体等内容的本地文档，会在地址栏下方显示 **此文档中的远程内容已被阻止** <!-- en: Remote content in this document is blocked --> 说明。由于不加载远程内容，页面可能没有样式。与脚本说明一样，不会遮住页面，而是将页面向下推移相应高度。

- **允许远程内容** <!-- en: Allow remote content -->：仅允许此文档加载远程内容，并重新加载一次。转到其他文档、文件内容更改或重新启动 Tasty 后，会再次阻止。与允许脚本相互独立。文档加载期间不能单击。
- 通过 **×** 关闭说明或允许远程内容后，地址框最右侧会保留地球图标。被阻止的文档显示带斜线的地球，单击会重新显示说明（仅单击不会允许）。已允许的文档显示地球，悬停只会说明已允许。
- 远程内容和脚本均被阻止时，两条说明会分别堆叠，顺序为远程内容 → 脚本。
- 智能体打开的文档，会在人查看该标签页时显示说明。智能体可用 `tasty surface html-remote-allow` 允许已查询文档的远程内容。
- 启用 **允许远程内容** 设置后，所有文档都会加载远程内容，不显示说明和图标。远程工作区的 HTML 标签页没有此说明。

### 脚本被阻止的文档

启用 **在沙箱中运行脚本** 时，查看含脚本的文档，会在页面上方显示 **此文档中的脚本已被阻止** <!-- en: Scripts in this document are blocked --> 说明。说明不会遮住页面，而是将页面向下推移相应高度。说明文字会完整显示，不会截断；界面较窄、文字换行增多时，说明会增高，页面也随之继续下移。HTML 界面较窄时，按钮会移到描述下方一行。

- **对此文档允许** <!-- en: Allow for this document -->：仅为此文档启用脚本，并重新加载一次。转到其他文档或重新启动 Tasty 后，会再次阻止。已允许文档的标签页会附有脚本文件图标。
- 界面加载新文档期间，不能单击 **对此文档允许**。悬停按钮会显示 **文档加载完成后可用** <!-- en: Available when the document finishes loading -->。通过链接、后退或重新加载直接打开的文档若有脚本，按钮会重新启用；若没有脚本，说明会消失。智能体打开的文档，会在再次查看该标签页时显示说明。对于极大文件，即使界面已经打开，Tasty 检查整个文件期间，按钮仍可能暂时禁用。此检查不会暂停其他终端和界面。重新加载已允许脚本的文档时，检查结束后才显示新文档。
- 说明右上方的 **×**：只关闭说明，不允许脚本。标签页标题后会保留锁图标，单击锁会重新显示说明。单击锁不会切换标签页。
- 智能体打开的文档，或通过会话恢复重新打开的文档，会在人查看该标签页时显示说明。智能体也可先查询状态，再用 `tasty surface html-script-allow` 允许该文档的脚本。若查询后文档已更改，或仍在加载，则不会允许。允许后，当前查看的标签页和焦点保持不变。
- 文档加载失败、显示 **加载失败** <!-- en: Failed to load --> 期间，说明以及标签页上的锁、脚本图标都会消失。重新加载的文档打开后，会根据该文档重新确定。

```sh
tasty html open --surface 5 ./dist/index.html
tasty new tab --pane 1 --type html --url http://localhost:3000
tasty surface html-script --surface 5   # 查询脚本检测结果、允许状态及说明状态
tasty surface html-script-allow --surface 5 --url <url> --fingerprint <hex>   # 允许已查询文档的脚本
tasty surface html-remote-allow --surface 5 --url <url> --fingerprint <hex>   # 允许已查询文档的远程内容
```

## Git 视图

单击侧边栏 **工具** > **Git**，会打开一个窗口，以只读方式显示当前终端目录中的仓库。

- **更改** <!-- en: Changes -->（status）· **提交** <!-- en: Commits -->（log）· 单击文件时显示 **Diff**。
- 在左侧 **工作树** <!-- en: Worktrees --> 列表中选择其他 worktree，可基于该工作树查看。实际 checkout 不变。
- 单击 **刷新** <!-- en: Refresh --> 更新外部更改。不提供提交、暂存等写入操作。
- **打开 Git 查看器** <!-- en: Open Git Viewer --> 快捷键在 **设置** > **按键绑定** > **插件** <!-- en: Plugins --> 中指定（无默认值）。

若当前目录是 Git 仓库，可独立于此窗口，在状态栏查看分支名称（[初识界面](../getting-started/first-look.md#状态栏)）。

## 空 Surface

文件已关闭或尚未指定种类的位置会保留为 **空** <!-- en: Empty -->，中央显示种类选择按钮。单击后与[更改种类](panes-tabs-splits.md#更改种类)弹窗相同。

文件浏览器内置于 Tasty，Markdown、图像、HTML、Git 视图为捆绑插件。关闭插件后，无法打开对应种类，参见[插件](../plugins/index.md)。
