# 랜딩

## 제품 소개 페이지

- 사이트 소스: [영어 진입점](../../src/pages/index.astro) · [한국어 진입점](../../src/pages/ko/index.astro) · [페이지 구성](../../src/components/Landing.astro) · [콘텐츠](../../src/lib/i18n/index.mjs) · [제품 예시](../../src/components/AppShell.jsx)
- 역할: 처음 방문한 사용자가 터미널의 쓰임을 이해하고 설치하거나 관련 가이드로 이동하는 진입점.
- 보여 줄 항목: 제작자의 취향을 드러내는 첫 제목, 일상 작업과 AI 에이전트에 함께 쓰는 터미널임을 밝히는 표어, 터미널의 용도와 여러 에이전트의 동시 실행, 지원 플랫폼, 설치 파일 선택, 프로젝트별 워크스페이스, 두 단계 분할, 문서 보기, 맞춤 설정, CLI와 에이전트 연동. GPU 가속 설명은 첫 화면이 아니라 공통 푸터와 검색·공유 소개에 둔다.
- 구성 순서: 제품 소개와 조작 가능한 화면 예시 → 두 단계 배치 → 일상 기능 → CLI·에이전트 → 플랫폼·설치 → 설치 진입.
- 제품 예시: 탭과 메뉴를 살펴보는 화면이며 표시된 명령의 실제 실행 여부를 알 수 있게 한다.
- 배치 예시: 독립 탭 바를 가진 페인과 같은 탭에서 함께 전환되는 서피스의 차이, 작업 터미널·테스트 로그·문서의 병치를 보여 주고 배치 실습으로 연결한다.
- 일상 기능: 워크스페이스, 프리셋 재사용, 파일 관리·뷰어, 출력 검색·복사, 단축키, 테마의 여섯 항목을 각 가이드로 연결한다. 스크립트·원격·플러그인은 보조 진입점으로 둔다.
- CLI·에이전트: 에이전트가 다른 에이전트를 실행해 작업을 나누는 기능, CLI로 추가 지시·명령을 보내고 출력을 읽는 조작, 외부 CLI·플러그인·훅의 조건, 상태 조회 예시, 응답 종료와 성공의 차이를 보여 준다. 작업 분담 방법과 알림 조건은 연동 가이드로 넘기고, CLI 입문·연동·작업 순서 가이드로 연결한다.
- 플랫폼·설치: OS·아키텍처별 선택 조건, Apple Silicon 지원, 설치 가이드와 릴리스 파일 진입점을 보여 준다. 표시 버전은 공개 릴리스 정보를 사용한다.
- 넣지 않을 항목: 전체 API·명령 참조, 성능 순위·비교 수치, 고정 성공 출력, 자동 성공·무중단 보장, 제작자 이야기 전용 구역, 디자인 시스템 상세, 앱 내부 예시의 문구 변경안.
