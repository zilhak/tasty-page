# ファイルの管理と表示

エクスプローラーでファイルを探して管理し、ターミナルの横でマークダウン・画像・HTML を表示できます。Git 表示では変更を確認します。ビューアと Git 表示には、それぞれのプラグインが有効になっている必要があります。

## 開く方法

| 場所 | 方法 |
|--------|--------|
| サイドバーの **ツール** <!-- en: Tools --> > **ファイルを開く…** <!-- en: Open File… --> | Tasty 独自のファイル選択ウィンドウです。現在表示しているターミナル・エクスプローラーのフォルダーで開き、リモートワークスペースではリモートファイルを表示し、選んだリモートファイルはそのリモートワークスペースで開きます |
| ファイルをウィンドウにドラッグ | **ドロップして開く** <!-- en: Drop to open --> が表示されたらドロップしてください。エクスプローラーの領域にドロップすると、開かずにそのフォルダーへコピーします（[ドラッグして移動](#ドラッグして移動)） |
| エクスプローラーサーフェス | ファイルをダブルクリックしてください |
| ターミナル | `Ctrl+クリック`、またはパスを選択して右クリック > **ファイルを開く** <!-- en: Open File -->（[ターミナルの操作](terminal.md#リンクとパスを開く)） |
| タブストリップの空白部分を右クリック | **新規マークダウン...** <!-- en: New Markdown... --> · **新規エクスプローラー** <!-- en: New Explorer --> · **新規HTML...** <!-- en: New HTML... --> · **新規画像** <!-- en: New Image --> |
| `Alt+'` | 現在のサーフェスを別の種類に変更します（[種類を変更する](panes-tabs-splits.md#種類を変更する)） |
| CLI | `tasty new tab --pane 1 --type markdown --file README.md` など |

ファイルの拡張子によって、どのサーフェスで開くかが決まります — `.md` はマークダウン、画像ファイルは画像、`.html` と `.svg` は HTML、フォルダーはエクスプローラーです。どれで開くか決まっていない場合は **次で開く…** <!-- en: Open file with… --> ウィンドウで選択でき、選んだものは **最近の選択** <!-- en: Recent --> に残ります。拡張子のマッピングとハンドラは **設定** > **ハンドラ** <!-- en: Handler --> タブで変更します。

ハンドラタブのファイル形式・関連付け設定は、**保存** を押すとすぐに適用され、ファイルにはバックグラウンドで保存されます。保存できない場合は警告と通知に原因が表示され、変更は Tasty を終了するまでだけ維持されます。外部で編集された元のファイルや破損した元のファイルは上書きしないため、ファイルを確認して Tasty を再起動してから、もう一度変更してください。起動時にこの設定を読み取れない場合は、ログにファイル名と問題の種類が残り、ファイルの内容は記録されません。

**次で開く…** ウィンドウには、ファイルパス、認識した形式、選択できるハンドラが表示されます。各ハンドラにはアイコン、名前、提供元（**標準搭載** <!-- en: built-in --> · **自分** <!-- en: you --> · **プラグイン**）が表示されます。

**最近の選択** には、以前使ったハンドラと使用した時点が表示されます。たった今・数分前・数時間前・昨日・数日前で表示され、1 週間を超えると `2026-09-13` のような日付に変わります。ウィンドウを開いたまま日付をまたいでも表示が更新されます。

1 回クリックするとハンドラを選択し、2 回クリックするとファイルを開きます。この選択は **今回だけ** 適用され、ファイル形式の既定のハンドラには登録されません。同じファイルを再び開くときに選択ウィンドウが表示される場合があります。既定のハンドラは **設定** > **ハンドラ** で指定してください。ウィンドウは `Esc` または **キャンセル** <!-- en: Cancel --> で閉じます。

上記の方法で直接開いたファイルは、新しいタブで開き、**そのタブに切り替わります。** AI エージェントが代わりに開く場合は、タブが増えるだけで、表示していたタブはそのまま残ります — 作業中の画面が突然切り替わらないようにするためです。

開く操作を要求したサーフェスが指定されている場合は、待っている間に別のウィンドウへ移動しても、元のサーフェスのペインに新しいタブで開きます。別のペインを表示しているときにエクスプローラーからファイルを開いても、エクスプローラーのあるペインで開きます。元のサーフェスを閉じた場合は、別のウィンドウに代わりに開くことはありません。

ファイルから開いたサーフェスも、ほかのサーフェスと同じように分割・移動・閉じる操作・再起動時の復元の対象です。タブ名はファイル名になります。

ファイル選択ウィンドウは、一番上の行（タイトルと ✕ がある行）をドラッグして移動します。✕、**キャンセル** <!-- en: Cancel -->、`Esc` のいずれかで閉じると、ファイルは何も開きません。

ファイル選択ウィンドウの一覧の上には名前・サイズ・更新日時の列名があり、選択した行の左端には色付きのバーが付きます。長いファイル名は `…` で省略し、サイズ・更新日時に重ならないように表示します。省略表示されても、選択したり開いたりするファイルは変わりません。

ファイルの種類を指定して開いた場合（例: キーバインドのインポートでは `.toml` のみ）は、名前欄の右に `*.toml` のように表示する拡張子を記した欄があります。拡張子が多い場合は末尾が `…` で省略され、マウスを合わせると一覧全体が表示されます。この欄は案内用で、クリックして変更することはできません。種類を指定せずに開いた場合、この欄はありません。

一覧で 1 回クリックすると、ファイルでもフォルダーでもその行が選択され、2 回クリックするとフォルダーはその中に入り、ファイルは開きます。フォルダーを選択したまま **開く** <!-- en: Open --> を押すと、そのフォルダーに入ります — キーボードで下の階層へ進む方法です。保存先を選ぶときはフォルダーを保存対象にできないため、フォルダーを選択しても名前欄はそのままで、下にそのことを知らせる灰色の行が 1 行表示されます。保存時にファイルをダブルクリックしても、名前が入力されるだけで保存はされません — 上書きの警告を読む機会を残すためです。

ファイルの選択中は、新しい選択要求は案内とともに拒否されます。既存のファイル選択ウィンドウで選択を完了するかキャンセルしてから、もう一度開いてください。

## エクスプローラー

Tasty に内蔵されているファイルマネージャーです。ターミナルで `Alt+'` > **エクスプローラー** に切り替えると、そのターミナルの現在のディレクトリをルートとして開きます。`tasty new tab --pane 1 --type explorer --path ~/proj` でも開きます。`--path` の代わりに `--cwd ~/proj` を指定しても、そのフォルダーをルートとして開きます。

### 画面

- **左側** — **ファイル** <!-- en: Files --> ツリー（ルート固定）と、その下の **お気に入り** <!-- en: Favorites --> です。
- **上側** — **戻る** <!-- en: Back --> · **進む** <!-- en: Forward --> · **上へ** <!-- en: Up --> · **更新** <!-- en: Refresh -->、アドレスバー、**新しいフォルダー** <!-- en: New folder --> · **新しいファイル** <!-- en: New file --> ボタンと、**検索** <!-- en: Find --> · **プレビューパネル** <!-- en: Preview panel --> · 隠しファイル（目の形）の切り替え、表示切り替え（**グリッド** <!-- en: Grid --> · **リスト** <!-- en: List --> · **詳細** <!-- en: Detail -->）です。エクスプローラーの領域が 440px より狭い場合、コマンドボタンは **その他** <!-- en: More -->（`…`）1 つに折りたたまれ、押すと同じコマンドがメニューに表示されます。メニューの検索・プレビューの行には、押すと実行する操作が表示されます（**検索** ↔ **検索を閉じる** <!-- en: Close find -->、**プレビューを表示** <!-- en: Show preview --> ↔ **プレビューを隠す** <!-- en: Hide preview -->、**隠しファイルを表示** <!-- en: Show hidden files --> ↔ **隠しファイルを非表示** <!-- en: Hide hidden files -->）。隠しファイルの切り替えは、隠しファイルを表示している間は押された状態になり、マウスを合わせると操作とショートカットが一緒に表示されます（例: **隠しファイルを表示（Ctrl+Shift+.）**）。
- **右側** — 現在のフォルダーの項目です。グリッド表示では、ローカルの画像ファイル（1 MiB 以下）がアイコンの代わりに小さなサムネイルで表示されます。一番上の `..` で上位フォルダーに移動します。詳細表示では **名前** · **サイズ** · **更新日時** · **種類** の列見出しをクリックして並べ替えます。種類の列には「Markdown」「PDF 文書」「圧縮ファイル」「PNG 画像」のように種類が単語で表示され（表にない形式は「RS ファイル」）、リンクには「Markdown リンク」のようにリンク先の種類が表示されます。プロパティのポップアップとプレビューのヘッダーにも同じ単語を使い、種類で並べ替えると同じ種類がまとまり、.gz と .zip のような圧縮ファイルが並びます。
- サーフェス内に **新しいタブ** <!-- en: New tab --> を複数置いて、フォルダーを別々に表示できます。ペインのタブとは別です。

内部タブを切り替えて戻ると、選択した項目、一覧と左側のファイルツリーのスクロール位置、検索バーの検索語・サブフォルダーの検索結果がそのまま残ります。同じフォルダーを開いた 2 つのタブも、それぞれ記憶します。別のタブを表示している間に完了した読み取りや検索は、開始したタブだけに反映されます。タブを閉じるとこの状態は破棄され、アプリを開き直したときはフォルダー・表示・並べ替えだけを復元し、選択と検索は初期状態から始めます。

リモートエクスプローラーも、同じ接続でサーバーのフォルダーが変わっていなければ、ワークスペースの更新後も内部タブと閲覧位置を維持します。サーバーがフォルダーを変えたり、接続を新たに確立したりすると、サーバーから通知されたフォルダーの新しいタブで始まります。

エクスプローラーを含む配置をプリセットとして保存して適用すると、エクスプローラー内の各タブで表示していたフォルダーが同じ表示・並べ替えで開き、ペインのタブタイトルはアクティブなタブが開いたフォルダー（ルート）の名前になります。プリセットの編集で作業ディレクトリを指定している場合は、保存したタブの代わりにそのフォルダー 1 つを開きます。保存したフォルダーが現在存在しない場合は、そのタブに読み取りエラーの案内が表示されます。

分割線をドラッグしてエクスプローラーの領域を縮めると、ツールバー・ステータス行と一覧の 2 行ほどが残る高さ（180px）で止まります。エクスプローラーの領域を分割するときや、分割して新しいエクスプローラーを作るときも、エクスプローラーの領域が 180px を保つように分割線が片側へ移動します。別の種類の領域には残りの高さが割り当てられますが、タブ行と 1 行が入る高さ（56px）より薄くは分割されません。エクスプローラー同士が 180px を保つ空間がない場合や、別の領域が 56px を保つ空間がない場合は分割せず、分割メニュー・ショートカットでは「このパネルを分割するための空間が足りません」という通知が一時的に表示され、`tasty split` はその理由をエラーとして知らせます。領域が低くなり、左側のサイドバーが 240px より低くなると、お気に入りは隠れ、ファイルツリーだけが表示されます。ウィンドウを縮小すると、この高さより低くなる場合もあります。コンテンツ領域が 120px より低い場合は、空のフォルダー・アクセス拒否・読み取りエラーの案内が、アイコン・タイトル・ボタンの 1 行に変わり、詳しい理由はタイトルにマウスを合わせると表示されます。

フォルダーを読み取れない場合（パスがなくなった、フォルダーではない、リモートでの読み取りに失敗した場合）は、一覧の位置に **このフォルダーを読み取れません** <!-- en: Can't read this folder --> と OS から通知された理由が表示されます。**再試行** <!-- en: Retry --> は同じフォルダーを読み直し、**上の階層へ** <!-- en: Go up --> は 1 つ上のフォルダーに移動します。上のフォルダーもなくなっている場合は、残っている最も近い上位フォルダーに移動します。権限がない場合は、別途 **アクセス拒否** <!-- en: Permission denied --> が表示されます。

エクスプローラーで貼り付け・名前変更・ゴミ箱への移動を行うと、変更されたフォルダーを表示しているほかのエクスプローラーも（別のウィンドウでも）、一覧と左側のツリーを読み直します。表示していたフォルダーが削除されたり名前が変わったりした場合は、その場で読み取りエラーの案内が表示され、別のフォルダーへ自動で移動することはありません。別のプログラムがフォルダー内に項目を作成・削除・名前変更すると、現在使用している Tasty ウィンドウのフォーカスがあるタブのエクスプローラーが 2 秒以内に検知し、一覧と展開済みのツリーを読み直します。このとき選択とスクロール位置はそのままです。別のタブにあるエクスプローラーや、別のアプリを使用している間のエクスプローラーは、そのタブや Tasty ウィンドウに戻った時点で確認します。ファイルの内容やサイズ、権限だけが変わった場合と、リモート（attach）エクスプローラーには自動で反映されないため、**更新**（`F5`）を押してください。開いているフォルダー内のファイルのサイズ・更新時刻の変更まで自動で反映するには、**設定** <!-- en: Settings --> > **一般** <!-- en: General --> > **エクスプローラー: ファイル情報を自動更新** <!-- en: Explorer: refresh file details --> を有効にしてください。有効にするとサイズ・日付の列とプレビュー・サムネイルが数秒以内に新しい値に変わりますが、確認するたびにそのフォルダーの全項目を読み取るため、低速なドライブや項目が非常に多いフォルダーでは無効のままにしておくほうがよいです。既定では無効で、展開済みのツリーフォルダー内のファイルは、有効にしても確認しません。ツリーを非常に多く展開している場合は、一度にすべてを確認せず、数回に分けて順番に確認するため、深いフォルダーの変更は少し遅れて表示される場合があります。更新では展開済みのツリーも一緒に読み直します。ローカルエクスプローラーがフォルダーの一覧を表示しているときは一覧を空にしないため、選択とスクロール位置がそのままです。リモート（attach）エクスプローラー、エラー案内の **再試行**、読み取り中に押した更新では、一覧を空にして最初から読み直します。読み直したときに選択していた項目がなくなっていれば、その項目は選択からも外れます。

アドレスバーをクリックするとパスを直接入力でき、最近訪問したフォルダーが自動補完に表示されます。候補をクリックするか、方向キーで選んで `Enter` を押すと、そのフォルダーに移動します。`Enter` または **移動** <!-- en: Go --> で移動します。左側のツリーはルートに固定されますが、右側の一覧はどこにでも移動できます。ファイルパスを入力すると、ファイルを開かずにそのファイルが入っているフォルダーへ移動し、そのファイルを選択します。リモートエクスプローラーも同じです。

字母やアクセントが分離して保存された名前は、画面では合成して表示します。このように表示していたアドレスを編集すると、元のパス全体が選択されます。同じ見た目のファイルが 2 つあっても、コピーと移動にはそれぞれの実際の名前をそのまま使います。

- 相対パスは現在表示しているフォルダーが基準です。`..` は 1 つ上の階層です。
- `~` と `~/フォルダー` はホームフォルダーの配下です。
- Windows では `C:` のようにドライブだけを入力するとそのドライブの最上位へ移動し、`\\サーバー\共有` のようなネットワークパスも使えます。
- 存在しないパスを入力すると、移動せずに理由を通知で表示します。リンク先がなくなったリンクはファイルと同じように、そのリンクが入っているフォルダーに移動してリンクを選択します。
- リモートワークスペースのエクスプローラーでは、入力したパスをリモートコンピューターで探します。ローカルにないフォルダーもリモートにあれば開き、リモートで読み取れない場合は一覧の位置に理由が表示されます。`~` はリモートコンピューターのホームフォルダーで、`.` と `..` もリモートのパスを基準に解決します。接続直後にリモートのホームをまだ取得できていない場合は、`~` の代わりにリモートのパス全体を入力するよう案内します。リモートのパスがファイルか確認している間、アドレスバーには入力したパスがそのまま表示され、確認が長引くとアドレスバーの末尾に回転する表示が出ます。このとき `Esc` を押すと確認を中止し、アドレスバーが現在のフォルダーに戻ります。

Linux X11 では、ハングルなどの文字を合成している間に一覧の移動・開く・選択解除・名前変更・ゴミ箱のキーを押すと、先に文字の合成を処理します。同じキー操作でファイルを移動したり開いたりはしません。合成が終わってからもう一度押したキーは、通常どおり動作します。検索入力欄でも、合成を終える `Esc` は検索語を消さず、次の `Esc` から通常どおり動作します。エクスプローラーの項目の名前変更ポップアップでは、合成を終える `Enter` は文字だけを確定し、ポップアップは開いたままにします。名前を変更するには、`Enter` をもう一度押すか **保存** <!-- en: Save --> ボタンを押してください。検索のほかのキーとパス入力欄には、その入力欄のキー処理が適用されます。

名前変更は入力欄で `Enter` または **保存** <!-- en: Save --> ボタンで確定し、`Esc` でキャンセルしてください。アプリを最初に開いた後も、別のウィンドウに切り替えて戻る必要なく、そのまま確定できます。

### 新しいフォルダー・新しいファイル

ツールバーの **新しいフォルダー** · **新しいファイル**、空白部分の右クリックメニュー、フォルダーの右クリックメニュー（そのフォルダー内に作成します）から開始します。一覧の一番上に名前の入力行が開きます。フォルダーの右クリックメニューから開始すると、そのフォルダーのすぐ下（グリッドではフォルダーの次のマス）に開き、行が少し字下げされ、入力欄の後ろに **{フォルダー} 内** <!-- en: in {folder} --> が付き、そのフォルダーが強調されます。表示していたフォルダーは変わりません。入力行では「新しいフォルダー」は名前全体が、「無題.txt」は拡張子の前までが選択されています。同じ名前がある場合は、「新しいフォルダー 2」のように番号が付いた名前で始まります。

- `Enter` で作成し、`Esc` でキャンセルします。キャンセルすると、ディスクには何も作成されません。
- 入力行の外をクリックすると、名前が有効なら作成し、空または無効ならキャンセルします。
- 名前が空（空白だけの名前も含みます）、使用できない文字（`/`、Windows では `\ : * ? " < > |` も）が含まれる、名前の先頭や末尾が空白、Windows の予約名（`CON`、`NUL` など）、Windows で名前の末尾がピリオドの場合は、入力欄の下にすぐ理由が表示されます。既存の名前は `Enter` を押したときに通知され（macOS・Windows では大文字と小文字だけが違う名前も既存の名前です）、入力行は開いたまま、文字もそのまま残ります。上書きはしません。
- 作成した項目は並べ替えられた位置に移動して選択されます。その間に別のフォルダーへ移動したり別の項目を選んだりした場合は、選択は変わりません。
- 書き込めないフォルダーでは両方のボタンが薄くなり、マウスを合わせると **このフォルダーには書き込めません** <!-- en: Can't write to this folder --> が表示されます。フォルダーの右クリックメニューで書き込めないフォルダー内に作成しようとすると、入力行は開かず、同じ案内が表示されます。リモートワークスペースのエクスプローラーでも使えます。リモートコンピューターの Tasty が古いバージョンの場合は、このボタンとメニュー項目がありません。

エクスプローラーにフォーカスがあるときは、`F7` で新しいフォルダー、`Shift+F4` で新しいファイルを作成します。macOS は既定の設定では F キーがメディアキーなので、`Fn` を一緒に押してください。キーは設定 > キーバインド > **エクスプローラー** <!-- en: Explorer --> で変更します。

### 検索・サブフォルダーの検索

ツールバーの **検索** の切り替え（領域が狭い場合は **その他** メニュー）、またはエクスプローラーにフォーカスがあるときの `Ctrl+F` で、ツールバーの下に検索行を開きます。`Ctrl+F` はターミナル検索と同じショートカットで、エクスプローラーではこの検索行を開きます。

- 入力するとすぐに、現在のフォルダーで名前にその文字が含まれる項目だけが残ります。大文字と小文字は区別せず、一致部分は強調色で表示されます。右側には「2 / 6」のように表示数と総数が出ます。一致する名前がない場合は、一覧の位置に「“…” に一致する名前がありません」と表示されます。上のフォルダーに移動する `..` 行は、絞り込み中も残ります。
- 絞り込みで見えなくなった項目は選択から外れます。全選択でも表示されている項目だけを選びます。
- **サブフォルダー** <!-- en: Subfolders --> を有効にすると、現在のフォルダーの配下全体で検索します。検索中は結果が届くたびに追加され、**停止** <!-- en: Stop --> で停止できます（見つかった結果は残ります）。詳細表示では種類の代わりに **フォルダー** <!-- en: Folder --> 列に現在のフォルダーを基準とした場所が表示され、リスト・グリッド表示では項目にマウスを合わせると表示されます。結果を 1 つ選ぶと、下のステータス行にも場所が表示されます。読み取れないフォルダーはスキップし、「フォルダー 1 個をスキップ」のように通知し、マウスを合わせると該当するフォルダーが表示されます。結果が 5,000 個に達すると検索を停止し、「5,000 個以上見つかりました · 停止しました」と表示します。見つかった結果は残り、検索語を追加入力すると範囲を絞れます。フォルダーのリンク内には入りません。結果の項目を名前変更・移動・削除すると、どのエクスプローラーで行っても検索を最初からやり直して結果を更新します。
- 検索欄で `Esc` を 1 回押すと文字を消し、もう 1 回押すと検索行を閉じます。× や別のフォルダーへの移動（戻る・上へ・アドレスバー・フォルダーを開く）でも閉じます。
- 検索欄に文字を入力している間は、文字を入力して探す機能とエクスプローラーのショートカットは動作しません。
- 拡張子で検索するには、同じ欄に `ext:rs` を入力してください。`ext:rs ext:md` は rs または md ファイルを検索し、`note ext:rs` は名前に note が含まれる rs ファイルを検索します。フォルダーは除外し、最後の拡張子だけを見ます。大文字と小文字は区別せず、`EXT:.RS` も同じです。拡張子は文字・数字・アンダースコア・ハイフンで記述してください。空の `ext:` や `ext:*`、`ext:rs,md` は通常の名前の文字として検索し、ワイルドカード・引用符の構文はありません。拡張子の条件と一緒に書いた残りの名前は、単語の間を空白 1 つでつないだ部分文字列として検索します。名前の条件だけが強調されます。
- 検索中にツールバーや空白部分のメニューから新しいフォルダー・新しいファイルを作成したり、通常の貼り付けをしたりすると、検索を開始したフォルダーに入ります。検索条件に一致すると結果に再表示されます。フォルダーを指定したメニューや **貼り付け（中へ）** は、指定したフォルダーを使います。
- リモートワークスペースのエクスプローラーは現在のフォルダーの絞り込みだけを行い、サブフォルダーの検索はありません。

### プレビューパネル

ツールバーの **プレビューパネル** ボタンを押すと、一覧の右側にパネルが開き、選択したファイル 1 つを表示します。テキストファイルは先頭部分（64 KB）を等幅フォントで、画像はパネルに合わせて（元のサイズより拡大せずに）表示します。それ以外の形式やフォルダーには **このファイル形式はプレビューできません** <!-- en: No preview for this file type -->、1 MiB より大きいファイルや、1 辺が 16384 ピクセルを超えるなど展開するには大きすぎる画像には **大きすぎてプレビューできません** <!-- en: Too large to preview --> が表示されます。画像がピクセル数の上限を超える場合は、その画像の実際のサイズも一緒に表示されます。ファイルを複数選ぶと、選択数を表示し、1 つだけ選ぶよう案内します。パネルの左端をドラッグすると、幅を 200~460px の間で変更できます。有効な状態と幅はエクスプローラーごとに記憶され、Tasty を開き直してもそのままで、プリセットとして保存した場合も引き継がれます。エクスプローラーの領域が狭く、一覧と一緒に配置できない場合は、ボタンは有効なままパネルだけが一時的に隠れます。パネルのヘッダーの下に残った高さが 120px 未満の場合は、ファイル名・種類・サイズだけが残り、本文とヘッダーの下の区切り線は隠れます。リモートワークスペースのエクスプローラーではプレビューできません。キーボードで移動した現在の項目の枠線は、プレビューパネルに入り込まず、ファイル一覧の中に表示されます。

### 隠しファイル

名前がピリオド（`.`）で始まるファイルとフォルダー、および Windows で隠し属性を付けた項目と macOS で非表示フラグ（`chflags hidden`）を付けた項目は、最初は一覧に表示されず、下のステータス行に **非表示 {n}** <!-- en: {n} hidden --> のように非表示の数が表示されます。`Ctrl+Shift+.`（macOS は `Cmd+Shift+.`）を押すか、**その他** メニューの **隠しファイルを表示** を選ぶと一緒に表示され、隠し項目は名前とアイコンが薄い文字色で表示されます。同じ方法で再び非表示にします。有効な状態はエクスプローラーごとに記憶され、Tasty を開き直してもそのままで、プリセットとして保存した場合も引き継がれます。左側のフォルダーツリーも同じ設定に従います。サブフォルダーの検索もこの設定に従います。隠しファイルの表示を無効にすると隠しフォルダー内に入らず、設定を変えると同じ検索を最初からやり直します。リモートワークスペースのエクスプローラーは、リモートコンピューターの隠し属性・非表示フラグにも従います。リモートコンピューターの Tasty が古いバージョンの場合は、名前の先頭のピリオドだけを見ます。

### プロパティ

右クリックメニューの一番下の **プロパティ** <!-- en: Properties --> を選ぶと、エクスプローラーの領域内にポップアップが開きます。ファイルとフォルダーは、種類・サイズ・更新日時・作成日時・パス・権限を表示します。**パス** <!-- en: Path --> は項目自身の絶対パスで、横のコピーボタンでコピーできます。フォルダーは配下の項目数とサイズをバックグラウンドで集計している間、進行状況の表示が回転し、読み取れないフォルダーがある場合はサイズの下に **一部のフォルダーを読み取れませんでした** <!-- en: Some folders couldn't be read --> と表示します。ポップアップを閉じると集計を停止します。時刻はこのコンピューターのタイムゾーンで表示され、**設定** > **一般** の **プロパティの日時形式** で、分まで・秒まで・秒 + UTC オフセットから選びます。

項目を 1 つ表示している場合は、下の **開く** <!-- en: Open --> ボタンが一覧で Enter を押した場合と同じようにその項目を開きます。ファイルはハンドラ設定に従い、フォルダーはそのエクスプローラーで中に入り、ポップアップは開いたまま残ります。リンク切れの場合はボタンが薄くなります。

このコンピューターのファイルまたはフォルダー 1 つは、**権限** <!-- en: Permissions --> の横の **編集** <!-- en: Edit --> で権限を変更できます。macOS・Linux では所有者・グループ・その他の読み取り・書き込み・実行にチェックを入れ、Windows では **読み取り専用** <!-- en: Read-only --> 属性だけを変更します。**適用** <!-- en: Apply --> を押すと変更され、その項目だけに適用し、フォルダー内の項目はそのままにします。setuid・setgid・sticky のような特殊ビットもそのままです。変更できない場合はボックスに理由が表示され、実際の権限を読み直して表示します。エクスプローラーの領域が狭い場合は、ボックスが切れないように役割名をチェックボックスの上の行に移し、さらに狭い場合は読み取り・書き込み・実行を、名前付きのチェックボックスで 1 行ずつ並べます。所有者でない場合（管理者権限で実行している場合を除きます）は、編集ボタンの代わりに所有者だけが変更できるという案内が表示されます。リンク、複数の項目、リモート項目の権限は変更できません。

リンクはリンク先と、リンク先の種類・サイズ・更新時刻、リンク自身のパスを表示します。リンク先もコピーできます。リンク先がないリンクは **リンク切れ** <!-- en: Broken link --> と表示し、リンク先の下に **リンク先が見つかりません** <!-- en: Target not found --> と表示します。リンクの下には、リンクを削除したり名前を変えたりしてもリンク先はそのままであるという案内が表示されます。権限エラーなどで読み取れない場合は、理由と **再試行** <!-- en: Retry --> ボタンが表示されます。

複数の項目を選ぶと個数・種類・合計サイズ・共通の場所を、空白部分を右クリックすると現在のフォルダーを表示します。選択した項目の一部を読み取れない場合は、読み取れた項目だけを集計して表示し、種類の下に **一部の項目を読み取れませんでした** <!-- en: Some items couldn't be read --> と表示します。どれも読み取れない場合は、上記の再試行画面が表示されます。フォルダーとその中の項目を一緒に選んでも、内部の項目は 1 回だけ集計し、ハードリンクでつながった同じファイルのサイズも 1 回だけ加算します。リモートエクスプローラーでは一覧にある種類・サイズ・更新日時・パスだけが表示され、リモートの一覧にはフォルダーのサイズがないため、フォルダーが混ざった合計サイズは — で表示します。

右クリックメニューでショートカットが割り当てられたすべての項目は、最初のショートカットを右側に表示します。**元に戻す**・**やり直し** も同じ規則に従い、設定でショートカットを変更したりすべて削除したりすると、メニューの表示もそれに合わせて変わります。

クリックで選択、`Ctrl+クリック` で追加、`Shift+クリック` で範囲選択します。キーで項目間を移動するとその項目に枠線が付き、一覧をクリックすると次にキーを押すまで隠れます。一覧の空白部分からドラッグすると、四角形にかかる項目を選択し、`Ctrl` または `Shift` を押したまま開始すると現在の選択に追加します。ドラッグ中に一覧の上端・下端に近づくと、その方向へスクロールしながら選択を続けます。端に近いほど速くなり、一覧の外に出ても最高速度（毎秒 20 行）でスクロールを続けます。`Shift+クリック` は最後にクリックした項目からクリックした項目までを選択し、`Ctrl+Shift+クリック` は現在の選択を残したままその範囲を追加します。macOS では `Ctrl` の代わりに `Cmd` を使います。

### 文字を入力して探す

一覧にフォーカスがあるときにファイル名の最初の文字を入力すると、その文字で始まる項目が選択され、その位置にスクロールします。グリッド・リスト・詳細のどの表示でも同じです。同じ文字を続けて押すと候補を 1 つずつ進み、最後の次は最初に戻ります。別の文字を続けて入力すると、`co`、`con` のように前方一致検索になります。大文字と小文字は区別せず、1 秒ほど間を空けて入力すると新しい検索を始めます。該当する名前がない場合は、選択はそのまま残ります。

アドレスバーを編集中、またはポップアップが開いている場合は、入力した文字はそちらに送られます。エクスプローラーを複数開いている場合は、現在フォーカスがある 1 つだけが動きます。

修飾キーなしの 1 文字にショートカットを直接割り当てている場合、その文字はショートカットとしてだけ動作し、この機能では使われません。既定の設定にはそのようなショートカットはありません。

### 右クリックメニュー

名前を変更するときに同じ名前の項目がある場合は、上書きせずに失敗を知らせます。コピー時にはシンボリックリンクはリンクとして維持し、ファイルは元の権限と更新時刻を、フォルダーは元の権限（読み取り専用を含みます）をそのまま保持します。所有者・拡張属性・ACL は引き継ぎません。また、実際には同じフォルダーやその配下にあたるパスには、フォルダーを貼り付けられません。ファイル操作に失敗すると、通知にエラーが表示されます。

フォルダーを指すリンクはフォルダーと同じように開き、アドレスバーにはリンクのパスが残ります。リンクの名前変更・ゴミ箱への移動はリンクだけを扱い、リンク先のフォルダーはそのままにします。リンク先がなくなったリンクを開くと、リンク先がないという通知が表示されます。一覧ではリンクの名前の後ろに小さなリンクアイコンが付き、リンク先がなくなったリンクはアイコンの位置に警告色のリンクアイコンが表示され、マウスを合わせると見つからないリンク先のパスが表示されます。リモートエクスプローラーも同じ表示と通知になりますが、マウスを合わせてもリンク先のパスは表示されません。リモートの Tasty がリンクの状態を送らないバージョンの場合は、リンクを区別せず通常の項目と同じように表示します。

- **開く** <!-- en: Open --> — サブフォルダーの検索結果を 1 つ右クリックすると、先頭に表示されます。ダブルクリックと同じように、フォルダーはその中に入り、ファイルは開きます。リモートエクスプローラーには表示されません。
- **含まれているフォルダで表示** <!-- en: Show in enclosing folder --> — サブフォルダーの検索結果（**開く** の次）やリンク 1 つを右クリックすると、先頭に表示されます。その項目が実際に入っているフォルダー（リンクはリンク先が入っているフォルダー）を、閲覧していたパスのまま開き、項目を選択して見える位置にスクロールします。リンク先がなくなったリンクとリモートエクスプローラーには表示されません。
- **新しいフォルダー** <!-- en: New folder --> · **新しいファイル** <!-- en: New file --> — 空白部分のメニューの先頭、フォルダーメニューのファイル操作グループにあります。上記の「新しいフォルダー・新しいファイル」を参照してください。
- **パスをコピー** <!-- en: Copy Path --> — 複数選択するとメニュー名が **パスをまとめてコピー** <!-- en: Copy Paths --> に変わり、パスを改行でつなぎます。
- **元に戻す** <!-- en: Undo --> · **やり直し** <!-- en: Redo --> — 空白部分のメニューにあり、「元に戻す: 3 個を移動」・「元に戻す: 名前の変更」のように対象の操作を名前に表示します。元に戻す操作ややり直す操作がなくても、**元に戻す**・**やり直し** の 2 行は **プロパティ** の前に薄く表示されたまま残ります。エクスプローラーごとに最近の操作 10 件（コピー・移動・名前変更・新しいフォルダー・新しいファイル）を記憶します。一部だけ完了したコピー・移動は、完了した項目だけを記憶します。元に戻した操作はやり直すことができ、新しい操作を行うとやり直せる操作はなくなります。やり直しは同じ操作を再び行い、コピー・移動は名前が重複すると再度尋ね、名前変更・新しい項目は同じ名前がある場合は上書きせずに失敗を知らせます。名前変更を元に戻すと元の名前に戻り（元の名前で別の項目が作られた場合や、その後に項目が編集された場合はそのままにします）、新しいフォルダー・新しいファイルを元に戻すとゴミ箱に移動します（作成後に内容を追加したり編集したりした場合は残します）。直近の操作をもう元に戻せない場合（例: コピーを削除した、移動したファイルを移動後に編集した）は行が薄くなり、マウスを合わせると理由が表示されます（Windows では同じ理由が行名に表示されます）。元に戻した後に元の場所の項目がなくなったり変わったりすると、やり直しも同じように薄くなるため、元に戻したことのないファイルをやり直しが移動することはありません。そのエクスプローラーのファイル操作がまだ待機中または進行中の場合は両方の行が薄くなり、ショートカットは案内だけを表示するため、直前に開始した操作を飛ばしてそれ以前の操作が元に戻ることはありません。ゴミ箱への移動はこの履歴に含まれません（ゴミ箱から復元します）。
- **コピー** <!-- en: Copy --> · **切り取り** <!-- en: Cut --> · **貼り付け** <!-- en: Paste --> · **貼り付け（中へ）** <!-- en: Paste (into) --> — 同じ名前がある場合は、どうするかを尋ねます（[進行状況と結果](#進行状況と結果)）。コピー・切り取りした一覧はすべての Tasty ウィンドウで共有するため、別のウィンドウでも貼り付けられます。この一覧は OS のクリップボードにも入り、別のファイルマネージャーに貼り付けられ、ファイルマネージャーでコピー・切り取りしたファイルもエクスプローラーに貼り付けられます。両者が異なる場合は後でコピーしたほうが貼り付けられ、その後で別のアプリで文字をコピーした場合は、エクスプローラーに貼り付けるものはありません。切り取ったファイルは、一度移動するとクリップボードから削除されます。リモートエクスプローラーでコピーしたファイルは OS のクリップボードには入れず、クリップボードにこのコンピューターのファイルではない項目（別のコンピューターのパスや Web アドレスなど）がある場合は貼り付けません。別のアプリがクリップボードを保持したまま応答しない場合も、そのアプリが後でコピーしたものとして扱って貼り付けず、通知で知らせます。macOS Finder でコピーしたファイルは、常にコピーとして貼り付けられます。システムクリップボードを更新できない場合は、ファイル一覧をこの Tasty インスタンス内だけに保存したことを知らせます。内部の一覧を貼り付ける場合も、システムクリップボードを確認できなければ案内します。使用できる内部の一覧がないときに貼り付けを実行すると、アクセスできないことを知らせます。メニューを開くだけでは通知は表示されません。
- **ゴミ箱に移動** <!-- en: Move to Trash --> — 確認なしで OS のゴミ箱へ移動します。元に戻す場合はゴミ箱から復元してください。そのドライブにゴミ箱がない場合は、何も削除せずに知らせます。
- **名前の変更** <!-- en: Rename -->。新しい名前にも新しいフォルダー・新しいファイルと同じ規則（空の名前、使用できない文字、前後の空白、予約名）が適用され、条件に合わない場合は入力欄の下に理由が表示され、保存されません。
- **システムで開く** <!-- en: Open in system --> — 選択したファイルは OS の既定のアプリで、フォルダーは OS のファイルマネージャーで開きます。複数の項目を選ぶと、すべて開きます。
- **Finder で表示** <!-- en: Show in Finder -->（macOS）· **エクスプローラーで表示** <!-- en: Show in File Explorer -->（Windows）· **ファイルマネージャーで表示** <!-- en: Show in File Manager -->（Linux）— 項目を 1 つ選択した場合、その項目が入っているフォルダーを開き、項目を選択します。Linux でファイルマネージャーが項目の選択をサポートしていない場合は、フォルダーだけを開きます。
- **新しいタブで開く** <!-- en: Open in New Tab --> — そのフォルダーをルートとするエクスプローラーのタブを、ペインにもう 1 つ開きます。
- **このフォルダをルートに設定** <!-- en: Set as Root --> — 左側のツリーのルートを変更します。
- **お気に入りに追加** <!-- en: Add to Favorites --> — フォルダー 1 つまたは空白部分を右クリックすると表示されます。名前を付けて左下の一覧に置きます。お気に入りはすべてのエクスプローラーで共有し、`~/.tasty/explorer-favorites.toml` に保存されます。別のウィンドウで追加・削除したお気に入りもすぐに反映されます。ファイルの保存はバックグラウンドで進むため、保存中も作業を続けられます。保存できない場合は警告通知が表示され、一覧は今回の実行中は残ります。外部でお気に入りファイルを変更した場合は上書きしないため、ファイルを確認してから Tasty を再起動してください。左下のお気に入りを右クリックすると、**新しいタブで開く** · **このフォルダをルートに設定** · **お気に入りから削除** <!-- en: Remove from Favorites --> が表示されます（リモートエクスプローラーでは新しいタブで開くが省かれます）。削除してもフォルダー自体はそのままです。
- **プロパティ** <!-- en: Properties --> — 上記の [プロパティ](#プロパティ) ポップアップを開きます。リモートエクスプローラーにも表示されます。

最後に選んだ表示方法は記憶され、新しいエクスプローラーにも適用されます。エクスプローラーのフォントは、**設定** > **外観** <!-- en: Appearance --> の **エクスプローラー** <!-- en: Explorer --> 項目で個別に指定します。リモートワークスペースのエクスプローラーでも、新しいフォルダー・新しいファイル・名前変更・ゴミ箱への移動・コピー・切り取り・貼り付け・ドラッグでの移動ができます。実際の操作はリモートコンピューターの Tasty が行い、進行状況の表示・名前の競合の質問・結果カードはローカルと同じように表示されます。ゴミ箱はリモートコンピューターのゴミ箱です。リモートの操作は **元に戻す** 一覧には入らないため、結果カードの **元に戻す** を使ってください。リモートの操作は接続ごとに 1 つずつ実行するため、進行状況の行と待機一覧の先頭にリモートコンピューター名が表示されます。領域が狭い場合は、名前・バイト表示を残りの幅に合わせて省略し、待機数・キャンセルボタンと重ならないようにします。名前の文字が見えなくてもホストのグリフにマウスを合わせると名前全体を表示し、省略されたバイト表示にマウスを合わせると値全体を表示します。待機一覧も領域内に収まるように開きます。非常に狭い領域では、待機一覧の操作アイコンを隠し、キャンセル・削除ボタンを優先して表示します。ボタン 1 つが完全に収まらない場合はボタンも隠れるため、領域を広げて使ってください。リモートコンピューターの Tasty が古いバージョンの場合は、ファイルを変更する項目とボタンが薄く無効になり、ツールチップ（ショートカットで呼び出すと通知）がそのコンピューターの Tasty を更新するよう案内します。操作中に接続が切れると、リモートでは操作が停止しますが、どこまで進んだかは分からないという案内が表示されるため、再接続後にフォルダーを確認してください。その接続で待機していた操作は実行せず、何件実行しなかったかを知らせます。システムで開く・ファイルマネージャーで表示・新しいタブで開くは、リモートエクスプローラーには表示されません。**お気に入りに追加** はメニューに表示されますが、押すとまだサポートしていないという通知だけが表示され、追加されません。

ローカルとリモートの間、または異なるリモートコンピューターの間では、ファイルの貼り付けやドラッグ＆ドロップはできません。貼り付けメニューは表示されず、ショートカットで貼り付けると案内だけが表示されます。パスが同じ別のコンピューターのファイルを代わりにコピーすることはありません。マークダウンファイルをダブルクリックすると、リモートコンピューターにそのファイルのタブが開き、既定のハンドラをリモートで使えない場合はリモートで使えるハンドラだけを選んで表示し、そのようなハンドラがない形式の場合は案内だけが表示されます。

### ドラッグして移動

項目をドラッグしてフォルダーの行・マス、左側のツリーのフォルダー、お気に入りにドロップすると、そのフォルダーに移動します。ファイル上や空白部分にドロップすると、そのエクスプローラーが表示しているフォルダーに入ります。隣に開いた別のエクスプローラーにドラッグすることもできます。項目をドラッグしながら一覧や左側のツリーの上下の端へ移動すると、自動でスクロールします。端に近いほど速くなり、領域の外では毎秒 20 行の速度を維持します。複数のエクスプローラーを上下に分けている場合は、マウスがある領域だけがスクロールし、領域の外では最も近いエクスプローラーだけが動きます。

- 同じディスクなら **移動**、別のディスクなら **コピー** します。`Ctrl`（macOS は `Option`）を押したままドロップすると逆の操作になります。このキーは **設定** > **キーバインド** > **一般** の一番下の **エクスプローラーのドラッグ切り替えキー** <!-- en: Explorer drag flip modifier --> で変更します（`config.toml` の `[keybindings]` の `explorer_drag_flip_modifier` と同じ値です）。
- ドラッグ中はポインターの横に **（フォルダー）に移動** <!-- en: Move to --> · **（フォルダー）にコピー** <!-- en: Copy to --> のように、実行する操作が事前に表示されます。ドロップできない場所では **ドロップできません** <!-- en: Can't drop --> と理由（自分自身の中、すでにそのフォルダー内、別のコンピューター、このリモートはファイルを変更できない、書き込み権限がない）が表示されます。シンボリックリンク経由で入ったフォルダーは、リンク先のフォルダーとして判断します。
- リモートエクスプローラー内でドラッグすると、リモートコンピューターが同じディスクと通知したフォルダー間でだけ **移動** し、それ以外は **コピー** します。
- 閉じたツリーのフォルダー上に 800ms 留まると、マウスをそれ以上動かさなくても展開されます。待っている間は、ドロップ先フォルダーの枠線が維持されます。`Esc` を押すとドラッグをキャンセルします。
- OS のファイルマネージャーからエクスプローラーの領域にドラッグしたファイルは、そのフォルダーに **コピー** します（移動はしません）。リモートエクスプローラーにはドロップできません（別のコンピューターのファイルだからです）。

Windows・macOS・Linux では、ローカルエクスプローラーの項目をウィンドウの外へドラッグして、別のアプリに **コピー** できます。Linux は X11 とネイティブ Wayland をサポートし、ファイルアイコンとポインターの表示は OS が提供します。元の項目はそのまま残り、外部へのコピーは Tasty の元に戻す一覧には入りません。元のウィンドウに戻ってドロップしても、内部の移動を同時に実行することはありません。リモート項目は外へドラッグできません。X11 ではエクスプローラーの **選択解除** キー（既定は `Esc`）でドラッグをキャンセルします。Windows・macOS・Wayland では、OS のドラッグキャンセルキーに従います。

同じ Tasty プロセスの別のウィンドウには送れません。別途起動した Tasty が通常の外部アプリのように受け取る場合はありますが、Tasty ウィンドウ間のファイルドラッグはサポート対象の機能ではありません。開始エラーや通信エラーが起きると案内が表示され、ドラッグを開始しただけでコピーが完了したと表示することはありません。

### 進行状況と結果

貼り付け・ドラッグ＆ドロップ・ゴミ箱への移動は、一度に 1 つずつ順番に処理します。コピー・移動では最初に対象ファイルを数えます。このときは **コピーする項目を集計中** または **移動する項目を集計中** と見つかった数を更新して表示し、進行状況バーはありません。集計が終わると、フォルダー内のファイルまで含めた進行数と現在のファイル名を表示します。バーはバイト基準で、すべて空のファイルであるか合計サイズが分からない場合はファイル数を基準にします。結果に表示される数は、最初に要求した項目数です。ただし、フォルダーとその中の項目を一緒に選んだ場合（例: サブフォルダーの検索結果）は、内部の項目はフォルダーと一緒に処理されるため別には数えません。リンク先の項目は、リンクと一緒に選んでも個別に処理します。  操作を開始したエクスプローラーの下のステータス行に、進行状況バー、現在処理しているファイル、サイズが表示され、**×** で停止します。停止すると、完了した項目はそのままにして、残りの項目は処理しません。待機中の操作がある場合は **+1 待機中** <!-- en: +1 queued --> が付き、押すと一覧が開いて待機中の操作を取り除けます。待機中の操作が多すぎたり、一度に選んだ項目が多すぎたりする場合は、操作を受け付けず、そのエクスプローラーに警告カードで知らせます。キューがいっぱいの場合は、カードの **キューを表示** <!-- en: Show queue --> で一覧を開けます。

同じ名前がすでにある場合は、そのエクスプローラーにフォーカスがあると質問のポップアップが開きます。別の場所を表示していた場合は、ステータス行の **表示** <!-- en: Show --> を押してください。

- **両方残す** <!-- en: Keep both -->（`Enter`）— 既定値です。新しい項目に `(copy)` を付けます。既存の項目は変わりません。
- **スキップ** <!-- en: Skip --> · **置き換え** <!-- en: Replace -->（ファイルのみ）· **残りをキャンセル** <!-- en: Cancel the rest -->（`Esc`）。
- 同じ名前のフォルダーは統合しません。フォルダーではスキップと両方残すだけを選べます。
- 競合がまだ残っている場合は **残り n 件の競合にも適用** <!-- en: Do this for the other conflicts --> を有効にして、一度に回答します。

完了すると、エクスプローラーの右下に結果カードが表示されます。すべて完了したカードはしばらくすると消え、失敗した項目やスキップした項目があるカードは、閉じるまで残ってそのパスを表示します。**×** で停止した操作のカードも、未処理の項目が残っている場合は閉じるまで残ります。コピー中に使用した隠し一時フォルダー（`.tasty-copy-` で始まります）を削除できない場合は、カードが警告カードに変わり、そのパスと「一時フォルダーを削除できませんでした」という理由を一緒に表示して閉じるまで残るため、原因を解消してからそのフォルダーを直接削除してください。

- **再試行** <!-- en: Retry --> — 失敗した項目やスキップした項目と、停止によって処理しなかった項目だけを再実行します。完了済みの項目は再実行しません。元の項目が残った移動項目は、元の項目の削除だけを再実行します。
- **パスをコピー** <!-- en: Copy paths --> — カードのパスをクリップボードに入れます。
- **元に戻す** <!-- en: Undo --> — すべて完了したコピー・移動で、カードが表示されている間に表示されます。移動した項目は元の場所に戻し（その場所に別の項目ができている場合はそのままにします）、コピーはゴミ箱に移動します。コピー後に編集したコピーは残します。置き換えで上書きしたファイルは元に戻せません。

別のディスクへ移動するときに元の項目をすべて削除できない場合（例: 書き込み権限がないサブフォルダー）は、元の項目が全部または一部残っているという警告カードが閉じるまで残ります。この場合、コピーが完全なデータなので元に戻すは表示されません。削除を妨げていた原因を解消して **再試行** を押すと、残った元の項目だけを削除します。その間にコピーがなくなったり別のものに変わったりした場合、または元のファイルを編集した場合は、元の項目を削除せず理由を表示します。コピーのパスがリンクなどで元と同じファイルを指す場合も削除しません。フォルダーはコピーに内容まで同じものがある項目だけを削除し（大きなファイルは比較中に進行状況が表示され、キャンセルできます。キャンセルすると、まだ残っている元の項目だけが警告カードに再び残り、後で再試行できます）、移動後に元のフォルダーに追加したり編集したりした項目は残して、その数を表示します。比較中はステータス行に確認中、削除中は元の項目を削除中と表示され、すべて削除すると削除した元の項目数を知らせるカードがしばらく表示されます。1 回の再試行で元の項目の削除と再移動を両方行っても、結果カードは 1 つです。

## Markdown

`.md` ファイルをレンダリングして表示します。ファイルが変わると、1 秒以内に自動で描画し直します。

- 表・チェックボックス・脚注・コードの強調・`mermaid` ダイアグラム・`$…$` 数式・`> [!NOTE]` コールアウト（Obsidian 形式の `[!tip]-` の折りたたみを含みます）・先頭の frontmatter の非表示に対応しています。
- 見出しがある場合は、本文の上に折りたためる **目次** <!-- en: Table of contents --> が付きます。項目を押すと、表示していた文書のままその見出しの位置へ移動します — 同じ項目をもう一度押しても再び移動します。
- コードブロックにマウスを合わせると **コードをコピー** <!-- en: Copy code --> ボタンが表示されます。
- 文書にフォーカスがあるときに、[キーバインド](../customize/keybindings.md) 設定の **検索** キー（既定は `Ctrl+F` · `Alt+F`、macOS は `Ctrl+F` · `Cmd+F`）— **文書内を検索** <!-- en: Find in document --> です。検索キーを変更すると、開いている文書にもすぐに適用されます。
- 全選択・コピーのキーは、フォーカスがある場所だけに適用されます。本文で全選択すると文書の内容だけを選び、アドレス欄・検索欄の文字は含まれず、アドレス欄や検索欄ではその欄の入力だけを選びます。
- 一番上のアドレスバーに別のファイルパスを入力し、`Enter` または **移動** <!-- en: Go --> を押して移動します。最近開いたファイルが自動補完に表示されます。同じ Tasty インスタンスの別のウィンドウで開いたファイルも、新しい順に最大 10 件まで一緒に表示されます。サーフェスが狭いと移動ボタンは隠れますが、`Enter` ではそのまま移動できます。
- アドレスバー左側のフォルダーボタン（**ファイルを開く…** <!-- en: Open a file… -->）を押すと、現在の文書があるフォルダーでファイル選択ウィンドウが開きます。選んだファイルが同じサーフェスで開き、新しいタブは作られません。キャンセルすると文書はそのままです。ファイル選択ウィンドウがすでに開いている場合は新しく開かないため、先にその選択を完了するかキャンセルしてください。リモートワークスペースのマークダウンのアドレスバーは、[リモート作業](../remote/attach.md) で説明します。
- 文書内のリンク — 別のマークダウン・ファイルは同じペインの新しいタブで開き、そのタブにすぐ切り替わります。`http(s)://` はブラウザーで開きます。相対パスはその文書があるフォルダーが基準です。開けるハンドラがないファイルの場合は、**次で開く…** ウィンドウが表示され、選択できます（リモートワークスペースではリモートで開けるハンドラだけが表示され、1 つもなければ通知が表示されます）。`#見出し` のように同じ文書内を指すリンクや、脚注番号・戻る矢印は、その位置へ移動するだけです。
- **更新** キー（既定は `F5`）を押すと、表示している文書 1 つだけをファイルから読み直して描画します。アドレス欄や検索欄への入力中でも使えます。ただし、文書を描画し直すため、アドレス欄に入力していた内容、開いていた検索欄と検索語、選択は消え、スクロール位置だけができるだけ元に戻ります。リモートワークスペースの文書は、リモートの原文を再取得し、接続が切れている場合は切断表示がそのまま残ります。大きなファイルは、以下と同じ確認を行います。
- 1 MiB を超えるファイルは、**大きなファイルを開きますか？** <!-- en: Open large file? --> で一度確認します。この確認ポップアップは、そのマークダウンサーフェスの中央に表示されます。サーフェスがポップアップより狭い場合は、ウィンドウの中央に表示されます。開いたときは小さかったファイルが後で 1 MiB を超えるサイズになっても、読み直す前に同じ確認を表示し、回答するまで以前の内容がそのまま表示されます。キャンセルすると本文の位置に **1 MiB を超えるファイルのため、まだ読み込んでいません** <!-- en: This file is larger than 1 MiB and has not been loaded --> と表示されます。その下の **ファイルを開く…** <!-- en: Open file… --> ボタンを押すと、同じ確認を再表示します。キャンセルしたファイルは変更されても自動で読み込まず、`tasty markdown reload --surface <ID>` でも再度尋ねられます。**開く** を選んだファイルは、その後は尋ねません。

**新規マークダウン...** または `Alt+'` > **マークダウン** は、**マークダウンファイルを開く** <!-- en: Open Markdown File --> ウィンドウを表示します。パスを入力するか、**参照…** <!-- en: Browse… --> で選んでください。参照は現在表示しているターミナルの現在のフォルダーから始まり、入力した相対パスもそのフォルダーを基準に開きます。このポップアップはそのサーフェス領域の中央に表示され、別のワークスペースやタブへ移動すると一時的に隠れ、戻ると入力していた状態のまま再表示されます。参照で開いたファイル選択ウィンドウも一緒に隠れて戻り、選択中のファイルと閲覧中のフォルダーを維持します。隠れている間は、別の画面のクリックやキーボード入力を妨げません。

```sh
tasty markdown recent
tasty markdown reload --surface 5
```

## 画像

PNG・JPEG などを表示し、簡単な描画ができます。**新規画像** は空のキャンバスから始まります。画像を開いた状態で作成しても元のファイルとは別なので、**保存** すると保存先のパスを尋ねます。新しいパスに保存するとタブ名がそのファイル名に変わり、再起動後もそのファイルが開きます。ファイルが外部で変更されると、1 秒以内に自動で読み直します — ただし **編集中は保留し**、編集を終えたときに反映します（描画中に下絵が変わらないようにするためです）。

- ツールバー — **前の画像** <!-- en: Previous image --> / **次の画像** <!-- en: Next image -->（同じフォルダー内で移動し、移動するとタブ名もそのファイルに変わります。編集中は移動しないため、先に保存するかキャンセルしてください — `tasty image next`・`prev` も、このときはエラーで終了します）、**更新** <!-- en: Refresh -->、**編集** <!-- en: Edit -->、**新規画像** <!-- en: New image -->、拡大の **フィット** <!-- en: Fit --> / `+` / `-` です。
- **編集** を押すと、**太さ** <!-- en: Brush --> · **色** <!-- en: Color --> を選んで上から描画します。`Ctrl+Z` / `Ctrl+Shift+Z` で元に戻したりやり直したりします。**保存** <!-- en: Save --> は PNG で書き込みます。JPEG のような PNG 以外のファイルを編集して保存すると、元のファイルは残し、同じフォルダーに同じ名前の `.png` を作成してそのファイルに切り替わります。その `.png` がすでにある場合は、上書きせず保存先のパスを尋ねます。このとき入力欄の上にすでに存在するという案内が表示され、入力欄には `名前-1.png` のようにまだ存在しない名前が、名前部分を選択した状態で入っています。
- **名前を付けて保存** のフォルダーボタンは、Tasty のファイル選択ウィンドウを開きます。PNG ファイルを選ぶか名前を入力して確定すると、保存先のパスが入力されます。既存のファイル名の場合は上書きの警告を表示します。実際のファイルは画像の **名前を付けて保存** で **保存** を押したときに書き込み、参照をキャンセルすると入力したパスはそのままです。
- ファイルを読み取れない場合は、キャンバスに理由を表示します — **画像が見つかりません** <!-- en: Image not found -->（パスを表示）、**アクセス権がありません** <!-- en: Permission denied -->、**この画像を開けません** <!-- en: Can't open this image -->（破損または未対応の形式で、デコーダーのメッセージを表示）、**画像が大きすぎて開けません** <!-- en: Image is too large to open -->（1 辺が 16384px を超える画像や、デコードに 512MiB より多いメモリが必要な画像は開かず、画像の実際のサイズを表示）です。大きすぎる画像を除いた場合は、**再試行** <!-- en: Retry --> を押すと読み直します。ファイルが戻ったり変わったりすると、自動でも読み直します。
- 画像上で貼り付けのショートカット（既定は `Ctrl+V`）を押すと、クリップボードの画像を浮動選択範囲として貼り付けます。クリップボードに画像がない場合は何もしません。`tasty image paste --surface <ID>` も同じです。
- `tasty image list` は、**ウィンドウが複数あっても** 開いている画像をすべて表示します。
- `tasty image reload --surface <ID>` は、待たずに今すぐ読み直します。

```sh
tasty image list
tasty image open --surface 5 shot.png
tasty image export --surface 5 out.png
```

## HTML

現在のフォルダーの継承を有効にした状態で、HTML ファイルのタブから新しいタブや分割を作成すると、そのファイルのフォルダーを基準にします。Web アドレスのタブは、既存の作業フォルダーを維持します。

ヘッドレスサーバーでも、`tasty html open` で HTML タブの要求アドレスを変更できます。ヘッドレスサーバーはページを描画せず、リモート接続での HTML 本文の表示はまだサポートしていません。

ローカルの HTML ファイルや URL を、OS の Web ビューで表示します。タブストリップの空白部分を右クリック > **新規HTML...** を押すと、ファイル選択ウィンドウがそのペインの現在のフォルダーで開き、フォルダーと `.html` · `.htm` · `.svg` ファイルだけが表示されます。ファイルを選ぶとそのペインに HTML タブが開き、キャンセルするとタブは作成されません。リモートワークスペースではファイル選択ウィンドウは開かず、まだ開けないという通知が表示されます。

- 読み込み中は **読み込み中…** <!-- en: Loading… -->、失敗すると **読み込みに失敗しました** <!-- en: Failed to load --> と URL が表示されます。
- メニューやポップアップが開いている間も、HTML・マークダウンのページがそのまま表示されます。画面合成（コンポジター）が無効な場合や、ウィンドウマネージャーがポップアップの位置を合わせられない場合は、ポップアップのボックスの位置だけが角張ったボックスで覆われます。全画面やウィンドウの一部が画面の外にあるときに、この状況が起こる場合があります。このときページを押したりホイールを回したりすると、ポップアップの外を押したものとして処理され、ページには伝わらず、キー入力もページには送られません。X サーバーが形状拡張（SHAPE・XFixes）をサポートしていない Linux では、ポップアップが開いている間、ページが一時的に隠れて空のパネルだけが表示されます。通知カードが表示されると、カードと重なるページだけがカードが消えるまで隠れ、ほかのページはそのまま表示されます。現在文字を入力しているページは隠さないため、その上の通知カードは隠れます。
- **設定** > **外観** の **HTML** 項目 — **既定のズーム** <!-- en: Default zoom --> · **カラースキーム** <!-- en: Color scheme -->（**テーマに従う** <!-- en: Follow theme --> / ライト / ダーク）· **リモートコンテンツを許可** <!-- en: Allow remote content --> · **スクリプトをサンドボックス化** <!-- en: Sandbox scripts --> です。リモートコンテンツとスクリプトは既定でブロックされています。ローカルで作成したプレビューを見る用途なので、外部サイトを開くときは **リモートコンテンツを許可** を有効にし、**スクリプトをサンドボックス化** を無効にする必要があります。

### アドレスバー

HTML 画面の上部にはアドレスバーがあります。左から **戻る** <!-- en: Back --> · **進む** <!-- en: Forward --> · **再読み込み** <!-- en: Reload --> ボタンとアドレス欄です。ローカルファイルはファイルパス（ホームフォルダーは `~`）、Web 文書は URL で表示されます。

- アドレス欄にファイルパスまたは `file://` · `http://` · `https://` アドレスを入力して `Enter` を押すと開きます。移動ボタンは別途ありません。
- 相対パスは現在の文書を基準に解決します。ローカルファイルの場合はそのファイルが入っているフォルダー、Web 文書の場合はそのアドレスが基準です。空の HTML タブではそのタブの作業フォルダーが基準となり、基準がない場合は開かずに知らせます。
- 存在しないファイルを入力すると、開かずにアドレス欄の下に **ファイルが見つかりません** <!-- en: File not found --> と表示されます。表示していたページと入力した文字はそのままで、次の文字を入力するか `Esc` を押すと案内が消えます。
- 編集中の `Esc` は入力をキャンセルし、現在の文書のアドレスに戻ります。アドレス欄に入力している間は、キーはページ・ターミナル・Tasty のショートカットには送られません。
- アドレス欄で `Tab` · `Shift+Tab` を押すと、押せる状態の **戻る** · **進む** · **再読み込み** ボタンとアドレス欄の間を順番に移動し、ボタンに枠線が表示されます。`Enter` または `Space` でそのボタンを押し、`Esc` で抜けます。ボタンへ移動すると入力していた文字は元のアドレスに戻り、アドレス欄に戻るとアドレス全体が選択されます。押したボタンが薄くなったり読み込み中の表示に変わったりすると、ボタンのフォーカスが外れます。
- `Alt+L`（macOS は `Cmd+L`）で、現在フォーカスがある HTML 画面のアドレス欄に移動し、アドレス全体が選択されます。ページ内で入力中でも動作します。キーは **設定** > **キーバインド** > **サーフェス** の **アドレスバーに移動** <!-- en: Focus the address bar --> で変更し、エクスプローラーのアドレスバーと同じキーです。
- 読み込み中は再読み込みの位置に回転する表示が出て、読み込みに失敗するとアドレス欄には開こうとしたアドレスが残ります。
- 履歴の先頭では戻る、末尾では進むボタンが薄くなります。HTML 画面が 440px より狭い場合は、進むボタンが隠れます。
- 空の HTML タブには、アドレス欄の案内とショートカットが一緒に表示されます。アドレスバーで開いた文書は、再起動すると最初に作成したときのアドレス（空のタブなら空のタブ）に戻ります。エージェントが `tasty html open` で開いたアドレスも同じです。
- リモートワークスペースの HTML タブにはアドレスバーがありません。

### リモートコンテンツがブロックされた文書

**リモートコンテンツを許可** が無効なときに、ネットワーク上のスタイルシート・画像・フォントなどを使うローカル文書を表示すると、アドレスバーの下に **このドキュメントのリモートコンテンツはブロックされています** <!-- en: Remote content in this document is blocked --> という案内が表示されます。リモートコンテンツは読み込まないため、ページがスタイルなしで表示される場合があります。スクリプトの案内と同じように、ページを覆わず、その分だけ下へ押し下げます。

- **リモートコンテンツを許可** <!-- en: Allow remote content --> — この文書だけリモートコンテンツを読み込めるようにして、一度読み込み直します。別の文書に移動したり、ファイルの内容が変わったり、Tasty を再起動したりすると、再びブロックされます。スクリプトの許可とは別です。文書の読み込み中は押せません。
- 案内を **×** で閉じるかリモートコンテンツを許可すると、アドレス欄の右端に地球アイコンが残ります。ブロックされた文書は斜線付きの地球で、押すと案内が再表示されます（押すだけでは許可しません）。許可した文書は地球アイコンで、ポインターを合わせると許可済みという案内だけが表示されます。
- リモートコンテンツとスクリプトが両方ブロックされた文書では、2 つの案内がリモートコンテンツ → スクリプトの順に別々に積み重なります。
- エージェントが開いた文書は、人がそのタブを見たときに案内が表示されます。エージェントは `tasty surface html-remote-allow` で、照会した文書のリモートコンテンツを許可できます。
- **リモートコンテンツを許可** 設定を有効にしている場合は、すべての文書でリモートコンテンツを読み込み、案内とアイコンはありません。リモートワークスペースの HTML タブにはこの案内はありません。

### スクリプトがブロックされた文書

**スクリプトをサンドボックス化** が有効なときにスクリプトがある文書を表示すると、ページの上に **このドキュメントのスクリプトはブロックされています** <!-- en: Scripts in this document are blocked --> という案内が表示されます。案内はページを覆わず、その分だけページを下へ押し下げます。案内文は切れずに最後まで表示され、画面が狭くて行が増えると案内が長くなり、ページもその分だけさらに下がります。HTML 画面が狭い場合は、ボタンが説明の下の行に移動します。

- **このドキュメントで許可** <!-- en: Allow for this document --> — この文書だけスクリプトを有効にし、一度読み込み直します。別の文書に移動したり Tasty を再起動したりすると、再びブロックされます。許可した文書のタブにはスクリプトファイルのアイコンが付きます。
- 画面が新しい文書を読み込んでいる間は、**このドキュメントで許可** を押せません。ボタンにポインターを合わせると **ドキュメントの読み込みが終わると使用できます** <!-- en: Available when the document finishes loading --> と表示されます。リンク・戻る・再読み込みで直接開いた文書にスクリプトがあればボタンが再び有効になり、なければ案内が消えます。エージェントが開いた文書の場合は、そのタブを再び見たときに案内が表示されます。非常に大きなファイルは、画面が開いた後も Tasty がファイル全体を確認している間、ボタンが一時的に無効になる場合があります。この確認は、ほかのターミナルや画面を停止しません。スクリプトを許可した文書を読み込み直すときは、確認が終わってから新しい文書が表示されます。
- 案内の右上の **×** — 許可せずに案内だけを閉じます。タブタイトルの後ろに鍵アイコンが残り、鍵を押すと案内が再表示されます。鍵を押してもタブは切り替わりません。
- エージェントが開いた文書やセッション復元で開き直した文書は、人がそのタブを見たときに案内が表示されます。エージェントも状態を照会してから `tasty surface html-script-allow` でその文書のスクリプトを許可できます。照会後に文書が変わった場合や、まだ読み込み中の場合は許可しません。許可しても、表示していたタブとフォーカスはそのままです。
- 文書を読み込めず **読み込みに失敗しました** <!-- en: Failed to load --> が表示されている間は、案内とタブの鍵・スクリプトアイコンが消えます。読み込み直した文書が開くと、その文書を基準に再び決まります。

```sh
tasty html open --surface 5 ./dist/index.html
tasty new tab --pane 1 --type html --url http://localhost:3000
tasty surface html-script --surface 5   # スクリプトの検出結果・許可の有無・案内の状態を照会
tasty surface html-script-allow --surface 5 --url <url> --fingerprint <hex>   # 照会した文書のスクリプトを許可
tasty surface html-remote-allow --surface 5 --url <url> --fingerprint <hex>   # 照会した文書のリモートコンテンツを許可
```

## Git 表示

サイドバーの **ツール** > **Git** を押すと、現在のターミナルのディレクトリにあるリポジトリを読み取り専用で表示するウィンドウが開きます。

- **変更** <!-- en: Changes -->（status）· **コミット** <!-- en: Commits -->（log）· ファイルをクリックすると **Diff** です。
- 左側の **ワークツリー** <!-- en: Worktrees --> 一覧から別の worktree を選んで、それを基準に表示します。実際の checkout は変わりません。
- **更新** <!-- en: Refresh --> で外部の変更を反映します。コミット・ステージングのような書き込みはありません。
- **Git ビューアを開く** <!-- en: Open Git Viewer --> ショートカットは、**設定** > **キーバインド** > **プラグイン** <!-- en: Plugins --> で指定します（既定値なし）。

現在のディレクトリが Git リポジトリの場合は、このウィンドウとは別にステータスバーでブランチ名を確認できます（[最初の画面を見てみる](../getting-started/first-look.md#ステータスバー)）。

## 空のサーフェス

ファイルを閉じた場所や、まだ種類を指定していない場所は **空** <!-- en: Empty --> のまま残り、中央に種類の選択ボタンがあります。押すと [種類を変更する](panes-tabs-splits.md#種類を変更する) ポップアップと同じです。

エクスプローラーは Tasty に内蔵されており、マークダウン・画像・HTML・Git 表示は同梱プラグインです。プラグインを無効にすると、その種類では開けません — [プラグイン](../plugins/index.md)。
