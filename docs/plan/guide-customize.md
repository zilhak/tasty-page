# 맞춤 설정

가이드 페이지는 영어, 한국어, 일본어, 중국어 간체로 함께 둔다. 각 페이지의 역할과 범위는 아래와 같다.

## 단축키

- 사이트 소스: [한국어](../../content/customize/keybindings.md) · [영어](../../content/en/customize/keybindings.md)
- 역할: 키 조합 선택·변경 참조.
- 보여 줄 항목: 기존 기본 키 표, 물리 위치 표기, 프리셋, 가져오기·내보내기, 빈 기본값, 플러그인 키.
- 넣지 않을 항목: 모든 셸·OS 자체 단축키도 Tasty에서 바꾼다는 주장.
- 구성: 프리셋 선택, 단축키 편집과 가져오기·내보내기를 다룬다. 내보내기 중 버튼 비활성화와 인접 진행 표시, 완료 안내의 표시 조건을 포함한다.

## 설정

- 사이트 소스: [한국어](../../content/customize/settings.md) · [영어](../../content/en/customize/settings.md)
- 역할: 설정의 목적별 길찾기.
- 보여 줄 항목: 설정 열기, 목적별 탭·반영 조건, 파일 직접 편집, 주요 저장 위치, 언어팩은 뒤쪽 상세.
- 넣지 않을 항목: 테마·단축키 전체 중복, 내부 자료를 사용자 편집 대상으로 안내.
- 구성: 목적별 길찾기와 기존 탭별 표를 유지한다. 원격 전송과 원격 Attach 설정을 구분하고, 무응답 시간의 기본값·범위·입력 확정 보정·파일 값 보정·새 연결 적용 범위를 보여 준다. 글꼴 값을 쓸 수 없을 때는 설정 윈도우 입력 칸 아래 오류 줄과 입력 중 숨김, 메인 윈도우 경고 알림이 뜨는 시점과 값마다 한 번이라는 범위, 에이전트가 적용한 값의 차이, 저장을 막지 않고 다른 글꼴로 표시한다는 점을 보여 준다.

## 테마

- 사이트 소스: [한국어](../../content/customize/themes.md) · [영어](../../content/en/customize/themes.md)
- 역할: 테마 선택부터 제작까지.
- 보여 줄 항목: Mocha·Latte, 테마 선택, 부분 색상 변경, 사용자 TOML, 오류와 복구.
- 넣지 않을 항목: 사이트 디자인 토큰 3단계 전체 설명, 번들 파일 직접 편집 권장.
- 구성: 기본 테마 선택, 부분 색 변경, 파일로 테마 제작을 구분하고 밝은 테마의 대비와 적용 범위를 보여 준다.

## Lua 스크립트

- 사이트 소스: [한국어](../../content/customize/scripts.md) · [영어](../../content/en/customize/scripts.md)
- 역할: 반복 조작을 등록하고 연결하기.
- 보여 줄 항목: 현재 등록 절차, 실제 이벤트와 함수, 파일 변경 확인, OS 접근과 실행 제약, 실패 안내.
- 넣지 않을 항목: init.lua 자동 실행 약속, 불신 코드를 안전하게 격리한다는 보장.
