# 使用终端

介绍在终端运行命令时复制输出、搜索和打开文件路径的方法。还可使用无需鼠标的复制模式，以及任务完成通知。

以下快捷键基于默认的 **Tasty** 预设。在 macOS 上，将 `Alt` 视为 `Cmd`。

## Shell

在 **设置** > **终端** <!-- en: Terminal --> 中设置。

- **Shell** <!-- en: Shell --> — 要运行的 Shell。在 Windows 上，Tasty 仅运行 Git Bash（Git for Windows 的 `bash.exe`）。值为空时，使用在默认安装位置找到的 Git Bash。如果安装在其他位置，输入对应的 `bash.exe` 路径。
- **启动命令** <!-- en: Startup command --> — 每个新终端启动时输入的一行命令。
- **继承工作目录** <!-- en: Inherit working directory --> — 在当前终端的目录中启动新终端（默认开启）。
- **关闭运行中进程前确认** <!-- en: Confirm close running process --> — 关闭仍有程序运行的终端时要求确认。

bash（4.4 及以上）和 zsh 无需额外配置即可启用 Shell 集成。标签页名称随当前目录变化，状态栏显示 git 分支，还可在命令结束时触发钩子（[钩子 · 通知](../agents/hooks-notifications.md)）。fish 等其他 Shell 需要手动配置，此时可能显示 **未检测到 Shell 集成** <!-- en: Shell integration not detected --> 横幅。通过附加到远程 Tasty 查看终端时，不显示此横幅。横幅在 10 秒后自动关闭，鼠标悬停时会保持显示。

程序退出且 Shell 结束后，该 Surface 自动关闭。

## 方向键和修饰键

终端程序可区分与 `Shift`、`Ctrl`、`Alt` 一起按下的方向键和普通方向键。**这些组合在 macOS 上使用实际的 `Option` 键，而非 `Cmd`。**例如，程序提示 `⌥ + ↑` 时，按 `Option+↑`。具体行为由终端内的程序决定。

无论 **将 Option 用作 Meta** 设置开启还是关闭，方向键组合都会传递。此设置仅决定 macOS 的 Option+字符是输入特殊字符，还是作为 Meta 键传递。已注册为 Tasty 快捷键的组合，以及被复制模式或拦截输入的叠加层接收的按键，不会发送给程序。

## 按应用设置 Shift+Enter

在 **设置 → 终端 → 输入** 中添加可执行文件名（如 `claude`），并开启或关闭 **使用 Shift+Enter 发送换行符**。开启时发送换行符（LF），关闭或删除规则时使用平台默认的按键发送方式。修改后保存设置即可应用。

Claude Code 插件在安装后首次激活时，会自动添加 `claude` 的换行规则。已安装的插件也会在更新后首次激活时注册规则。已有的设置值及之后修改或删除的规则会保留。

可执行文件名忽略大小写和 `.exe` 后必须完全匹配。检测应用切换最多可能需要 1 秒。如果只检测到 `node` 等启动器，需要为该可执行文件名添加规则。此设置不影响粘贴或普通 Enter。

Windows 版 Codex CLI 在默认按键发送方式下，使用 `Shift+Enter` 或 `Ctrl+J` 换行，使用 `Enter` 发送。

## 复制和粘贴

| 操作 | 快捷键 |
|---------|--------|
| 复制 | `Ctrl+C` · `Alt+C` · `Ctrl+Shift+C` |
| 粘贴 | `Ctrl+V` · `Alt+V` · `Ctrl+Shift+V` |
| 进入复制模式 | `Ctrl+Shift+Space` |

- `Ctrl+C` 在有选区时复制，否则像平常一样中断程序。
- 粘贴后 0.5 秒内的 `Ctrl+C` 会被忽略，防止误按 `Ctrl+V` 旁边的键导致输入丢失。被忽略时会显示短暂提示。
- 剪贴板中没有文本但有图像时，会将图像保存为 PNG 文件，再粘贴其路径。可用于向智能体提供截图。保存会在后台进行，不会冻结画面，保存完成后路径会输入到执行粘贴的终端。在此期间输入的字符可能先于路径到达。如果在此期间关闭终端，则不输入路径并删除文件。
- 因窗口宽度而折行的内容，复制时会合并为一行。
- 从右键菜单复制时，“Copied”通知右侧会同时显示复制快捷键。文件浏览器右键菜单中的复制路径也会显示复制路径的快捷键。通过快捷键复制或未设置快捷键时，不会显示。

### 将截图复制到剪贴板

按 `Ctrl+Alt+S` 并选择屏幕区域后，会将 PNG 文件保存到 `~/.tasty/screenshots/`，同时将路径和图像放入剪贴板。粘贴到终端时输入路径，粘贴到图像编辑器等接受图像的应用时输入图像。在远程镜像工作区中按下时，文件会保存到远程计算机，并放入远程剪贴板。

- **macOS**：通过 `screencapture` 选择区域。需要屏幕录制权限。
- **Linux**：Wayland 下使用 `grim`、`slurp`，未安装时使用 `gnome-screenshot`。X11 下按 `gnome-screenshot` → `scrot` → ImageMagick `import` 的顺序使用已安装的工具。一个工具失败时会尝试下一个。
- **Windows**：不选择区域，截取所有显示器合并后的整个屏幕。
- 无法将图像放入剪贴板时（无法读取图像、Linux 下图像超过 X11 单次传输上限等），只放入路径。
- 使用 Esc 取消区域选择时，不会再打开其他工具，剪贴板也保持原样。工具结束但未生成文件时同样如此。
- 结果以通知形式显示在按下快捷键的窗口中。图像和路径均放入时显示成功，只放入路径时显示警告，工具缺失、失败或无法保存、复制时显示原因。使用 Esc 取消时不显示通知；工具结束但未生成文件时（部分工具在取消时也会这样结束），仅提示“未截取截图”。选择区域期间即使切换到其他窗口，通知仍显示在原窗口中；如果已关闭原窗口，则不显示通知。

### 选择

拖动（字符）· 双击（单词）· 三击（行）。选区可延伸到回滚缓冲区。选择后右键点击，会显示 **复制** <!-- en: Copy --> · **复制时移除换行** <!-- en: Copy Without Line Breaks --> · **复制终端 ID** <!-- en: Copy Terminal ID --> 菜单。如果所选文本是实际存在的文件或文件夹路径，还会显示 **打开文件** <!-- en: Open File --> / **打开文件夹** <!-- en: Open Folder -->。

在 Shell 中输入命令时，单击输入行可将光标移至该位置。在非 Shell 程序、向上查看回滚缓冲区时，或捕获鼠标的程序中，不会移动光标。要关闭此行为，在 `config.toml` 的 `[general]` 中添加 `click_to_move_cursor = false`（[设置](../customize/settings.md)）。

### 复制模式（vi）

无需鼠标即可在屏幕和回滚缓冲区中移动并复制。点击终端后，按 `Ctrl+Shift+Space` 进入。在 macOS 上也使用 `Control` 键，而非 `Cmd`。如果修改了快捷键，按修改后的按键。

进入后，终端右下角会显示通知，列出移动、选择、复制和退出的按键，当前屏幕第一行的第一个单元格会出现复制光标。复制模式中的按键不会发送给 Shell 或程序。

无法进入时，会通过通知说明原因。

- vim、less 等使用终端 **备用屏幕** 的程序运行期间无法进入。与窗口最大化或切换到操作系统全屏无关。退出程序后重试。
- 无法在文件浏览器等非终端 Surface 中进入。Markdown 或 HTML Surface 接收按键输入时也无法进入，但此时原因通知可能被该 Surface 的画面遮挡。
- 如果已处于复制模式，会提示当前状态，不会再次进入。

模态框或弹窗接收键盘输入时，快捷键会传给它们，因此不会进入复制模式，也不会显示通知。点击终端后再次按下。

例如，在 Shell 中运行 `printf '\033[2J\033[HABCDE\n'`，屏幕顶部会留下 `ABCDE`。进入复制模式并确认光标位于 `A` 上后，松开 `Ctrl`、`Shift`，依次按 `v` `l` `l` `y`，即可将 `ABC` 复制到剪贴板并退出复制模式。

| 按键 | 操作 |
|----|------|
| `h` `j` `k` `l` | 移动。前加数字可重复 |
| `w` `b` `e` / `W` `B` `E` | 按单词移动 |
| `0` `^` `$` | 行首 / 首个字符 / 行尾 |
| `gg` `G` / `H` `M` `L` | 最顶部 / 最底部 / 屏幕顶部 · 中间 · 底部 |
| `v` / `V` | 开始按字符 / 按行选择 |
| `y` | 复制成功后退出。失败时保留选区。无选区时按下则不复制，直接退出 |
| `/` `?` `n` `N` | 向下 · 向上搜索，下一项 · 上一项结果 |
| `"+` `"*` | 指定下次复制的目标剪贴板 |
| `q<字符>` … `q` / `@<字符>` | 录制 / 回放宏 |
| `Esc` | 清除选区。无选区时退出。有选区时，第一次 `Esc` 清除选区，第二次 `Esc` 退出 |

仅在成功写入剪贴板后显示复制通知。无法访问或传输失败时，会显示提示并保留选区。有选区时，即使 Ctrl+C 复制失败，也不会中断程序。粘贴失败时不发送输入；剪贴板为空时不执行任何操作。

在 Linux 上使用 X11 运行时，终端复制和粘贴使用 X11。在设有 `DISPLAY` 且能连接 X 服务器的 Wayland 会话中，通过 XWayland 与其他应用交换内容。因未设置 `DISPLAY` 或无法连接 X 服务器而使用原生 Wayland 运行时，也可与其他应用相互复制和粘贴文本。如果其他应用只复制了图像而没有文本，粘贴时会将图像保存为 PNG 文件并输入其路径。

在原生 Wayland 下，vi 复制模式中用 `"*` 复制的内容无法传递到其他应用。请改用 `"+` 复制，或不指定目标直接复制。文件浏览器的文件复制、剪切和粘贴无法使用操作系统的文件剪贴板，只使用此 Tasty 中保存的列表。

如果合成器不支持剪贴板，终端和输入框都无法通过复制和粘贴与其他应用交换内容。此时，在终端复制和粘贴，或在输入框复制和剪切时，会显示包含原因和使用 XWayland 的解决方法的警告短暂提示。`"*` 复制以及文件浏览器的文件复制、剪切和粘贴也会显示警告短暂提示。参见 [Linux 原生 Wayland 故障排除](../help/troubleshooting.md#linux-native-wayland)。

### 程序访问剪贴板（OSC 52）

终端内的程序（tmux、远程 vim 等）可请求向剪贴板 **写入**。仅在写入成功后显示复制通知，无法访问或失败时也会提示。**读取** 需要开启 **设置** > **终端** > **允许读取剪贴板（OSC 52）** <!-- en: Allow clipboard read (OSC 52) -->。默认关闭，开启后，通过 SSH 连接的远程程序也可获取剪贴板内容，需注意。

### 从脚本写入剪贴板

脚本或智能体可直接将文本放入剪贴板。

```sh
tasty clipboard set-text "要复制的内容"
```

## 搜索

按 `Ctrl+F` 或 `Alt+F`，或点击标签栏中的搜索图标。搜索栏会显示在 Surface 顶部中央。

普通终端中会搜索整个回滚缓冲区和屏幕。在 vim、less 等使用备用屏幕的程序内，仅搜索当前屏幕。退出程序后可搜索之前的 Shell 记录。

- `Enter` / `Shift+Enter` / `↑` `↓` — 下一项 / 上一项结果。结果数量显示为 `3/42`，屏幕会随之移动。
- 搜索结果以浅黄色标记，当前结果以深黄色标记。当前结果内的文字使用主题的强调文字色，不受程序指定颜色影响，确保在各主题中均可阅读。其他结果保留原文字颜色。
- 右侧开关 — **区分大小写** <!-- en: Match case --> · **正则表达式** <!-- en: Regular expression --> · **全字匹配** <!-- en: Match whole word -->。
- 光标位于搜索栏时，按 `Esc` 或点击 `×` 关闭。即使搜索栏已打开，只要光标在终端内，按键输入仍会传给终端。再次按 `Ctrl+F` 可在搜索栏和终端之间切换。
- 搜索输入框在没有焦点时也可通过背景和边框区分。输入无效的正则表达式时，输入框边框会显示为红色；将光标移回终端后，错误标记仍会保留。
- 搜索栏显示在当前光标所在的 Surface 上。如果其他标签页或旁边拆分的 Surface 已打开搜索栏，会清除该搜索并移至当前 Surface。

## 打开链接和路径

按住 `Ctrl` 并将鼠标悬停在 URL 或路径上，会出现蓝色下划线，点击后通过浏览器或关联程序打开。如果无法启动浏览器或关联程序，会在该终端右下角显示无法打开的通知。也支持 `src/main.rs` 等相对路径，但只有相对于当前目录实际存在的路径才会成为链接。

右键点击带下划线的链接，会显示链接专用菜单。

- **选择** <!-- en: Select --> — 选择完整链接文本。
- **复制** <!-- en: Copy --> — 复制屏幕上显示的链接文本。如果在快捷键设置中为 **复制链接** 指定按键，“Copied”通知右侧会显示该按键；在链接上按下此键，无需菜单即可复制。没有默认按键。
- **打开方式…** <!-- en: Open With… --> — 不立即打开，而是显示用于选择打开程序的列表。也可为 `http(s)://` 地址选择程序，例如选择 HTML 查看器后，会在 Tasty 内的标签页中打开，而非浏览器。远程附加终端中的路径无法在本机打开，因此只显示空列表。

即使 vim、tmux 等使用鼠标的程序正在运行，右键点击链接也不会传给该程序，而是显示此菜单。非链接区域的右键点击行为不变。

在 **设置** > **终端** > **链接点击修饰键** <!-- en: Link click modifier --> 中选择 `Ctrl`、`Alt` 或 **禁用左键点击打开** <!-- en: Disable left-click opening -->。选择 **禁用左键点击打开** 后，左键点击不会打开链接。无需修饰键即可悬停显示链接，链接右键菜单仍可使用。弹窗或横幅可能阻挡链接标记。

文件的打开方式（Markdown、图像、文件浏览器）见[文件管理与查看](files.md)。将文件拖放到终端上（**放下以打开** <!-- en: Drop to open -->），会按相同规则打开。

## 滚动

- 使用鼠标滚轮，或 `PageUp` / `PageDown`（每次一屏）查看回滚缓冲区。输入时会返回最底部。
- 在 vim、less、htop 等使用整个屏幕的程序中，滚轮和 `PageUp` / `PageDown` 会传给程序。
- 保留行数位于 **设置** > **终端** > **回滚缓冲区行数** <!-- en: Scrollback lines -->（默认 10,000，最多 100,000）。`clear` 也会清空回滚缓冲区。
- 重启后回滚缓冲区仍会保留，见[工作区](workspaces.md#重启后恢复)。

使用 `Ctrl+=` / `Ctrl+-` 增大或减小字号，使用 `Ctrl+0` 重置。应用于当前获得焦点的 Surface，支持终端、文件浏览器和 Markdown。

## 捕获鼠标的程序

vim（`:set mouse=a`）、htop、Claude Code 等直接使用鼠标的程序运行时，点击和拖动会传给该程序。首次点击时会显示横幅。

> **鼠标输入已被捕获** <!-- en: Mouse input captured --> — 此应用正在捕获鼠标。使用 Shift+拖动选择文本，使用 Shift+右键点击打开 tasty 菜单。

- `Shift+拖动` — 选择文本。`Shift+双击` 选择单词。
- `Shift+右键点击` — Tasty 的复制菜单。
- 程序结束后，横幅会自动关闭。也可点击 `×` 立即关闭。
- 将鼠标悬停在横幅上，在出现的 **更多选项** <!-- en: More options --> 中选择 **不再为 {程序} 显示** 或 **让 Tasty 处理 {程序} 中的点击**。由 Tasty 处理点击时，该程序上的点击会像平常一样用于选择，只有滚轮会传给程序。无法识别运行中的程序时，例如通过附加到远程 Tasty 查看终端时，这两项会变灰且无法选择。菜单顶部的提示会说明原因。

相同选项位于 **设置** > **终端** > **鼠标捕获** <!-- en: Mouse Capture --> 中，包括 **显示鼠标捕获提示** <!-- en: Show mouse-capture hint --> 开关、**让 Tasty 处理这些程序中的点击** <!-- en: Let Tasty handle clicks in these programs --> 列表，以及 **不为这些程序显示捕获通知** <!-- en: Don't show the capture notice for these programs --> 列表。名称采用部分匹配，支持 `ht*` 等通配符。

## 运行中和需要关注的标记

- 标签页的 **绿点**、侧边栏卡片的点 — Shell 以外的程序正在输出。程序停止输出并等待输入时会消失。仅修改终端标题的输出不计入。
- Surface 的 **黄色边框** — 程序正在等待响应（智能体提出问题时）。**蓝色边框** — 命令已结束或收到通知。点击该 Surface 后消失。标签页名称和侧边栏徽标也使用相同颜色。

## 通知

汇总显示终端响铃（`\a`）和程序发送的通知序列（OSC 9 · 99 · 777）。

- `Ctrl+Shift+I` — **通知** <!-- en: Notifications --> 面板。包含按时间从新到旧排列的列表、**跳转** <!-- en: Jump --> 按钮和 **全部标为已读** <!-- en: Mark all read -->。打开后会全部标为已读。通过标题栏的全屏按钮可放大查看（[全屏](panes-tabs-splits.md#全屏)）。
- 不会发送到操作系统通知中心。即使窗口位于后台，也通过此面板、Surface 边框和侧边栏徽标查看通知。
- **设置** > **常规** > **通知** <!-- en: Notifications --> — **启用通知** <!-- en: Notifications enabled --> · **声音** <!-- en: Sound --> · **通知合并间隔（ms）** <!-- en: Coalesce interval (ms) -->（将同一位置连续收到的通知合并为一条的时间间隔，默认 500）。
- 仅关闭响铃通知时，使用 **设置** > **终端** > **显示响铃通知** <!-- en: Show bell notification -->。

从脚本直接显示通知，使用 `tasty notify "构建完成" --title build`。

## 各平台说明

- **macOS** — 开启 **设置** > **终端** > **将 Option 用作 Meta** <!-- en: Use Option as Meta --> 后，`Option+F` 等组合会作为 readline、Emacs 的 Meta 键传入，而非特殊字符（默认关闭）。
- **Windows** — 从睡眠中唤醒后，终端可能无响应。Tasty 会尝试唤醒，如果仍然显示为卡住状态，会通过通知提示。此时重新打开该终端。
- 如果不希望程序使整个屏幕闪烁（如 readline 的 visible bell），可关闭 **设置** > **终端** > **屏幕反色闪烁（DECSCNM）** <!-- en: Reverse-screen flash (DECSCNM) -->。

- 不支持 Sixel、Kitty 图像协议。通过[图像 Surface](files.md#图像)查看图像。
- 脚本或智能体向此终端发送命令并读取输出的方法见 [tasty CLI](../agents/cli.md)。状态栏中的数字是该终端的 ID。
