# 初识界面

Tasty 的初始界面由用于切换工作区的侧边栏和用于显示终端或文档的工作区域组成。每个窗格都有标签栏，每个标签页内都有用于显示终端或文档的 Surface。

## 在界面中直接学习

通过侧边栏的 **工具** <!-- en: Tools --> > **教程…** <!-- en: Tutorial… -->，可以直接学习界面结构和拆分操作。

拆分练习在新建的练习工作区中进行。点击工作区域，再使用显示的快捷键或菜单。确认操作生效后，点击 **下一步**。练习空间在完成后仍会保留，可以继续使用或自行关闭。

通过 **主题** 或 `Esc` 可中断，之后选择 **继续**。重新打开应用后，仍会记住完成状态和进度位置。继续拆分练习时会创建新的练习空间。快捷键提示遵循当前设置。

## 四个术语——工作区、窗格、标签页和 Surface

Tasty 的界面按此顺序构成包含关系。要在界面中查看各部分，可打开侧边栏的 **工具** <!-- en: Tools --> > **教程…** <!-- en: Tutorial… -->，按照直接显示在界面上的指引操作。

| 术语 | 含义 | 类似概念 |
|------|----|------------|
| **工作区** <!-- en: Workspace --> | 包含所有标签页、窗格和 Surface 的最大单位。在侧边栏中切换 | tmux 的 session、iTerm2 的 window |
| **窗格** <!-- en: Pane --> | 工作区在空间上划分出的区域。每个区域都有 **自己的标签页条** | Tasty 特有的概念，tmux 和 iTerm2 中没有对应概念 |
| **标签页** <!-- en: Tab --> | 窗格内的一个标签页 | tmux 的 window、iTerm2 的 tab |
| **Surface** <!-- en: Surface --> | 实际绘制终端、Markdown、文件浏览器的区域。一个标签页内可以拆分为多个 Surface | tmux 和 iTerm2 的 pane |

Tasty 的特点是 **拆分分为两级**。

- **拆分窗格** — 将工作区左右或上下划分。在某个窗格中切换标签页时，其他窗格保持原样。例如：左侧窗格专用于 Claude Code，右侧窗格放置多个日志、构建标签页。
- **拆分 Surface** — 划分一个标签页内部。切换标签页时，整个拆分布局一起切换。

详细操作见 [窗格、标签页和拆分](../using/panes-tabs-splits.md)。

## 窗口结构

<!-- tasty-diagram: window-anatomy -->
```
┌─────────────────────────────────────────────────┐
│ 标题栏                                          │
├──────────┬──────────────────────────────────────┤
│          │ 标签页条                             │
│ 侧边栏   ├──────────────────────────────────────┤
│          │ 工作区域（窗格、标签页、Surface）    │
│          ├──────────────────────────────────────┤
│          │ 状态栏                               │
└──────────┴──────────────────────────────────────┘
```

- **标题栏** — 拖动可移动窗口，双击可最大化。在 Linux 和 Windows 上，Tasty 自行绘制最小化、最大化、关闭按钮；在 macOS 上，沿用左侧的红黄绿按钮。
- **侧边栏** — 工作区列表以及工具、插件、设置的入口。
- **工作区域** — 放置终端和文档的区域。分为以下四种组成部分。
- **状态栏** — 当前终端的状态和快捷按钮。

## 侧边栏

从上到下分为三个区域。

- **顶部区域** — `tasty.` 文字标识和 **折叠** <!-- en: Collapse --> 按钮。折叠后变为仅保留图标的窄栏。
- **工作区** <!-- en: WORKSPACES --> 列表 — 点击卡片切换，拖动调整顺序。通过最下方的 **新建工作区** <!-- en: New workspace --> 按钮添加。右键点击此按钮，会显示 **从预设创建工作区...** <!-- en: Create workspace from preset... --> 和 **添加远程工作区** <!-- en: Add remote workspace -->。卡片右侧有两种数字徽标。黄色徽标表示等待输入的 Surface 数量，蓝色徽标表示任务已完成或收到通知的 Surface 数量。两者同时存在时，黄色徽标位于左侧。
- **底部按钮** — **工具** <!-- en: Tools -->（依次为 **命令面板…** <!-- en: Command palette… -->、**监听端口…** <!-- en: Listening ports… -->、**远程连接…** <!-- en: Remote connections… -->、**预设** <!-- en: Presets -->、**教程…** <!-- en: Tutorial… -->、**任务 DAG** <!-- en: Task DAGs -->、**打开文件…** <!-- en: Open File… -->，下方分隔线后是插件添加的项目）、**插件** <!-- en: Plugins -->（管理安装和启用的窗口）、**设置** <!-- en: Settings -->（设置窗口）。

工作区较多时，可开启 **设置** > **常规** <!-- en: General --> > **工作区分类（文件夹）** <!-- en: Workspace categories (folders) -->，像文件夹一样分组。详情见 [工作区](../using/workspaces.md)。

## 标签页条

位于每个窗格的最上方。

- 每个标签页都显示类型图标（终端、Markdown 等）和名称。名称按以下顺序确定：自行指定的名称 → 程序设置的终端标题 → Shell 当前目录名 → 默认名称。通过右键 > **重命名标签页** <!-- en: Rename Tab --> 指定名称后，就不会变为其他名称。
- 程序正在输出时，会显示 **绿点**；等待输入或任务完成时，名称颜色会改变（[名称和标记](../using/panes-tabs-splits.md#名称和标记)）。
- `+` 用于新建标签页。右键点击可从预设创建。旁边的拆分、搜索图标用于拆分此窗格或在当前 Surface 内搜索。
- 标签页超出可用宽度时，会出现左右箭头。拖动可调整顺序。
- 右键点击空白处，可通过 **新建终端** <!-- en: New Terminal -->、**新建 Markdown…** <!-- en: New Markdown... -->、**新建 HTML…** <!-- en: New HTML... -->、**新建图像** <!-- en: New Image --> 创建标签页。使用 **新建 HTML…**，在文件选择窗口中选择 HTML 或 SVG 文件后，会在该窗格中打开标签页。同一菜单中还可选择 **保存为窗格预设** <!-- en: Save as pane preset -->、**从预设创建标签页...** <!-- en: Create tab from preset... --> 和 **从预设创建窗格...** <!-- en: Create pane from preset... -->。各类型的说明见 [文件管理与查看](../using/files.md)。

窗格中最后一个标签页无法通过关闭标签页操作关闭。关闭 Surface 则不同。关闭标签页中最后一个 Surface 时，该标签页会关闭；若该标签页是窗格中的最后一个标签页，窗格也会关闭；若该窗格是工作区中的最后一个窗格，工作区也会一并关闭。

<summary>状态栏</summary>

位于工作区域最下方的一行。左侧显示当前获得焦点的 Surface 的信息，右侧是按钮。

- **git 分支** — Shell 当前目录为 git 仓库时，显示分支图标和分支名称。更新最多延迟 1 秒。若不是仓库，则 **完全不显示此项**。直接查看某个提交时（detached HEAD），显示 `@` 和短提交编号，而非名称。
- **Surface ID** — 如 `s3·p1`，表示 Surface 编号及其所在窗格的编号。前面的数字是通过 `tasty` CLI 指定此终端时使用的值（[tasty CLI](../agents/cli.md)）。
- **Shell** — 正在运行的程序名称。
- **网格大小** — `列×行`。
- **命令面板快捷键** — 以按键形状显示。点击可打开命令面板，显示的按键遵循设置。清空快捷键后，此项也会消失。
- **主题图标** — 每次点击都会在浅色主题（latte）和深色主题（mocha）之间切换。图标形状表示当前主题，浅色主题显示太阳。

**没有值的项目会消失，不会留下空位。** 窗口变窄时，依次隐藏网格大小 → Shell → Surface ID → 命令面板快捷键 → 分支名称，主题图标始终保留。

## 首先需要了解的快捷键

以下为默认预设（**Tasty**）的值。标记中的 `Alt` 在 macOS 上对应 `Cmd(⌘)`，`Ctrl` 对应 `Control(⌃)`。修改方法和完整表格见 [按键绑定](../customize/keybindings.md)。

| 操作 | Windows · Linux | macOS |
|---------|-----------------|-------|
| 新建工作区 | `Alt+N` | `Cmd+N` |
| 新建标签页 | `Alt+T` | `Cmd+T` |
| 拆分窗格（左右 / 上下） | `Alt+E` / `Alt+Shift+E` | `Cmd+E` / `Cmd+Shift+E` |
| 拆分 Surface（左右 / 上下） | `Alt+D` / `Alt+Shift+D` | `Cmd+D` / `Cmd+Shift+D` |
| 命令面板 | `Ctrl+Shift+P` | `Ctrl+Shift+P` |
| 设置 | `Ctrl+,` | `Ctrl+,` |

在 macOS 上，若要使用 iTerm2 风格、以 `⌘` 为主的组合键，可在 **设置** > **按键绑定** <!-- en: Keybindings --> 中选择 **Mac** 预设。

## 关闭窗口时

有多个窗口时，关闭按钮只会关闭所在窗口。点击最后一个窗口的关闭按钮时，会询问是 **退出** <!-- en: Quit --> 还是 **最小化** <!-- en: Minimize -->。选择最小化后，Tasty 会进入系统托盘（菜单栏），通过托盘图标菜单中的 **显示窗口** <!-- en: Show Window --> 可返回。若不想每次都询问，可修改 **设置** > **常规** > **关闭行为** <!-- en: Close behavior -->。

确认退出后，所有窗口中的网页和 Markdown 文档会隐藏；若需要等待退出，则显示进度界面。取消退出确认，或最小化到后台后返回时，可以继续使用文档。

再次启动时，可以 [恢复](../using/workspaces.md#重启后恢复) 布局和终端历史记录。这与恢复此前运行的程序不同，具体取决于设置以及各程序对会话恢复的支持。
