# テーマ

Tasty は明るい Latte と暗い Mocha のテーマに対応しており、一部の色を変更したり、TOML ファイルでユーザーテーマを作成したりできます。テーマファイルは `~/.tasty/themes/` に保存します。

## 同梱テーマ

| テーマ | ファイル | 明るさ | 備考 |
|------|------|------|------|
| **Catppuccin Mocha** | `~/.tasty/themes/mocha.toml` | 暗い | デフォルトのテーマです。削除したり壊したりしても、次回起動時に元の内容に復元されます |
| **Catppuccin Latte** | `~/.tasty/themes/latte.toml` | 明るい | テーマフォルダーが空のときに作成されます。ほかのテーマが残っている場合、削除した Latte は再作成されません |

両方のファイルは Tasty が管理するため、**直接編集しないでください** — 起動時に Mocha と、ファイルが残っている Latte を元の内容に戻します。色を変更するには、以下の「一部の色だけを変更する」または「自分で作成する」を使用してください。

読み取り権限やファイルのエンコーディングの問題で元の内容を読み取れない場合、ファイルを上書きしません。選択したテーマを読み込めない場合は、内蔵の Mocha の色を使用します。実行中や追加のウィンドウでテーマを適用するときには、ファイルを復元しません。ファイルを修正したら、設定のテーマ一覧を開き直すか、Tasty を再起動してください。

明るい Latte テーマでは、バナーの本文とカウントダウン、ボタン、キー表示とタグ、選択中・キーボード操作でアクティブな行の文字を読みやすくするため、コントラストを高めました。

## テーマを変更する

最も手早い方法は、ステータスバーの右端にある **テーマアイコン** です。クリックするたびに Latte と Mocha が切り替わります。ほかのテーマを使用しているときに押すと、Latte に切り替わります。

一覧から選ぶには:

1. **設定** <!-- en: Settings --> （`Ctrl+,`）> **外観** <!-- en: Appearance --> > **テーマ** <!-- en: Theme --> を開いてください。
2. **テーマプリセット** <!-- en: Theme Preset --> の下にあるカードのいずれかをクリックしてください。カードには名前と代表的な色が 5 色表示されます。
3. **保存** <!-- en: Save --> を押してください。

テーマを変更すると、**色** タブと **Tasty** タブで上書きした色、**ターミナル** タブで設定したフォーカス時の背景・非フォーカス時の背景がすべてリセットされます。新しいテーマを適用すると、そのテーマの色を基準に開始します。

設定に記載されたテーマファイルが存在しないか読み込めない場合は、代わりに Mocha で起動し、**テーマが見つかりません** <!-- en: Theme not found --> という案内が表示されます。

## 一部の色だけを変更する

テーマファイルを作成せずに、現在のテーマの色を上書きします。設定する場所は 3 か所あります。

### 外観 > 色

**色** <!-- en: Colors --> タブには、現在のテーマのすべての色がグループ別に並びます — **背景** <!-- en: Surfaces --> · **オーバーレイ** <!-- en: Overlays --> · **テキスト** <!-- en: Text --> · **アクセント** <!-- en: Accents --> · **ターミナル専用** <!-- en: Terminal-specific --> · **ANSI 16色** <!-- en: ANSI 16 -->。

1. 変更する行の **デフォルト** <!-- en: Default --> のチェックを外してください。
2. 色を選ぶか、hex 値を入力してください。
3. 行の **リセット** <!-- en: Reset --> でその色だけを、上部の **すべてリセット** <!-- en: Reset all --> ですべてを元に戻してください。変更した数は **n 件変更済み** <!-- en: n changed --> と表示されます。
4. **保存** してください。

### 外観 > Tasty

ボタン、サイドバー、タブの見た目を変更する 3 つの項目です。

- **アクセント** <!-- en: Accent --> — アクティブ表示、フォーカスリング、ボタンなどに使われる色です。
- **サイドバー背景** <!-- en: Sidebar background -->。
- **アクティブタブインジケーター** <!-- en: Active tab indicator --> — **下線** <!-- en: Underline --> / **塗りつぶし** <!-- en: Fill --> / **ドット** <!-- en: Dot --> のいずれかです。

**テーマのデフォルトを使用** <!-- en: Use theme defaults --> で 3 項目をまとめて元に戻します。

### 外観 > ターミナル

ターミナルサーフェスの **フォーカス時の背景** <!-- en: Focused background --> と **非フォーカス時の背景** <!-- en: Unfocused background --> を個別に設定します。行の **デフォルトを使用** <!-- en: Use default --> をオフにすると編集できます。フォーカスされたターミナルと、フォーカスされていないターミナルを背景色で区別するのが Tasty のデフォルトの動作です — Mocha はフォーカス時が `#000000` / 非フォーカス時が `#1e1e2e` です。

このように上書きした値は、`~/.tasty/config.toml` の `[appearance]` の下に保存されます。

## 自分で作成する

`~/.tasty/themes/<id>.toml` という 1 つのファイルが 1 つのテーマです。ファイル名（拡張子を除く）がテーマの id になり、設定のテーマカードには `label` が表示されます。ほかのフォルダーにあるファイルは読み込みません。

**すべての色の項目は任意** です。記載しなかった項目には、直前に適用されていたテーマの値がそのまま残ります。そのため、数行のファイルでもテーマになります。

```toml
# ~/.tasty/themes/my-theme.toml
label = "My Theme"      # カードに表示される名前
is_light = false        # 省略すると前のテーマの値を維持

[palette]
crust    = "#11111b"    # 最も暗い背景
mantle   = "#181825"    # サイドバーなど
base     = "#1e1e2e"    # 基本の背景
surface0 = "#313244"
surface1 = "#45475a"
surface2 = "#585b70"
overlay0 = "#6c7086"
overlay1 = "#7f849c"
overlay2 = "#9399b2"
text     = "#cdd6f4"
subtext1 = "#bac2de"
subtext0 = "#a6adc8"
placeholder = "#6c7086"

[accent]
blue = "#89b4fa"        # デフォルトのアクセント
green = "#a6e3a1"
red = "#f38ba8"
yellow = "#f9e2af"
peach = "#fab387"
mauve = "#cba6f7"
teal = "#94e2d5"
sky = "#89dceb"
lavender = "#b4befe"
flamingo = "#f2cdcd"
pink = "#f5c2e7"
maroon = "#eba0ac"
rosewater = "#f5e0dc"

[terminal]
selection_bg = "#585b70"
vi_cursor_bg = "#b4befe"
search_match_bg = "#f9e2af4d"          # 8 桁 = 最後の 2 桁が透明度(そのセルの背景に重ねて混合されます)
search_match_active_bg = "#f9e2afb3"
search_match_active_fg = "#1e1e2e"     # 現在の結果内の文字色。省略するとこの値

[ansi]
black = "#45475a"
red = "#f38ba8"
green = "#a6e3a1"
yellow = "#f9e2af"
blue = "#89b4fa"
magenta = "#cba6f7"
cyan = "#94e2d5"
white = "#bac2de"
bright_black = "#6c7086"
bright_red = "#f38ba8"
bright_green = "#a6e3a1"
bright_yellow = "#f9e2af"
bright_blue = "#89b4fa"
bright_magenta = "#cba6f7"
bright_cyan = "#89dceb"
bright_white = "#cdd6f4"

[surfaces.terminal]
focused_bg   = "#000000"
focused_fg   = "#cdd6f4"
unfocused_bg = "#1e1e2e"
unfocused_fg = "#a6adc8"

[surfaces.markdown]
focused_bg   = "#11111b"
focused_fg   = "#cdd6f4"
```

ルール:

- 色は `#RGB` · `#RRGGBB` · `#RRGGBBAA` 形式です。8 桁の場合、最後の 2 桁が透明度です。
- `[surfaces.<種類>]` は、サーフェスの種類ごとのフォーカス時 / 非フォーカス時の背景色・文字色です。`terminal` · `markdown` のほかに、プラグインが登録した種類の名前も使用でき、定義していない種類は安全なデフォルトの色で描画されます。Markdown 文書の背景は、フォーカスに関係なく `[surfaces.markdown]` の `focused_bg` で塗られます。
- ホバー・選択の強調表示などの半透明効果は、`is_light` に応じて自動的に決まります。余白・文字サイズはテーマファイルでは設定しません。
- 明るいテーマを作成するときは、必ず `is_light = true` を記載してください。オーバーレイの色の方向（黒を重ねる / 白を重ねる）は、この値で分かれます。

作成したファイルを適用するには、**設定** > **外観** > **テーマ** を開いてください。このタブを開くたびにフォルダーを読み直すため、再起動は不要です。カードが表示されたらクリックし、**保存** してください。

Mocha を少しだけ変更した派生テーマを作成するには、`mocha.toml` をコピーして **別の名前** で保存し、修正してください。`mocha.toml` 自体を修正すると、次回起動時に元の内容に戻ります。

## トラブルシューティング

| 症状 | 確認すること |
|------|-----------|
| カード一覧に自分のテーマが表示されません | ファイルが正しく `~/.tasty/themes/` にあるか、拡張子が `.toml` かを確認してください。設定ウィンドウを閉じて開き直してください |
| 起動直後に **テーマが見つかりません** と表示されます | `config.toml` の `theme = "…"` が指すファイルが存在しないか、構文エラーがあります。ファイルを修正するか、設定で別のテーマを選んでください |
| 一部の色が前のテーマの色のままです | 正常です — 記載しなかった項目は前の値が維持されます。その項目をファイルに明記してください |
| 色タブで変更した値が消えました | テーマを変更すると、上書きした値がリセットされます。テーマファイルに色を書き移してください |
