# 원격 연결·플러그인·도움말

가이드 페이지는 영어, 한국어, 일본어, 중국어 간체로 함께 둔다. 각 페이지의 역할과 범위는 아래와 같다.

## 원격 작업 이어가기 (attach)

- 사이트 소스: [한국어](../../content/remote/attach.md) · [영어](../../content/en/remote/attach.md)
- 역할: 원격 Tasty 워크스페이스 연결.
- 보여 줄 항목: 이미지 업로드 진행·실패와 다운로드 후 실행 팝업이 열리는 위치, 업로드 대상 닫힘 뒤 실패 안내·재시도 제한, 다운로드 후 실행 팝업의 대상 변경 시 다시 열기, 원격 실행·SSH 조건, 프로필, GUI/CLI, 미러의 범위, 점유·연결 끊기·닫기, 사이드바의 원격 워크스페이스 닫기 확인 팝업의 현재 윈도우 중앙 표시와 대상 워크스페이스로 전환하지 않는 동작·전환 후 표시 유지, 강제 끊기도 대상 워크스페이스로 전환 없이 요청 가능, 연결 끊기 결과(이미 끊김 응답과 오류 이유), 저장된 원격 행과 명시적 연결, 실패 안내. mirror 스크린샷을 붙여넣기 단축키로 입력하는 조건과 한계, 로컬 캡처를 mirror에 붙여넣을 때 입력되는 경로.
- mirror에서 새 탭·분할 결과를 기다리는 동안의 명령: 도구 메뉴·명령 팔레트·플러그인 명령 단축키를 계속 사용할 수 있음을 다룬다. 명령 입력 시점에 대상을 정하며, 이때 요청한 팝업은 생성된 새 서피스에서 연다. 기다리는 동안 다른 서피스를 선택해도 대상은 바뀌지 않고, 원격에서 생성이 실패하면 해당 명령은 실행하지 않는다. 플러그인 명령 단축키의 키는 터미널이나 다른 동작에 전달하지 않는다. 상세 설명은 원격 가이드에 모으고 단축키 가이드에서는 짧게 연결한다.
- mirror에서 새 탭 생성 대기 중의 변환 입력: 마크다운 파일 열기처럼 새 탭을 만드는 입력 팝업의 요청, 새 탭 생성 뒤 해당 탭을 기준으로 팝업 표시, 원격 탭 생성 실패 시 팝업을 열지 않는 동작.
- mirror에서 새 탭 생성 대기 중의 내장 동작: 탭 하나 대상 동작의 생성 후 순서대로 실행, 보류하는 탐색기 동작의 구체적인 목록과 항목 옮기기·선택 넓히기·고른 항목 열기·선택 해제 키 제외, 새 탭 종류가 지원하지 않는 동작 제외, 복사·잘라내기·붙여넣기 제외, 생성 실패·취소 시 폐기, 페인 닫기·활성 항목 닫기로 워크스페이스를 닫지 않는 동작, 탭 이름 변경의 무동작. 명령 팔레트의 탭 하나 대상 동작은 대기 여부와 관계없이 Enter 시점의 탭에서 실행하고 해당 종류가 지원하지 않으면 실행하지 않는 규칙은 단축키 가이드에서 다룬다.
- 넣지 않을 항목: 일반 SSH 셸 생성과 동일시, 동시 공동 편집·충돌 병합 보장.
- 구성: 원격 실행·SSH·점유 조건을 먼저 둔다. 터미널 attach, 실행 중인 윈도우에 mirror 연결, 저장된 원격 행의 연결 규칙을 구분한다. 기존·신규 워크스페이스의 JSON 결과와 대기, mirror ID·권한, 무응답 시간, 파일·클립보드 전송, mirror 스크린샷과 로컬 캡처의 붙여넣기, 재연결 시간 설정, 저장 행의 자동 연결·명시적 연결·목록 조회·요청 대기, 원격 닫기와 로컬 닫기, GUI·CLI 연결 끊기를 보여 준다.

## 플러그인

- 사이트 소스: [한국어](../../content/plugins/index.md) · [영어](../../content/en/plugins/index.md)
- 역할: 제공 기능 선택과 설치·실행 상태 관리.
- 보여 줄 항목: 현재 번들 목록, 활성화·비활성화·설치·업데이트, 승인 없이 사용할 수 있는 Tasty 기능과 다른 플러그인 명령, 로컬 전용·디버그 기능의 제한. 제작 시 이벤트 구독·발행 선언과 미선언 요청의 거절·로그 안내. Claude Code의 자식 출력 없음 알림 설정 위치·라벨·키·기본값·허용 범위, 상세 동작 가이드로 연결. `com.tasty.` 예약 id와 공식 목록의 관계, 서명 확인 전 거부 및 미검증 설치 선택의 한계, 추가 화면의 거부 표시, 플러그인 폴더에 직접 넣은 예약 id 폴더의 확인 필요 표시·제거 흐름·CLI 제거와의 차이를 다룬다.
- 넣지 않을 항목: 설치·업데이트 권한 승인과 권한 표시, 없어진 플러그인 권한 명령, 실행 중 모든 악성 동작 차단·인증 완료 보장, 탐색기를 번들 플러그인으로 소개.
- 구성: 번들 목록, 활성화·설치·업데이트, 서명·신뢰 선택, 서명 확인과 프로세스 격리의 차이, 플러그인용 기능의 사용 범위, 에이전트 세션 권한 명령을 보여 준다.

## 문제 해결

- 사이트 소스: [한국어](../../content/help/troubleshooting.md) · [영어](../../content/en/help/troubleshooting.md)
- 역할: 증상에서 조치·신고로 연결.
- 보여 줄 항목: Linux 표시 경로별 증상·원인·조치(네이티브 Wayland, X 서버 연결 실패, `GDK_BACKEND`, 원인 불명 GTK 초기화 실패), 기능 제한과 안내 위치, 로그·신고 연결, 멈춤 리포트의 Linux 부하 정보와 Windows `tasty.pdb` 보관 안내로 연결. 증상별 분기, 안전한 현재 저장 위치, 권한·연결·복원·플러그인, 신고 정보. CLI 응답 지연 시 셸 timeout을 통한 동일 요청 반복의 위험, 연결 종료와 요청 취소의 차이, 단일 요청 명령의 응답 대기 상한과 실행 시작 전후 만료의 차이를 다루고 재시도 판단은 진단 안내로 연결한다. 셸 문제는 Windows(Git Bash가 아니거나 없는 값으로 시작 때 셸 선택 화면, 실행 중 새 터미널 실패와 설정 탭 원인)와 macOS·Linux(다른 셸로 대신 실행, 폴더·실행 권한)를 나누어 보여 준다.
- Wayland 클립보드에서 보여 줄 항목: 컴포지터의 클립보드 지원 조건, 편집 결과를 알려 주는 플러그인의 로컬 화면·팝업 입력칸과 명령 팔레트 붙여넣기의 읽기 대기, 원격 미러 제외와 기본 제공 플러그인의 현재 미적용 범위. 플랫폼 공통인 기존 비텍스트 형식 붙여넣기와 플러그인의 직접 읽기, 회신 약속과 비텍스트 형식 지원을 모두 갖춘 로컬 화면의 Wayland 읽기 대기 뒤 빈 결과·실패에 따른 형식 붙여넣기 요청 및 팔레트 적용 범위. 형식 미지원·붙일 형식 없음·읽기 시간 초과의 분기별 원래 키 전달과 키 없는 팔레트 종료, 편집 결과 응답 시한 초과 때 키를 전달하지 않는 처리. 대상 닫힘·키 입력 대상 변경·같은 윈도우 클릭·윈도우 포커스 상실·다른 읽기로 교체·플러그인 종료 및 재시작에 따른 취소와 늦은 텍스트 폐기.
- 넣지 않을 항목: 첫 화면부터 파일 목록 암기, 자료 삭제로 해결을 기본 권장, 낡은 legacy 직접 수정, Windows에서 Git Bash가 아닌 셸로 우회하는 방법.
- 구성: 설치·Linux 표시 경로·입력·복원·알림·플러그인·신고 순서로 증상을 먼저 보여 주고 로그·설정 위치는 뒤에 둔다. 닫기 때 기록 생략과 실행 중 저장 중단의 적용 범위 및 안전한 조치를 구별한다.

## 크래시·멈춤 리포트와 로그

- 사이트 소스: [한국어](../../content/help/error-reports.md) · [영어](../../content/en/help/error-reports.md)
- 역할: 갑작스러운 종료·멈춤 직후의 자료 보관과 문제 신고 안내.
- 보여 줄 항목: 재실행 전 로그 복사 순서, 기본 데이터 폴더와 `TASTY_HOME`, 크래시·멈춤 리포트, GUI 실행에 한정된 자동 멈춤 감지·리포트 기록, 멈춤 시간·마지막 처리·화면 그리기·윈도우 포커스·가림 상태와 Linux의 시스템 부하·CPU 사용 시간·실행·대기·스케줄 정보 및 해당 Linux 정보의 수집 불가 사유 표시, 윈도우 포커스·가림 상태의 알 수 없음 표시 가능성, Linux·Windows 크래시 backtrace와 Linux GDB 표본의 함수 이름·Tasty 함수 줄 번호 부재, Windows ZIP·헤드리스 ZIP·MSI의 `tasty.pdb` 동봉과 실행 파일 옆 보관, PDB가 있어도 일부 프레임의 함수 이름이 부정확할 가능성, `debug.log`, 플러그인 로그, 훅 실패 기록, `TASTY_LOG`와 표준 오류 출력 및 GUI 실행 시 한계, 진단 명령과 재시작 시 누계 초기화, 멈춘 상태의 스택 표본과 Linux GDB, OS 자체 크래시 기록, 신고 첨부 자료와 토큰·경로·원격 연결 정보 가리기.
- 넣지 않을 항목: 내부 판정 조건·소스 좌표·개발 빌드 경로, 미측정 OS 도구의 구체적인 조작·저장 위치, macOS backtrace 함수 이름 표시 단정, 모든 프레임의 정확한 이름 보장, 로그의 토큰 미기록 보장, 배포물 크기 수치.
- 구성: 직후 조치와 재실행 전 복사, 데이터 폴더·파일별 설명, 상세 로그·진단 명령, 스택 표본·OS 기록, 첨부·개인 정보 가리기 순서로 보여 준다. 문제 해결과 설정의 데이터 폴더 표에서 연결한다.

## CLI 응답 지연과 연결 진단

- 사이트 소스: [한국어](../../content/help/cli-diagnostics.md) · [영어](../../content/en/help/cli-diagnostics.md)
- 역할: CLI 전문 진단 참조.
- 보여 줄 항목: 현재 오류 코드·대기 상한·지원 기능 조회·pressure 필드 참조.
- 넣지 않을 항목: 대기 시간 연장만을 만능 해결로 제시, 진단 필드를 랜딩에 열거.
- 구성: 응답 대기와 작업 대기를 구분하고 오류별 조치, 지원 기능 조회와 연결·요청 큐·저장소 상태를 보여 준다.
