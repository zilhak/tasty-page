# Tasty ガイド

Tasty は Windows、macOS、Linux 向けの GPU アクセラレーテッドターミナルで、ワークスペースでプロジェクトを分け、ペインとタブでターミナルとドキュメントを配置します。

初めての方は、[インストール](getting-started/install.md) → [最初の画面を見てみる](getting-started/first-look.md) → [作業レイアウトを作る](using/workflow-layouts.md)の順に始めてください。
