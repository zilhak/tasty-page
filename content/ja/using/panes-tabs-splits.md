# ペイン・タブ・分割

Tasty のペイン分割はタブを個別に切り替える領域を作り、サーフェス分割は 1 つのタブで一緒に表示する画面を分けます。目的の配置に合わせて 2 つの分割を選んで使用してください。

以下のショートカットは、既定の **Tasty** プリセットを基準にしています。macOS では `Alt` を `Cmd`、`Ctrl` を `Control` と読み替えてください。

## 2 段階の分割 — 先に選ぶ

| | ペイン分割 | サーフェス分割 |
|--|-----------|-------------|
| 分割するもの | ワークスペース | 1 つのタブの内側 |
| タブを切り替えると | 他のペインはそのまま | 分割全体が一緒に切り替わります |
| タブストリップ | ペインごとに個別 | 1 つのタブで共有 |
| 左右 / 上下 | `Alt+E` / `Alt+Shift+E` | `Alt+D` / `Alt+Shift+D` |
| 次 / 前へのフォーカス | `Ctrl+]` / `Ctrl+[` | `Alt+]` / `Alt+[` |
| 閉じる | `Ctrl+Shift+W` | `Alt+W` |

- エージェントの画面を片側に開いたまま、もう片側のタブを切り替えて作業するには、**ペインを分割**を使用してください。
- 同じタスクのログとエディタを並べて一緒に切り替えるには、**サーフェスを分割**を使用してください。

新しい区画のターミナルは、元の区画の作業ディレクトリで開始します（**設定** > **ターミナル** > **作業ディレクトリを継承**）。区画間の境界をドラッグすると比率が変わります。

タブストリップ右側の分割アイコンは、そのペインを左右に分割します。別の種類のサーフェスに分割するには、CLI を使用してください。

```sh
tasty split --level pane --pane 1 --direction horizontal
tasty split --level surface --surface 5 --type markdown --file notes.md
tasty split --level surface --surface 5 --type explorer --path ~/proj
```

## タブ

### 作成・閉じる

- `+` ボタンまたは `Alt+T` — 新しいターミナルタブです。
- `+` を右クリック > **プリセットからタブを作成...** <!-- en: Create tab from preset... --> / **プリセットからペインを作成...** <!-- en: Create pane from preset... -->。
- タブストリップの空いている場所を右クリック > **新規ターミナル** <!-- en: New Terminal --> · **新規マークダウン...** <!-- en: New Markdown... --> · **新規HTML...** <!-- en: New HTML... --> · **新規画像** <!-- en: New Image --> で新しいタブを作成します。**新規HTML...** は、ファイル選択ウィンドウで HTML · SVG ファイルを選ぶと、そのペインにタブを開きます。同じメニューには **ペインプリセットとして保存** <!-- en: Save as pane preset -->、**プリセットからタブを作成...** <!-- en: Create tab from preset... -->、**プリセットからペインを作成...** <!-- en: Create pane from preset... --> もあります。種類ごとの説明は[ファイルの管理と表示](files.md)を参照してください。
- タブの `×`、タブを右クリック > **タブを閉じる** <!-- en: Close Tab -->、または `Ctrl+W`。ペインに最後に残ったタブは閉じられません。ペインごと閉じるには、ペインを閉じる（`Ctrl+Shift+W`）を使用してください。

```sh
tasty list panes
tasty new tab --pane 1 --cwd ~/proj
tasty new tab --pane 1 --type html --url https://example.com
tasty list tabs --pane 1
tasty close tab --tab 7
```

### 切り替え・順序

- クリック、または `Ctrl+1` ～ `Ctrl+9`、`Ctrl+0`（10 番目）。`Ctrl` を押したままにすると、タブに番号が表示されます。
- `Ctrl+L` / `Ctrl+H` — 次 / 前のタブです。**次のタブ** <!-- en: Next tab --> / **前のタブ** <!-- en: Previous tab --> のショートカットは、OS と重複しないよう既定値が空になっています。
- ドラッグで順序を変更します。タブを右クリック > **左へ移動** <!-- en: Move Left --> / **右へ移動** <!-- en: Move Right --> でも変更できます。
- タブが収まりきらないと左右の矢印が表示されます。ショートカットで切り替えると、アクティブなタブが見えるように自動でスクロールします。

### 名前と表示

タブ名は優先順位に従って決まります — 自分で指定した名前 > プログラムが設定したウィンドウタイトル > シェルの現在のディレクトリ。

- タブを右クリック > **タブ名の変更** <!-- en: Rename Tab -->、または `F2`。指定すると、ディレクトリを移動しても変わりません。
- **緑の点** — シェル以外のプログラムが出力している状態です。プロンプトで待機しているときやプログラムが停止しているときは消えます。ターミナルタイトルだけを変える出力は数えないため、入力を待ちながらタイトルだけを点滅させるプログラム（例: Codex の質問待ち）でも消えます。
- **黄色の名前** — プログラムが入力を待っています。**青色の名前** — タスクが終了しました。そのサーフェスをクリックすると元の色に戻ります。

タブの幅と文字サイズは設定ウィンドウに項目がなく、`~/.tasty/config.toml` の `[appearance]` 配下にある `tab_width` · `tab_font_size` で変更します。

### 再起動後に表示されないタブ

レイアウトを復元するとき、画面に表示されていないタブのシェルはすぐには起動せず、そのタブを初めて開いたときに開始します。`tasty list surfaces` には `pty_ready: false` と表示され、開かずに先に起動するには `tasty wake --surface <ID>` を使用してください。

## サーフェスを移動する

使用中のサーフェスを別のタブ、ペイン、ワークスペースに移動できます。ターミナルの場合は、実行中のプログラムとスクロールバックがそのまま引き継がれます。

1. 移動するサーフェスの空いている場所を右クリック > **サーフェスを移動** <!-- en: Move Surface -->。サーフェスを切り取ったことを知らせる通知が、そのサーフェスの上に一時的に表示されます。
2. 移動先のサーフェスの空いている場所を右クリック > **サーフェスをここへ移動** <!-- en: Move Surface Here -->。この項目はサーフェスを切り取っている間だけ表示されます。

切り取ったものは 1 つだけ記憶します。別のものを切り取ると、前のものは忘れます。

移動先のサーフェスは閉じられ、移動してきたサーフェスがその場所に入ります。空のターミナルを先に作成して移動先にしてください。マウスを捕捉するプログラム（vim など）の上では `Shift+右クリック` を使用してください。

## タブを移動する

1 つのタブを内側の分割とともに、別のペインやワークスペースに移動します。ターミナルの実行中のプログラムとスクロールバックがそのまま引き継がれます。

1. 移動するタブを右クリック > **タブを移動** <!-- en: Move Tab -->。タブを切り取ったことを知らせる通知が、そのペインの上に一時的に表示されます。
2. 移動先のタブを右クリック > **タブをここへ移動** <!-- en: Move Tab Here -->。この項目は別のタブを切り取っている間だけ表示されます。

移動先のタブは内側のサーフェスとともに閉じられ、移動してきたタブがその場所に入ります。移動したタブが元のペインの最後のタブだった場合はそのペインが閉じられ、ワークスペースの最後のペインだった場合はワークスペースが閉じられます。リモートワークスペース（attach で接続した場所）のタブは移動できません。切り取ったものは同じウィンドウ内でのみ移動できます。

## ペインを移動する

1 つのペインを内側のすべてのタブとともに、別の分割位置や別のワークスペースに移動します。ターミナルの実行中のプログラムとスクロールバックがそのまま引き継がれます。

1. 移動するペインのいずれかのタブを右クリック > **ペインを移動** <!-- en: Move Pane -->。ペインを切り取ったことを知らせる通知が、そのペインの上に一時的に表示されます。
2. 移動先のペインのタブを右クリック > **ペインをここへ移動** <!-- en: Move Pane Here -->。この項目は別のペインを切り取っている間だけ表示されます。

移動先のペインは内側のタブとともに閉じられ、移動してきたペインが同じサイズでその場所に入ります。元の場所は隣のペインが広がって埋めます。移動したペインがワークスペースの最後のペインだった場合は、そのワークスペースが閉じられます。リモートワークスペースのペインは移動できず、同じウィンドウ内でのみ移動できます。

## 切り取ったものを見分ける

切り取ったサーフェス・タブ・ペインには、内側にピンクの点線の枠が表示されます。サーフェスはそのサーフェスの区画、タブはタブタイトルの区画、ペインはタブの行を含むペイン全体を囲みます。他の枠はすべて実線なので、点線で見分けられます。通知の枠があるサーフェスでは、点線の間から元の枠が見えます。

切り取ったものが現在の画面にない場合は、それを含む場所に移動アイコンが表示されます。

- 表示されていないタブの中にある場合は、そのタブタイトルの後ろです。
- 別のワークスペースにある場合は、サイドバーのそのワークスペースの行です。サイドバーを折りたたんでいる場合は、アバターの左下です。

タブが多く、タブの行が横にスクロールされているとき、切り取ったタブ、または切り取ったサーフェスを含むタブ（そのタブがアクティブなタブではない場合）がタブの行の外にあると、そのタブがある側のタブの行の矢印がピンクに変わります。切り取ったサーフェスがアクティブなタブ内にある場合は、サーフェスの枠がすでに画面に見えているため、矢印は変わりません。タブがタブの行に完全に収まると、矢印は元の色に戻り、タブの表示が見えるようになります。ピンクの矢印を押しても、通常どおり 1 区画ずつだけスクロールします。

表示は移動を完了するか、別のものを切り取るか、切り取ったものを閉じると消えます。別のタブやワークスペースに移動しても残り、クリックを妨げません。

## 種類を変更する

`Alt+'` を押すと **サーフェスタイプ切替** <!-- en: Surface Type --> ポップアップが表示されます。現在のサーフェスをその場で **ターミナル** <!-- en: Terminal --> · **エクスプローラー** <!-- en: Explorer --> · **マークダウン** <!-- en: Markdown --> · **HTML...** · **画像** <!-- en: Image --> · **DAG** に変更します。方向キーと `Enter`、または行の右側に表示される文字で選んでください。文字のない行は方向キーかクリックで選んでください。現在の種類は一覧に表示されません。空のサーフェス中央のボタンも同じポップアップです。

- エクスプローラーに変更すると、ターミナルの現在のディレクトリをルートとして開きます。
- マークダウン · HTML はファイルパス · URL を尋ねます。
- 以前の内容は失われます。ターミナル → エクスプローラー → ターミナルと戻しても、シェルセッションは新しく開始します。
- ポップアップが表示されている間、暗くなるのは **そのサーフェス 1 区画**だけです。隣の区画で実行中のタスク、サイドバー、ステータスバーはそのまま見えます。

**マークダウンに切り替え** <!-- en: Convert to Markdown --> · **エクスプローラーに切り替え** <!-- en: Convert to Explorer --> は、ポップアップなしで直接変更するショートカットで、既定値は空になっています。

## 全画面

通知ウィンドウのタイトルバーにある全画面ボタン（ツールチップは **全画面で表示** <!-- en: Show fullscreen -->）を押すと、Tasty ウィンドウがモニターを覆い、通知一覧だけが大きく表示されます。`Esc` または右上の終了ボタンで抜けてください。抜けると、ウィンドウのサイズとターミナルのグリッドは全画面に入る前のままです。現在、全画面表示は通知一覧で使用できます。

## レイアウトの保存 — プリセット

よく使う配置をプリセットとして保存しておき、新しいワークスペース・タブ・ペインを作成するときに呼び出して使用します。保存されるのは分割構造と、各区画の種類・作業ディレクトリ・起動コマンド・ファイルパス・URL です。

プリセットは配置と起動設定を新しい作業に適用します。実行中のプロセスは複製しません。以前の作業の配置と履歴を復元する方法は、[ワークスペースの復元案内](workspaces.md#再起動後の復元)を参照してください。

### 保存

- ワークスペース — サイドバーのカードを右クリック > **ワークスペースプリセットとして保存** <!-- en: Save as workspace preset -->。
- タブ — タブを右クリック > **タブプリセットとして保存** <!-- en: Save as tab preset -->。
- ペイン — タブストリップの空いている場所を右クリック > **ペインプリセットとして保存** <!-- en: Save as pane preset -->。

ファイルは `~/.tasty/presets/{workspace,tab,pane}/<名前>.toml` に作成されます。同じ名前がある場合は、`-2` のように末尾に番号が付きます。

読み込み後に別のエディタで変更されたファイルや、破損して読み込めなかったファイルは、保存で上書きせずにエラーを通知します。外部での変更内容を確認したうえで、アプリを開き直して読み込んでください。

名前の変更中に新しいファイルを保存した後、以前のファイルを削除できないとエラーになり、両方の名前が残ることがあります。一覧とファイルを確認してから、残す名前を決めてください。

プリセットの保存、名前の変更、削除中は、エディタへの入力が一時的に無効になります。ファイル処理が終わると再び編集できます。保存に失敗した場合はエラーを通知し、編集中の設定と選択を保持します。複数の変更のうち一部だけ保存された場合は、保存済みの変更は残ります。

### 編集

サイドバーの **ツール** <!-- en: Tools --> > **プリセット** <!-- en: Presets --> を開くと、**レイアウトプリセット** <!-- en: Layout Presets --> ウィンドウが表示されます。

- 上部のタブで **ワークスペース** / **タブ** / **ペイン** を選び、左側の一覧からプリセットを選んでください。
- 右側に構造のプレビューが表示されます。ツールバーには **名前の変更** <!-- en: Rename --> · **複製** <!-- en: Duplicate --> · **削除** <!-- en: Delete --> があります。
- **編集** <!-- en: Edit --> を押すと、プレビュー上で構造を直接変更します — 区画の端にマウスを重ねると表示される帯をクリックしてその方向に分割し、区画の中央をクリックして選択してから右上のごみ箱ハンドルで削除し、`+` / `×` でタブを追加・削除してください。選択した区画では、本体と同じ分割・閉じるショートカットも動作します。
- 構造を変更すると、保存ボタンなしで自動的に保存を要求します。**自動保存** <!-- en: automatic saving --> は、この保存方式を知らせる案内です。**完了** <!-- en: Done --> で抜けてください。
- 区画の種類・作業ディレクトリ・起動コマンドは、**サーフェス設定** <!-- en: Surface settings --> 画面で変更します。選択した区画の歯車ハンドルを押すか、区画をダブルクリックすると、右側の領域全体がその区画の設定画面になります。区画がどれほど小さくても、すべての入力欄が表示されます。
  - 値を変更すると上部に **未保存** <!-- en: unsaved --> が表示され、下部の **OK** <!-- en: OK --> を押すと保存されます。**キャンセル** <!-- en: Cancel --> または `Esc` は変更した値を破棄します。入力欄で `Enter` を押しても確定します。
  - 設定画面が開いている間は、左側の一覧と上部のタブが薄く表示され、クリックできません。確定またはキャンセルするとプレビューに戻り、その区画は選択されたままになります。
- **新規プリセット** <!-- en: New preset --> は、ターミナル 1 つだけの空のプリセットを作成します。

### 適用

- **新しいワークスペース** ボタンを右クリック > **プリセットからワークスペースを作成...** <!-- en: Create workspace from preset... -->。
- タブストリップの `+` を右クリック > **プリセットからタブを作成...** / **プリセットからペインを作成...**。
- **ワークスペースプリセット適用** <!-- en: Apply workspace preset --> など 3 つのショートカットは、既定値が空になっています。割り当てると選択ポップアップが表示されます。

ターミナルの区画に起動コマンドがある場合は、シェルが起動するとすぐに 1 行入力されます。

```sh
tasty preset list --kind workspace
tasty preset capture --kind workspace --source-id 2 --name dev
tasty preset apply --kind workspace --name dev
tasty preset apply --kind tab --name logs --target-pane 1
```

CLI で適用すると、フォーカスは移動しません。再起動時の自動復元と閉じた項目の復元については、[ワークスペース](workspaces.md#再起動後の復元)にあります。
