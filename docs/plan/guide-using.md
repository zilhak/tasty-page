# 기본 사용과 배치

가이드의 한국어·영어 페이지를 함께 둔다. 각 페이지의 역할과 범위는 아래와 같다.

## 워크스페이스

- 사이트 소스: [한국어](../../content/using/workspaces.md) · [영어](../../content/en/using/workspaces.md)
- 역할: 프로젝트 단위 관리와 복원.
- 보여 줄 항목: 생성, 이름·부제, 카테고리, 전환, 닫기, 닫은 항목 복원과 재시작 복원의 구별.
- 넣지 않을 항목: 프리셋 편집 상세, 과거 저장 파일을 현재 저장 원본으로 설명.
- 구성: 닫은 항목 복원, 재시작 시 배치·기록 복원, 프로그램 세션 재개를 구별한다. 닫기 기록의 가용 예산과 실행 중 저장 중단의 차이를 보여 준다.

## 작업 배치 만들고 다시 쓰기

- 사이트 소스: [한국어](../../content/using/workflow-layouts.md) · [영어](../../content/en/using/workflow-layouts.md)
- 역할: 한 가지 완결된 배치 실습.
- 보여 줄 항목: 구현·테스트 예시, 문서 탭, 프리셋 저장·적용, 경로·시작 명령 점검.
- 넣지 않을 항목: 전체 단축키 표, 모든 프리셋 조작, OS 간 환경 자동 동기화 약속.
- 구성: 배치 생성부터 프리셋 재사용까지 이어지는 실습을 두고, 다른 OS에서 경로·셸·도구를 점검할 항목을 보여 준다.

## 페인 · 탭 · 분할

- 사이트 소스: [한국어](../../content/using/panes-tabs-splits.md) · [영어](../../content/en/using/panes-tabs-splits.md)
- 역할: 배치 조작의 참조.
- 보여 줄 항목: 두 단계 분할, 생성·닫기, 이동, 종류 전환, 프리셋, 지원 대상의 전체화면 무대.
- 넣지 않을 항목: 코드 편집기 내장 암시, 모든 서피스의 전체화면 확대 약속.
- 구성: 페인 분할과 서피스 분할의 차이를 먼저 보여 주고, 프리셋과 닫은 항목 복원을 별개로 다룬다.

## 터미널 다루기

- 사이트 소스: [한국어](../../content/using/terminal.md) · [영어](../../content/en/using/terminal.md)
- 역할: 일상 터미널 조작의 참조.
- 보여 줄 항목: 현재 셸·선택·검색·클립보드·입력 조합·지원 제약·앱 안 알림.
- 넣지 않을 항목: CLI 전문 참조, 앱 알림을 OS 알림 센터 전송으로 소개.

## 파일 관리와 보기

- 사이트 소스: [한국어](../../content/using/files.md) · [영어](../../content/en/using/files.md)
- 역할: 파일 작업과 종류별 뷰어 안내.
- 보여 줄 항목: 탐색기, 파일 작업과 결과, 마크다운·이미지·HTML, Git 보기, 차단된 콘텐츠의 실제 안내.
- 넣지 않을 항목: IDE·범용 브라우저로 소개, 모든 파일 편집 가능 주장, 탐색기를 플러그인으로 분류.
- 구성: 파일 열기, 탐색기 관리, 종류별 뷰어, 문제 해결 순서로 안내한다. 탐색기 하위 항목은 기존 앵커로 연결하고 파일 작업 실패·충돌·원격 제약 및 HTML 콘텐츠·스크립트 차단을 포함한다.
