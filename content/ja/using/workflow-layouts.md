# 作業用レイアウトを作成して再利用する

Tasty では、実装・テスト・文書をペインに分けて配置し、そのレイアウトをプリセットとして保存して次のタスクで再利用できます。ペインごとにタブを個別に切り替えるため、別のペインのテストログを表示したまま文書を確認できます。

<!-- tasty-diagram: workflow-layout -->
```
左のペイン: 実装用ターミナル | 右のペイン: テスト用ターミナル
各ペインのタブは個別に切り替えます。
```

## 1. 作業スペースを分ける

1. プロジェクトのワークスペースを開き、ターミナルでプロジェクトのディレクトリに移動してください。
2. `Alt+E` でペインを左右に分割してください。Tasty のデフォルトのショートカットを基準としています。変更した場合は、[キーバインドの設定](../customize/keybindings.md)を確認してください。
3. 一方で実装し、もう一方でプロジェクトのテストコマンドを実行してください。

ペインごとにタブを個別に切り替えられるため、テストログを残したまま、もう一方で文書を確認するのに便利です。複数の画面を 1 つのタブにまとめて一緒に切り替えたい場合は、[サーフェスの分割](panes-tabs-splits.md)を使ってください。

## 2. 文書を手元に置く

文書を表示するペインのタブストリップの空いている場所を右クリックし、**新規マークダウン...** を選択してプロジェクトの README を開いてください。ターミナルに戻るには、同じペインのターミナルタブをクリックします。別のペインのテスト画面はそのまま残ります。

画像や HTML の出力結果も、[ファイルの管理と表示](files.md)で案内するビューアで確認できます。作業用レイアウトは、実行と結果の確認を近くに配置するためのもので、ファイルエディタやウェブブラウザのすべての機能を代替するものではありません。

## 3. 現在のレイアウトをプリセットとして保存する

1. サイドバーのワークスペースを右クリックしてください。
2. **ワークスペースプリセットとして保存** を選択してください。
3. **ツール > プリセット** で、保存されたワークスペースプリセットを確認してください。
4. **編集** で各区画の種類、作業ディレクトリ、起動コマンドを確認してください。構造の変更は自動保存され、区画の設定は **OK** をクリックすると保存されます（[編集](panes-tabs-splits.md#編集)）。

起動コマンドは、新しいターミナルが開くときに実行されます。自動実行が不要な区画では空欄にしてください。別のプロジェクトでも使うレイアウトの場合は、先にパスとコマンドを合わせてください。

区画設定のディレクトリ・ファイルフィールドの横にある **参照…** は、プリセット内の Tasty ピッカを開きます。フォルダーの場合は選択したサブフォルダーまたは現在のフォルダーを、ファイルの場合は一覧から選んだファイルを確定します。結果はそのフィールドにだけ入り、**OK** をクリックすると保存されます。ピッカで Esc を押すとピッカだけが閉じ、編集中の設定は残ります。

## 4. 新しいタスクで再利用する

**新しいワークスペース** ボタンを右クリックし、**プリセットからワークスペースを作成...** を選択してください。保存したプリセットを選んだ後、各ターミナルが意図したディレクトリで起動したかを確認してください。

プリセットはレイアウトと起動設定を再利用します。実行中のプロセスは複製しません。アプリを再度開いたときの[レイアウトと履歴の復元](workspaces.md)は別の機能です。

<a id="すべての-os-で同じ環境を使ってください"></a>

## 別の OS でレイアウトを使う場合

Windows、macOS、Linux でワークスペース・ペイン・タブを使ってレイアウトを構成する方法は同じです。ファイルパス、シェルコマンド、インストールされているツールは、各環境に合わせて設定してください。

## エージェントと一緒に使うには

一方に [Claude Code や Codex CLI](../agents/claude-codex.md) を接続し、もう一方で自分の作業を続けてください。エージェントがバックグラウンドタブを作成しても、自分が見ていた画面のフォーカスや選択・スクロールは変わりません。

タブなしで実行していたタスクを後から見たい場合は、[バックグラウンドタスクをタブに取り込む](../agents/background-tasks.md)を参照してください。
