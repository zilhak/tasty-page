# 기본 사용과 배치

가이드 페이지는 영어, 한국어, 일본어, 중국어 간체로 함께 둔다. 각 페이지의 역할과 범위는 아래와 같다.

## 워크스페이스

- 사이트 소스: [한국어](../../content/using/workspaces.md) · [영어](../../content/en/using/workspaces.md)
- 역할: 프로젝트 단위 관리와 복원.
- 보여 줄 항목: 이름·부제 입력과 강제 끊기 확인 팝업의 현재 윈도우 중앙 표시, 대상 워크스페이스로 전환하지 않는 동작과 전환 후에도 표시 유지, 강제 끊기 재요청 시 대상 변경과 다시 열기, 생성, 이름·부제, 카테고리, 전환, 닫기, 닫은 항목 복원과 재시작 복원의 구별.
- 사이드바 메뉴에서 보여 줄 항목: 로컬 워크스페이스 카드에만 표시하는 구분선과 강제 끊기 항목, 점유 여부에 따른 활성·비활성 상태.
- 새 워크스페이스에서 보여 줄 항목: 입력 시점에 선택한 서피스의 작업 폴더를 생성 시점에 읽기, 원본이 mirror의 서피스이거나 닫혔을 때 새 로컬 워크스페이스의 터미널을 홈 폴더에서 시작.
- 닫은 항목 복원에서 보여 줄 항목: 단축키·명령 팔레트·더블탭의 입력 시점 페인, 포커스 이동이나 선택했던 서피스 닫힘 뒤에도 같은 페인에서 복원, 페인 닫힘 시 복원 생략.
- 넣지 않을 항목: 프리셋 편집 상세, 과거 저장 파일을 현재 저장 원본으로 설명.
- 구성: 닫은 항목 복원, 재시작 시 배치·기록 복원, 프로그램 세션 재개를 구별한다. 닫기 기록의 가용 예산과 실행 중 저장 중단의 차이를 보여 준다.

## 작업 배치 만들고 다시 쓰기

- 사이트 소스: [한국어](../../content/using/workflow-layouts.md) · [영어](../../content/en/using/workflow-layouts.md)
- 역할: 한 가지 완결된 배치 실습.
- 보여 줄 항목: 구현·테스트 예시, 문서 탭, 프리셋 저장·적용, 경로·시작 명령 점검.
- 넣지 않을 항목: 전체 단축키 표, 모든 프리셋 조작, OS 간 환경 자동 동기화 약속.
- 구성: 배치 생성부터 프리셋 재사용까지 이어지는 실습을 두고, 다른 OS에서 경로·셸·도구를 점검할 항목을 보여 준다.

## 페인 · 탭 · 분할

- 사이트 소스: [한국어](../../content/using/panes-tabs-splits.md) · [영어](../../content/en/using/panes-tabs-splits.md)
- 역할: 배치 조작의 참조.
- 보여 줄 항목: 탭 이름 바꾸기 팝업의 탭 바를 포함한 페인 영역 표시와 같은 페인에서 대상만 변경과 다른 페인에서 개별 표시, 탭 프리셋 적용 팝업의 페인 영역 표시, 페인 프리셋 적용 팝업의 사이드바·상태 표시줄을 제외한 워크스페이스 영역 중앙 표시와 워크스페이스 전환·복귀 시 숨김·재표시, 페인 닫힘에 따른 관련 팝업 닫힘과 대상 탭 닫힘에 따른 탭 프리셋 팝업 닫힘, 프리셋 적용 재요청 시 대상 변경과 다시 열기, 서피스 종류 전환 팝업의 서피스별 개별 표시, 두 단계 분할, 생성·닫기, 이동, 종류 전환, 프리셋, 지원 대상의 전체화면 무대.
- 이동 메뉴에서 보여 줄 항목: 서피스 이동 메뉴를 열 수 있는 대상, 옮길 항목이 없어도 표시되는 서피스·탭·페인의 목적지 지정 항목, 잘라 둔 항목 유형에 따른 활성 상태, 잘라 둔 탭·페인 자체에서의 비활성 상태, 잘라 둔 서피스에서 이동 대기 취소.
- 팝업에서 보여 줄 항목: 팝업이 서피스·탭·페인·워크스페이스에 들어가지 않을 때의 접기와 버튼 표시, 윈도우 전체 팝업의 접기 제외, 버튼 클릭 또는 접힌 팝업에 키보드 포커스가 있을 때 Enter·Space로 펼치기, 원래 자리가 넓어져도 펼친 상태 유지, 제목줄 버튼·Esc로 접기와 입력 유지, 윈도우보다 큰 팝업의 테두리·제목줄·버튼 표시와 오른쪽·아래 내용 잘림, 펼친 팝업에서 연 파일 선택의 펼침과 함께 접기.
- 팝업이 덮는 곳에서 보여 줄 항목: 펼친 팝업의 윈도우 전체 덮음, 펼치지 않은 팝업의 서피스 한 칸·탭 바 아래 영역·사이드바와 상태 표시줄을 제외한 워크스페이스 표시 위치와 덮는 영역, 메뉴·안내 예외와 저장된 원격 워크스페이스 연결 팝업의 빈 워크스페이스·마지막 화면 구분, 덮인 곳의 클릭·휠·마우스 이동·파일 놓기, 터미널의 마우스 이동 보고·링크 강조·링크 복사 제한과 마우스 버튼을 놓을 때 전달되는 곳, 윈도우 테두리에서의 크기 조절과 팝업 유지.
- 팝업 포커스에서 보여 줄 항목: 다른 서피스를 눌렀을 때 유지, 누르기 직전 포커스 위치에 따른 첫 클릭과 바깥 클릭 구분, 닫기·덮음 여부에 따른 바깥 클릭 결과, 키를 받는 펼친 팝업의 윈도우 안 바깥 클릭과 닫기, 위에 있는 팝업이 받은 클릭의 처리, 여러 곳의 포커스 유지와 맨 위 팝업만 받는 키, Esc로 펼친 팝업 먼저 접기와 아래 알림 목록·팝업 유지, Esc 한 번에 팝업 하나 닫기 또는 종류에 따라 포커스만 풀기, 서피스·탭·페인·워크스페이스 팝업의 위쪽 포커스 막대와 키보드 포커스가 있는 접힌 팝업 틀 위쪽의 표시 및 펼친 팝업·윈도우 전체 팝업 제외, 두 버튼의 Tab 포커스와 툴팁.
- 분할과 새 탭에서 보여 줄 항목: 탭 바의 분할 버튼이 있는 페인과 그 페인의 선택된 서피스, 단축키·명령 팔레트·더블탭의 입력 시점 대상, 페인 분할·새 탭의 대상 페인 닫힘 시 실행 생략, 로컬 페인 분할의 원본 서피스 닫힘 시 상속 없이 분할, 서피스 분할의 대상 서피스 닫힘 시 실행 생략, 탭 바 + 버튼과 페인 메뉴의 새 탭에서 작업 폴더를 물려받는 원본 서피스, 터미널로 변환할 때 이전 서피스의 작업 폴더 유지.
- 넣지 않을 항목: 코드 편집기 내장 암시, 모든 서피스의 전체화면 확대 약속.
- 구성: 페인 분할과 서피스 분할의 차이를 먼저 보여 주고, 프리셋과 닫은 항목 복원을 별개로 다룬다.

## 터미널 다루기

- 사이트 소스: [한국어](../../content/using/terminal.md) · [영어](../../content/en/using/terminal.md)
- 역할: 일상 터미널 조작의 참조.
- 보여 줄 항목: 처리기 선택·마우스 캡처 메뉴가 열리는 위치와 서피스별 개별 표시, 현재 셸·선택·검색·클립보드·입력 조합·지원 제약·앱 안 알림. 셸 설정에서는 Windows가 Git Bash만 지원한다는 범위와 기본 설치 위치 밖 Git Bash의 경로 지정을 다룬다.
- 우클릭 메뉴에서 보여 줄 항목: 메뉴 맨 앞의 복사 두 항목과 텍스트 선택이 없을 때의 비활성 상태.
- 작업 디렉토리 상속에서 보여 줄 항목: 새 탭·분할·워크스페이스의 입력 시점에 선택한 서피스, 생성 시점 작업 폴더 읽기와 원본 터미널에서 그사이 cd한 경우, 로컬에서 읽기 전 원본 서피스 닫힘 시 상속 생략과 원격 가이드 연결, 마크다운·이미지·HTML 파일이 든 폴더와 탐색기의 루트 폴더.
- 로컬 파일 링크에서 보여 줄 항목: 클릭·우클릭 열기의 결과 탭이 열리는 페인, 처리 중 포커스 이동과 페인 닫힘.
- 넣지 않을 항목: CLI 전문 참조, 앱 알림을 OS 알림 센터 전송으로 소개, Windows에서 Git Bash가 아닌 셸의 우회·설정 예시.

## 파일 관리와 보기

- 사이트 소스: [한국어](../../content/using/files.md) · [영어](../../content/en/using/files.md)
- 역할: 파일 작업과 종류별 뷰어 안내.
- 보여 줄 항목: 파일 선택 창·처리기 선택 창이 열리는 위치, 파일 선택의 열리는 자리 구분(새 탭 버튼 메뉴는 페인, 사이드바 도구 메뉴는 윈도우 전체, 플러그인·마크다운 주소창 폴더 버튼은 서피스, 플러그인 팝업은 연 팝업과 같은 곳), 펼친 팝업에서 연 파일 선택과 함께 접는 동작을 팝업 절로 연결, 파일 선택 내용이 원래 자리에 보일 때 Esc 닫기, 윈도우를 닫으면서 플러그인 팝업도 닫힐 때 위치와 관계없이 그 팝업에서 연 파일 선택 취소, 다른 자리에서 동시 파일 선택과 요청별 결과 전달, 같은 자리의 중복 파일 선택 거절과 직접 요청 시 안내 토스트, 같은 페인에서 탭 전환 후 새 탭 버튼 메뉴 재요청과 도구 메뉴 재요청 시 개별 표시하지 않는 동작, 처리기 선택의 서피스별 개별 표시와 같은 서피스 재요청 시 대상 변경, 탐색기 속성·이름 충돌 질문·탐색기 항목의 이름 바꾸기 팝업의 서피스별 개별 표시, 탐색기, 파일 작업과 결과, 마크다운의 큰 파일 확인 팝업이 좁은 서피스에서 접힐 때 팝업 절로 연결, 마크다운·이미지·HTML, Git 보기, 차단된 콘텐츠의 실제 안내.
- 탐색기 우클릭 메뉴에서 보여 줄 항목: 빈 곳·단일 폴더에 표시되는 붙여넣기 항목과 비활성 상태, 이유를 확인하는 방법, 원격 탐색기의 실행 취소·다시 실행·시스템 열기·파일 관리자에서 보기·새 탭 열기 비활성 상태, 즐겨찾기 메뉴의 새 탭 열기 비활성 상태, 원격 즐겨찾기 추가 시 알림, 파일 관리자에서 보기의 단일 선택 범위, 대상이 사라진 로컬 링크의 폴더 보기 비활성 상태와 대상 경로 및 검색 결과에서 열기 미표시, 이유가 있는 항목의 Linux·macOS 툴팁과 Windows 메뉴의 툴팁 미표시.
- 결과 탭에서 보여 줄 항목: 도구 메뉴·단축키의 파일 열기, 파일 끌어 놓기(탭 바 포함), 터미널의 로컬 파일 링크가 열리는 페인, 포커스 이동 뒤 대상 유지, 페인 닫힘 시 열기 생략, 지정된 서피스가 있는 파일 열기의 결과 페인과 다른 윈도우로 전환할 때 대상 유지 및 페인이 남아 있어도 지정된 서피스가 닫히면 열기 생략, 탐색기에서 연 파일의 결과 페인.
- 탐색기·마크다운·HTML에서 보여 줄 항목: 탐색기의 새 탭으로 열기에서 선택한 폴더 사용, 명령 팔레트의 새 마크다운에서 Enter 시점의 페인·서피스 및 대상 닫힘 시 열기 생략, HTML 파일 탭에서 새 탭·분할 시 파일이 든 폴더 상속.
- 넣지 않을 항목: IDE·범용 브라우저로 소개, 모든 파일 편집 가능 주장, 탐색기를 플러그인으로 분류.
- 구성: 파일 열기, 탐색기 관리, 종류별 뷰어, 문제 해결 순서로 안내한다. 탐색기 하위 항목은 기존 앵커로 연결하고 파일 작업 실패·충돌·원격 제약 및 HTML 콘텐츠·스크립트 차단을 포함한다.
