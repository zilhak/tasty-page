# 맞춤 설정

가이드 페이지는 영어, 한국어, 일본어, 중국어 간체로 함께 둔다. 각 페이지의 역할과 범위는 아래와 같다.

## 단축키

- 사이트 소스: [한국어](../../content/customize/keybindings.md) · [영어](../../content/en/customize/keybindings.md)
- 역할: 키 조합 선택·변경 참조.
- 보여 줄 항목: 수식키 힌트 팝업의 표시 대기 시간·Shift 단독 조건·저장된 위치가 없을 때 사이드바 하단 기본 위치·Win/Super의 단축키 또는 역할 조건, 위쪽 띠 이동·오른쪽 아래 그립 크기 변경·마우스 주 버튼을 놓을 때 끌기 종료, 위치와 크기의 `[modifier_hint]` `pos`·`size` 저장, HTML·마크다운 위 표시와 화면·키보드 포커스 유지, 시작 오류·설정 윈도우 열기 실패 등 Tasty의 안내 팝업과 원격 파일 전송 실패·다운로드 실패 팝업의 포커스 유무에 따른 Enter·Escape 닫기와 클릭·포커스 이동 후 키 사용, 복원 안내의 표시 시 포커스 유지와 카드 안 컨트롤에 포커스가 있을 때만 키 전달, Esc와 바깥 클릭의 동작을 팝업 절로 연결, 키를 받는 펼친 팝업과 알림 목록의 Esc 처리 순서, 기존 기본 키 표, 물리 위치 표기, 프리셋, 가져오기·내보내기, 빈 기본값, 플러그인 키, mirror의 새 탭 생성 대기 중 내장 동작 요약과 탐색기 목록 이동·선택·열기·선택 해제 키 제외 및 원격 가이드 연결, 명령 팔레트의 탭 하나 대상 동작에서 Enter 시점의 탭 선택과 해당 종류가 지원하지 않는 동작 제외, 탭 닫기·이름 변경·이동·프리셋·복사·잘라내기·붙여넣기의 Enter 시점 대상 선택, 새 워크스페이스의 카테고리 선택, 페인·서피스 분할·새 탭·닫은 항목 복원·탐색기 열기·새 탭에서 여는 마크다운의 Enter 시점 대상 선택과 포커스 이동 뒤 대상 유지 및 대상 닫힘 시 실행 생략, 페인 분할·새 탭·닫은 항목 복원에서 페인이 남아 있으면 선택했던 서피스가 닫혀도 실행, 로컬 페인 분할의 원본 서피스 닫힘 시 상속 생략, 서피스 분할의 대상 서피스 닫힘 시 실행 생략, 새 마크다운의 Enter 시점 작업 폴더 원본 서피스, HTML·마크다운 페이지의 내장 단축키 대상과 F2의 탭 이름 변경 예시.
- 넣지 않을 항목: 모든 셸·OS 자체 단축키도 Tasty에서 바꾼다는 주장.
- 구성: 프리셋 선택, 단축키 편집과 가져오기·내보내기를 다룬다. 내보내기 중 버튼 비활성화와 인접 진행 표시, 완료 안내의 표시 조건을 포함한다.

## 설정

- 사이트 소스: [한국어](../../content/customize/settings.md) · [영어](../../content/en/customize/settings.md)
- 역할: 설정의 목적별 길찾기.
- 보여 줄 항목: 설정 열기, 목적별 탭·반영 조건, 터미널 탭의 마지막 섹션인 프레임 레이트와 출력·입력 두 항목의 용도·기본값, 연결된 모니터의 최고 주사율 반올림 및 주사율을 알 수 없을 때의 60 Hz 기준·선택지·모니터에 맞춤·주사율을 초과한 저장값의 표시와 선택 유지, 윈도우가 있는 모니터의 주사율에 따른 실제 다시 그리기 상한, 입력 직후 같은 터미널의 에코 출력에 적용되는 입력 상한·쉬던 화면의 첫 입력 즉시 다시 그리기, 설정 윈도우에서 저장하면 열린 윈도우에 즉시 적용, 설정 파일의 `[performance]`에 있는 `output_redraw_fps`·`input_redraw_fps`의 허용값과 목록 밖 파일 값의 기본값 보정, 파일 직접 편집 후 재시작 적용, 주요 저장 위치, 언어팩은 뒤쪽 상세.
- 원격 연결에서 보여 줄 항목: 지원 버전 GUI로 연결할 때 내 쪽의 OSC 52 읽기 허용 설정과 설정 파일 섹션, 알림음 설정, GUI 서버와 헤드리스 서버에서 OSC·벨 알림 생성에 적용되는 설정의 위치, 원격 알림 가이드 연결.
- 넣지 않을 항목: 테마·단축키 전체 중복, 내부 자료를 사용자 편집 대상으로 안내.
- 구성: 목적별 길찾기와 기존 탭별 표를 유지한다. 원격 전송과 원격 Attach 설정을 구분하고, 무응답 시간의 기본값·범위·입력 확정 보정·파일 값 보정·새 연결 적용 범위를 보여 준다. 글꼴 값을 쓸 수 없을 때는 설정 윈도우 입력 칸 아래 오류 줄과 입력 중 숨김, 메인 윈도우 경고 알림이 뜨는 시점과 값마다 한 번이라는 범위, 에이전트가 적용한 값의 차이, 저장을 막지 않고 다른 글꼴로 표시한다는 점을 보여 준다.

## 테마

- 사이트 소스: [한국어](../../content/customize/themes.md) · [영어](../../content/en/customize/themes.md)
- 역할: 테마 선택부터 제작까지.
- 보여 줄 항목: Mocha·Latte, 테마 선택, 부분 색상 변경, 사용자 TOML, 오류와 복구.
- 넣지 않을 항목: 사이트 디자인 토큰 3단계 전체 설명, 번들 파일 직접 편집 권장.
- 구성: 기본 테마 선택, 부분 색 변경, 파일로 테마 제작을 구분하고 밝은 테마의 대비와 적용 범위를 보여 준다.

## Lua 스크립트

- 사이트 소스: [한국어](../../content/customize/scripts.md) · [영어](../../content/en/customize/scripts.md)
- 역할: 반복 조작을 등록하고 연결하기.
- 보여 줄 항목: 현재 등록 절차, 실제 이벤트와 함수, 파일 변경 확인, OS 접근과 실행 제약, 실패 안내.
- 넣지 않을 항목: init.lua 자동 실행 약속, 불신 코드를 안전하게 격리한다는 보장.
