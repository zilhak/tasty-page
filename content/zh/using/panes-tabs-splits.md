# 窗格、标签页和拆分

Tasty 的窗格拆分用于创建可独立切换标签页的区域，Surface 拆分用于划分同一标签页内共同显示的画面。根据所需布局选择这两种拆分方式。

以下快捷键以默认 **Tasty** 预设为准。在 macOS 上，将 `Alt` 视为 `Cmd`，将 `Ctrl` 视为 `Control`。

## 两级拆分——先选择

| | 拆分窗格 | 拆分 Surface |
|--|-----------|-------------|
| 拆分对象 | 工作区 | 一个标签页的内部 |
| 切换标签页时 | 其他窗格保持原样 | 整个拆分区域一起切换 |
| 标签栏 | 每个窗格独立 | 一个标签页共用 |
| 左右／上下 | `Alt+E` / `Alt+Shift+E` | `Alt+D` / `Alt+Shift+D` |
| 下一个／上一个焦点 | `Ctrl+]` / `Ctrl+[` | `Alt+]` / `Alt+[` |
| 关闭 | `Ctrl+Shift+W` | `Alt+W` |

- 若要在一侧保留智能体画面，在另一侧切换标签页进行操作，使用**拆分窗格**。
- 若要并排显示同一任务的日志和编辑器，并一起切换，使用**拆分 Surface**。

新区域的终端从原区域的工作目录启动（**设置** > **终端** > **继承工作目录**）。拖动区域之间的边界可调整比例。

标签栏右侧的拆分图标将该窗格左右拆分。若要拆分出其他种类的 Surface，使用 CLI。

```sh
tasty split --level pane --pane 1 --direction horizontal
tasty split --level surface --surface 5 --type markdown --file notes.md
tasty split --level surface --surface 5 --type explorer --path ~/proj
```

## 标签页

### 创建和关闭

- `+` 按钮或 `Alt+T`——新建终端标签页。
- 右键点击 `+`——**从预设创建标签页...** <!-- en: Create tab from preset... --> / **从预设创建窗格...** <!-- en: Create pane from preset... -->。
- 右键点击标签栏空白处——通过**新建终端** <!-- en: New Terminal --> · **新建 Markdown…** <!-- en: New Markdown... --> · **新建 HTML…** <!-- en: New HTML... --> · **新建图像** <!-- en: New Image --> 创建标签页。**新建 HTML…** 在文件选择窗口中选定 HTML · SVG 文件后，在该窗格中打开标签页。同一菜单中还有**保存为窗格预设** <!-- en: Save as pane preset -->、**从预设创建标签页...** <!-- en: Create tab from preset... -->、**从预设创建窗格...** <!-- en: Create pane from preset... -->。各种类的说明见[文件管理和查看](files.md)。
- 标签页的 `×`、右键点击标签页 > **关闭标签页** <!-- en: Close Tab -->，或 `Ctrl+W`。窗格中最后一个标签页无法关闭。若要关闭整个窗格，使用关闭窗格（`Ctrl+Shift+W`）。

```sh
tasty list panes
tasty new tab --pane 1 --cwd ~/proj
tasty new tab --pane 1 --type html --url https://example.com
tasty list tabs --pane 1
tasty close tab --tab 7
```

### 切换和顺序

- 点击，或使用 `Ctrl+1` ~ `Ctrl+9`、`Ctrl+0`（第 10 个）。按住 `Ctrl` 时，标签页上会显示编号。
- `Ctrl+L` / `Ctrl+H`——下一个／上一个标签页。**下一个标签页** <!-- en: Next tab --> / **上一个标签页** <!-- en: Previous tab --> 快捷键默认为空，以免与操作系统冲突。
- 拖动可调整顺序。也可右键点击标签页 > **左移** <!-- en: Move Left --> / **向右移动** <!-- en: Move Right -->。
- 标签页溢出时会出现左右箭头。使用快捷键切换时会自动滚动，使活动标签页可见。

### 名称和标记

标签页名称按以下优先级确定——手动指定的名称 > 程序设置的窗口标题 > Shell 的当前目录。

- 右键点击标签页 > **重命名标签页** <!-- en: Rename Tab -->，或 `F2`。指定后，即使切换目录也不会改变。
- **绿点**——Shell 以外的程序正在输出。等待提示符输入或程序停止活动时消失。仅更改终端标题的输出不计入，因此，等待输入时仅闪烁标题的程序（例如 Codex 等待问题回答）也不会显示绿点。
- **黄色名称**——程序正在等待输入。**蓝色名称**——任务已结束。点击该 Surface 后恢复原色。

设置窗口中没有标签页宽度和字号选项，需通过 `~/.tasty/config.toml` 的 `[appearance]` 下的 `tab_width` · `tab_font_size` 修改。

### 重启后不可见的标签页

恢复布局时，屏幕上不可见的标签页不会立即启动 Shell，而是在首次打开该标签页时启动。在 `tasty list surfaces` 中显示为 `pty_ready: false`，若要在不打开标签页的情况下提前启动，使用 `tasty wake --surface <ID>`。

## 移动 Surface

可将使用中的 Surface 移到其他标签页、窗格或工作区。若为终端，运行中的程序和回滚缓冲区会一并保留。

1. 右键点击要移动的 Surface 空白处 > **移动 Surface** <!-- en: Move Surface -->。该 Surface 上会短暂显示已剪切 Surface 的通知。
2. 右键点击目标 Surface 的空白处 > **将 Surface 移到此处** <!-- en: Move Surface Here -->。仅在已剪切 Surface 时显示此项。

只记住一个已剪切的项目。再次剪切其他项目会忘记前一个。

目标 Surface 会关闭，移入的 Surface 占据其位置。可先创建空终端作为目标。在捕获鼠标的程序（如 vim）上，使用 `Shift+右键点击`。

## 移动标签页

将一个标签页及其内部拆分移到其他窗格或工作区。终端中运行的程序和回滚缓冲区会一并保留。

1. 右键点击要移动的标签页 > **移动标签页** <!-- en: Move Tab -->。该窗格上会短暂显示已剪切标签页的通知。
2. 右键点击目标标签页 > **将标签页移到此处** <!-- en: Move Tab Here -->。仅在已剪切其他标签页时显示此项。

目标标签页及其内部 Surface 会关闭，移入的标签页占据其位置。若移动的标签页是原窗格的最后一个标签页，该窗格会关闭；若该窗格又是工作区的最后一个窗格，工作区也会关闭。远程工作区（通过 attach 连接的工作区）的标签页无法移动。已剪切的项目只能在同一窗口内移动。

## 移动窗格

将一个窗格及其全部标签页移到其他拆分位置或其他工作区。终端中运行的程序和回滚缓冲区会一并保留。

1. 右键点击要移动的窗格中的任意标签页 > **移动窗格** <!-- en: Move Pane -->。该窗格上会短暂显示已剪切窗格的通知。
2. 右键点击目标窗格中的标签页 > **将窗格移到此处** <!-- en: Move Pane Here -->。仅在已剪切其他窗格时显示此项。

目标窗格及其内部标签页会关闭，移入的窗格以相同大小占据其位置。相邻窗格会扩大以填满原位置。若移动的窗格是工作区的最后一个窗格，该工作区会关闭。远程工作区的窗格无法移动，且只能在同一窗口内移动。

## 识别已剪切的项目

已剪切的 Surface、标签页或窗格内侧会出现粉色点状边框。Surface 的边框围住其自身区域，标签页的边框围住标题区域，窗格的边框围住包含标签栏在内的整个窗格。其他边框均为实线，因此可通过点线区分。若 Surface 还有通知边框，可从点线间隙看到原边框。

若已剪切的项目不在当前屏幕上，其所在容器会显示移动图标。

- 若在不可见的标签页内，显示在该标签页标题后。
- 若在其他工作区内，显示在侧边栏中该工作区所在行。若侧边栏已折叠，显示在头像左下角。

标签页过多导致标签栏横向滚动时，若已剪切的标签页，或包含已剪切 Surface 的标签页（该标签页不是活动标签页时）位于标签栏可见范围外，该方向的标签栏箭头会变为粉色。若已剪切的 Surface 位于活动标签页内，其边框已在屏幕上可见，因此箭头不会变色。标签页完全进入标签栏可见范围后，箭头恢复原色，并显示标签页上的标记。点击粉色箭头仍与平时一样，每次只滚动一格。

完成移动、剪切其他项目或关闭已剪切的项目后，标记会消失。切换到其他标签页或工作区时仍会保留，且不阻挡点击。

## 更改种类

按 `Alt+'` 会显示 **Surface 类型** <!-- en: Surface Type --> 弹窗。可将当前 Surface 就地改为**终端** <!-- en: Terminal --> · **文件浏览器** <!-- en: Explorer --> · **Markdown** <!-- en: Markdown --> · **HTML...** · **图像** <!-- en: Image --> · **DAG**。使用方向键和 `Enter`，或行右侧显示的字母进行选择。没有字母的行可通过方向键或点击选择。当前种类不会出现在列表中。空 Surface 中央的按钮也会打开同一弹窗。

- 改为文件浏览器时，以终端的当前目录为根目录打开。
- Markdown · HTML 会询问文件路径 · URL。
- 原有内容会丢失。即使按终端 → 文件浏览器 → 终端切换回来，也会启动新的 Shell 会话。
- 弹窗显示期间，仅**该 Surface 区域**变暗。相邻区域中运行的任务、侧边栏和状态栏仍保持可见。

**转换为 Markdown** <!-- en: Convert to Markdown --> · **转换为文件浏览器** <!-- en: Convert to Explorer --> 是无需弹窗即可直接切换的快捷键，默认为空。

## 全屏

点击通知窗口标题栏的全屏按钮（工具提示为**全屏显示** <!-- en: Show fullscreen -->），Tasty 窗口会覆盖显示器，仅放大显示通知列表。按 `Esc` 或点击右上角退出按钮退出。退出后，窗口大小和终端网格与进入前相同。目前全屏显示可用于通知列表。

## 保存布局——预设

将常用布局保存为预设，在创建工作区、标签页或窗格时使用。保存的内容包括拆分结构，以及各区域的种类、工作目录、启动命令、文件路径和 URL。

预设将布局和启动配置应用于新任务。不会复制运行中的进程。恢复先前任务的布局和记录的方法见[工作区恢复说明](workspaces.md#重启后恢复)。

### 保存

- 工作区——右键点击侧边栏卡片 > **保存为工作区预设** <!-- en: Save as workspace preset -->。
- 标签页——右键点击标签页 > **保存为标签页预设** <!-- en: Save as tab preset -->。
- 窗格——右键点击标签栏空白处 > **保存为窗格预设** <!-- en: Save as pane preset -->。

文件创建在 `~/.tasty/presets/{workspace,tab,pane}/<名称>.toml`。若名称已存在，会追加 `-2` 之类的编号。

对于加载后被其他编辑器修改的文件，或因损坏而无法读取的文件，保存时不会覆盖，而会报告错误。查看外部更改后，重新打开应用以加载。

重命名时，若保存新文件后无法删除旧文件，会报告错误，且两个名称可能同时保留。查看列表和文件后，决定保留哪个名称。

保存、重命名或删除预设期间，编辑器输入会暂时禁用。文件处理完成后可继续编辑。保存失败时会报告错误，并保留正在编辑的配置和选择。若多项更改中仅部分已保存，已保存的更改会保留。

### 编辑

打开侧边栏的**工具** <!-- en: Tools --> > **预设** <!-- en: Presets -->，会显示**布局预设** <!-- en: Layout Presets --> 窗口。

- 通过顶部标签页选择**工作区** / **标签页** / **窗格**，再从左侧列表选择预设。
- 右侧显示结构预览。工具栏中有**重命名** <!-- en: Rename --> · **创建副本** <!-- en: Duplicate --> · **删除** <!-- en: Delete -->。
- 点击**编辑** <!-- en: Edit -->，可直接在预览上修改结构——将鼠标移至区域边缘，点击出现的条带向该方向拆分；点击区域中央选中，再通过右上角的垃圾桶手柄删除；通过 `+` / `×` 添加和移除标签页。选中区域也支持与主界面相同的拆分和关闭快捷键。
- 修改结构时，无需保存按钮，会自动请求保存。**自动保存** <!-- en: automatic saving --> 是对此保存方式的说明。点击**完成** <!-- en: Done --> 退出。
- 区域的种类、工作目录和启动命令在 **Surface 设置** <!-- en: Surface settings --> 界面中修改。点击选中区域的齿轮手柄，或双击区域，整个右侧区域会变为该区域的设置界面。无论区域多小，所有输入框均可见。
  - 修改值后，顶部会显示**未保存** <!-- en: unsaved -->，必须点击底部的**确定** <!-- en: OK --> 才会保存。**取消** <!-- en: Cancel --> 或 `Esc` 会丢弃更改。在输入框中按 `Enter` 也可确认。
  - 设置界面打开期间，左侧列表和顶部标签页会变暗，无法点击。确定或取消后返回预览，该区域仍保持选中。
- **新建预设** <!-- en: New preset --> 创建仅含一个终端的空预设。

### 应用

- 右键点击**新建工作区**按钮 > **从预设创建工作区...** <!-- en: Create workspace from preset... -->。
- 右键点击标签栏的 `+` > **从预设创建标签页...** / **从预设创建窗格...**。
- **应用工作区预设** <!-- en: Apply workspace preset --> 等三个快捷键默认为空。指定后会显示选择弹窗。

若终端区域配置了启动命令，Shell 启动后会立即输入一行。

```sh
tasty preset list --kind workspace
tasty preset capture --kind workspace --source-id 2 --name dev
tasty preset apply --kind workspace --name dev
tasty preset apply --kind tab --name logs --target-pane 1
```

通过 CLI 应用时，焦点不会移动。重启时自动恢复和恢复已关闭项目的说明见[工作区](workspaces.md#重启后恢复)。
