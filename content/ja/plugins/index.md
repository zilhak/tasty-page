# プラグイン

マークダウン・画像・HTML の表示や Claude Code・Codex との連携などは、プラグインで提供されます。標準搭載プラグインの管理や新しいプラグインのインストール、必要な権限の確認ができます。

## プラグインとは

マークダウンビューア、画像ビューア、Claude Code 連携などの機能は、Tasty 本体ではなく **プラグイン** が提供します。プラグインは別のプロセスとして動作し、何を追加するか（サーフェスの種類 · ツールメニュー項目 · `tasty` サブコマンド · 設定ページ · ファイルハンドラ）と、どの **権限** が必要かを宣言します。Tasty は許可された権限の範囲内でのみ、そのリクエストを受け付けます。

- インストール先は `~/.tasty/plugins/<id>/`、ログは `~/.tasty/plugins-logs/<id>.log` です。
- 標準搭載プラグインは初回起動時に自動でインストールされます。その後は、自分でインストールしたプラグインと同じように無効にしたり削除したりできます。削除した標準搭載プラグインは、次回起動時に再インストールされません。
- プラグインが無効になっていると、そのプラグインが追加したサーフェスの種類 · コマンド · メニュー項目もなくなります。実行中に無効にしたり削除したりしても、再起動せずにすぐ反映されます。その種類の新しいサーフェスを開こうとすると、「提供していたプラグインが無効になっているか、まだ再接続されていない」という理由で開きません。すでに開いているサーフェスはそのまま残り、再び有効にすると続行します。ただし、スクロール位置や未保存の内容は失われます。

プラグインの有効・無効や権限を変更すると、保存結果を確認してから実行状態に反映します。インストールや信頼の選択も、保存が完了してから結果を通知します。保存に失敗した場合や結果を確認できない場合は、成功として扱いません。終了中に保存が完了した有効化は次回起動時に適用され、終了処理中にプラグインを新たに起動することはありません。終了期限までに結果を確認できなかった変更は、成功として通知したり、自動で再実行したりしません。

| **Image** | `com.tasty.image` | 画像ビューア兼簡単なペイントツールです。同じフォルダーの次 · 前の画像に切り替え、PNG で保存します | **新規画像** <!-- en: New Image -->、画像ファイルを開く、`tasty image open` · `save` · `export` · `next` · `prev` · `paste` · `list` |
| **HTML Viewer** | `com.tasty.html` | HTML・SVG ファイルと URL を内蔵 webview で表示するサーフェスです | **新規HTML...** <!-- en: New HTML... -->、`.html` · `.svg` を開く、`tasty html open` |
| **Clipboard Viewer** | `com.tasty.clipboard-viewer` | 現在クリップボードにある内容をテキスト · ファイル · 画像 · HTML に分類して表示するポップアップです。履歴は保存しません | **ツール** <!-- en: Tools --> > **クリップボードビューア** <!-- en: Clipboard Viewer -->、`Ctrl+Shift+H` |

### プラグインが追加する設定

**設定** <!-- en: Settings --> ウィンドウでは、プラグインのページは 2 か所に表示されます。

- **外観** <!-- en: Appearance --> > **Markdown** — マークダウンサーフェスにのみ適用するフォント設定 · **リモートコンテンツを許可** <!-- en: Allow remote content -->（既定ではオフ — 文書が読み込む外部 http/https リソースをブロックします）。
- **外観** > **HTML** — **既定のズーム** <!-- en: Default zoom -->（%）· **カラースキーム** <!-- en: Color scheme -->（テーマに従う / ライト / ダーク）· **リモートコンテンツを許可** <!-- en: Allow remote content -->（既定ではオフ — 外部 http/https リソースをブロックします）· **スクリプトをサンドボックス化** <!-- en: Sandbox scripts -->（既定ではオン）。
- **プラグイン** <!-- en: Plugins --> > **Claude Code** — **Spawn child 警告しきい値** <!-- en: Spawn child warning threshold --> · **子の出力がないとき親に通知するまでの待ち時間（秒）** <!-- en: Seconds without child output before notifying the parent -->（`no_output_notice_secs`、既定は 600 秒、範囲は 60~86400 秒）。詳しい動作は、[Claude・Codex と一緒に使う 第 4 節](../agents/claude-codex.md#4-完了通知を受け取る)をご覧ください。
- **プラグイン** > **Codex** — **Spawn child 警告しきい値** · **デフォルト承認ポリシー** <!-- en: Default approval policy --> · **デフォルトサンドボックスモード** <!-- en: Default sandbox mode -->。

ウェブページで描画するサーフェスを追加するプラグインは、自分でインストールしたものでも、HTML と同じように自分の設定ページの拡大 · カラースキーム · リモートコンテンツを許可 · スクリプトをサンドボックス化の値をそのサーフェスに適用します。変更していない値はプラグインが定めた既定値に従います。拡大ショートカットに対応するサーフェスでは、ショートカットによってそのプラグインの拡大値が変わります。

プラグインウィンドウの **設定** <!-- en: Configure --> ボタンも、このページに移動します。

ライトテーマの信頼済みボックスは、本文と盾アイコンを濃い緑色で表示します。署名の判定を示すもので、コードレビューや実行時の安全性を保証する表示ではありません。

## プラグインウィンドウ

サイドバーの一番下にある **プラグイン** <!-- en: Plugins --> ボタンを押してください。タブは 3 つあります。

### インストール済みプラグイン

**インストール済み** <!-- en: Installed --> タブです。左側の一覧で 1 つ選ぶと、右側に詳細が表示されます。一覧の上にある **インストール済みを絞り込み…** <!-- en: Filter installed… --> で、名前を絞り込めます。

- 詳細の一番上にある名前の下の行に、作成者とプラグイン id が表示されます。ホームページがある場合は同じ行の末尾に表示されます。`http://` · `https://` のアドレスは下線付きリンクになり、押すとブラウザーで開きます。それ以外の値は文字としてのみ表示されます。ブラウザーを起動できない場合は、開けなかったことを示す通知がプラグインウィンドウに表示されます。
- 一覧の行には **無効** <!-- en: Disabled --> または **実行中** <!-- en: Running --> が付きます。有効でも実行に失敗すると、赤い表示とともに **接続に失敗しました。設定でプラグインの構成を確認してください。** <!-- en: Failed to connect. Check the plugin's configuration in Settings. --> という案内が付きます。
- **アクセス権** <!-- en: Permissions --> — このプラグインに付与された権限の一覧です。ここでは閲覧のみ可能で、変更はできません。
- **コマンド** <!-- en: Commands --> — プラグインが追加したキーバインドコマンドです。1 行にコマンド 1 つとそのショートカットが表示されます。macOS では実際に押すキーに置き換え、Ctrl · Option · Shift · Command の順に表示されます。Option · Shift · Command は、**設定** > **一般** の修飾キーの表示方法（単語または記号）に従います。キーは **設定** > **キーバインド** > **プラグイン** で変更してください。
- **インストール先** <!-- en: Install path --> · **ログ** <!-- en: Log --> — 詳細の最後の節です。長いパスは折り返されて末尾まで表示され、ドラッグして選択・コピーできます。見出し行の右側にある **フォルダを開く** <!-- en: Open folder --> は、インストールフォルダーをファイルマネージャーで開きます。ファイルマネージャーを起動できない場合は、開けなかったことを示す通知がプラグインウィンドウに表示されます。
- 詳細の下のバーは、詳細をスクロールしても常に表示されます。
  - 左側のスイッチ — 隣のラベルに **有効** <!-- en: Enabled --> / **無効** <!-- en: Disabled --> と表示されます。ラベルを押しても切り替わります。オフにするとプロセスが終了処理され、オンにすると再び起動します。
  - **設定** <!-- en: Configure --> — 設定ウィンドウのプラグインページに移動します。
  - **削除** <!-- en: Uninstall --> — 押すと、このバーがその場で確認表示に変わります。**キャンセル** <!-- en: Cancel --> と **削除** <!-- en: Uninstall --> ボタンが表示され、削除を押すとインストールフォルダーが削除されます。プラグイン設定は自分で削除するまで残ります。**標準搭載** <!-- en: built-in --> プラグインの場合は、次回起動時に再インストールされないという案内が表示されます。確認が表示されると **キャンセル** にキーボードフォーカスがあるため、Enter ですぐにキャンセルでき、Esc を押してもキャンセルされます（別のタブに移動してから押してもかまいません）。別のプラグインを選ぶと確認がキャンセルされ、通常のバーに戻ります。

### 要確認

**要確認** <!-- en: Attention --> タブです。登録が拒否されたプラグインや実行に失敗したプラグインが、理由とともに集まります。以下の **公式プラグインではありません** <!-- en: Not an official plugin --> の項目を除き、詳細の一番上にはインストール済みプラグインと同じように、名前 · 作成者 · id とホームページリンク（`http://` · `https://` のアドレスの場合）、その下に説明が表示されます。署名が無効なプラグインはマニフェストの内容を信頼できないため、説明とホームページを表示せず、説明の位置に **署名が無効なため説明を非表示にしています。** <!-- en: Description hidden — the signature is invalid. --> と表示されます。

| 表示 | 意味 | 操作 |
|------|----|------|
| **署名が信頼されていません** <!-- en: Signature not trusted --> | 信頼リストにない鍵で署名されています | 詳細に **未検証のプラグイン** <!-- en: Unverified plugin --> の警告が表示されます。配布元を確認してから、Signature 節の **フィンガープリントをコピー** <!-- en: Copy fingerprint --> ボタンでフィンガープリントをコピーして照合してください。信頼できる場合は **それでも登録** <!-- en: Register anyway --> を押してください |
| **署名が無効です** <!-- en: Signature invalid --> | 署名がないか、検証に失敗しています。詳細に失敗の原因（署名ファイルがないなど）が 1 行で表示されます | 配布者から正しいパッケージを受け取るのが安全です。配布元を信頼する場合は **それでも登録** <!-- en: Register anyway --> で使用できます |
| **権限が変更されました** <!-- en: Permissions changed --> | 更新により要求する権限が変わりました | **新規要求** <!-- en: newly requested --> の一覧を見て **再承認** <!-- en: Re-approve --> してください |
| **実行エラー** <!-- en: Runtime error --> | 有効ですが実行中に失敗しました | **ログ** を確認してください |
| **公式プラグインではありません** | 公式 Tasty プラグイン専用の `com.tasty.` 接頭辞を id に使用していますが、公式プラグインではないため登録できませんでした。削除のみ可能です | **プラグイン › 要確認** でフォルダーを選び、**削除** <!-- en: Remove --> してください |

**公式プラグインではありません** の項目は、プラグインフォルダー（`~/.tasty/plugins/`）の直下でマニフェストを読み取ることができ、id が `com.tasty.` で始まるものの公式リストにはないフォルダーです。マニフェストを読み取れないフォルダーは、この項目として表示されません。登録されないため実行されず、`tasty plugin list` にも表示されません。Tasty が自動で削除することもありません。フォルダー名は id と異なっていてもかまいません。同じ id のフォルダーが複数ある場合は、それぞれ 1 行ずつ表示され、個別に選択できます。各行は、タブバッジとサイドバーバッジの両方の件数に含まれます。

この項目の詳細にはフォルダー名と id だけが表示され、マニフェストの表示名 · 作成者 · 説明 · ホームページ · バージョンは表示されません。非公式のマニフェストが自分を Tasty のように表示できるためです。説明の位置には **公式プラグインではないため説明を非表示にしています。** <!-- en: Description hidden — it is not an official plugin. --> と表示され、**フォルダー** <!-- en: Folder --> 節にパスが表示され、下部のバーには **未登録** <!-- en: Not registered --> と表示されます。実行できる操作は **削除** のみで、**それでも登録** · **再承認** · **設定** · **フォルダを開く** はありません。

- **プラグイン › 要確認** で削除するフォルダーの行を選び、**削除** を押してください。行を選ぶだけでは、削除ボタンにキーボードフォーカスは移りません。下部のバーがその場で **{フォルダー名} を削除しますか？** という確認に変わり、**プラグインフォルダーからこのフォルダーが削除されます。** という案内が表示されます。フォーカスは **キャンセル** にあるため、Enter はキャンセルになります。Esc · **キャンセル** · 別の行の選択でも確認をキャンセルします。
- 確認の **削除** を押すと、選択したフォルダーだけが削除され、同じ id の別のフォルダーは残ります。処理中は **削除中…** <!-- en: Removing… --> と表示され、両方のボタンは無効になり、Esc と行のクリックは無視されます。削除直前に再確認するため、その間にマニフェストの id が許可される id に変わった場合や、マニフェストを読み取れなくなった場合は、削除せずに失敗します。
- 成功すると行が消えて両方のバッジの件数が減り、**'{フォルダー}' を削除しました。** というトーストが表示されます。Tasty の外ですでに削除したフォルダーも成功として扱います。失敗すると **削除に失敗しました: {理由}** というトーストが表示され、バーが通常の状態に戻り、行は残るため再試行できます。理由はファイル操作のエラー原文なので、韓国語の画面でも英語で表示されることがあります。
- リンクになっているフォルダーは、対象にもリンクにも変更を加えずに失敗します。この行を消すには、リンクを直接削除してください。削除の途中で失敗し、マニフェストがすでに削除されている場合は、行が残っている間は再試行できます。次の探索後には行がないままファイルが残ることがあるため、その場合は残ったフォルダーを直接削除してください。

このようなフォルダーが新たに見つかると、フォルダーごとに通知一覧に警告が 1 件残ります。本文では `com.tasty.` 接頭辞が公式 Tasty プラグイン専用であることを知らせ、**プラグイン › 要確認** で削除するよう案内します。同じフォルダーが残っていると、Tasty を再起動したときに警告が再び残ります。

### プラグインの追加

**プラグインを追加** <!-- en: Add plugin --> タブです。

`com.tasty.` で始まる id は Tasty 公式プラグイン専用です。Tasty の公式リストにない `com.tasty.*` id は、すべてのビルドで署名確認前に拒否され、**それでも追加** <!-- en: Add anyway --> や `--allow-unverified` でもインストールできません。この検査は id だけを確認し、公式リストにある id も署名確認を受けます。公式リストにない `com.tasty.*` id のフォルダーをプラグインフォルダーの直下に直接入れた場合、マニフェストを読み取ることができれば登録せずに **要確認** タブに表示し、そこで削除できます。

1. **プラグインフォルダ** <!-- en: Plugin folder --> 入力欄に `tasty-plugin.toml` が入っているフォルダーを入力するか、**フォルダを探す…** <!-- en: Find folder… --> で選択してください。Tasty のフォルダーピッカでは、下位フォルダーを選択するか、どの行も選ばずに現在のフォルダーを確定できます。ダブルクリックはフォルダー内への移動、Enter は確定です。キャンセルすると入力はそのままです。
2. フォルダーを探して確定すると、すぐに検証します。パスを直接入力した場合は **確認** <!-- en: Verify --> を押してください。入力欄のすぐ下にマニフェストカードが表示されます。名前 · バージョン · id · 作成者 · 説明 · **要求権限** · サーフェスの種類 · 元のパスが表示されます。ホームページが `http://` · `https://` のアドレスの場合は下線付きリンクを押してブラウザーで開くことができ（ブラウザーを起動できない場合は、開けなかったことを示す通知が表示されます）、それ以外の値は文字としてのみ表示されます。作成者が複数いる場合は最初の作成者の後に `+N` が付き、マウスを重ねると全員の一覧が表示されます。パスを修正するとカードが消えるため、再び **確認** を押してください。フォルダーに `tasty-plugin.toml` がないか、形式が誤っていて読み取れない場合は、カードの代わりに **tasty-plugin.toml を読み込めません** <!-- en: Can't read tasty-plugin.toml --> というボックスが表示され、その下の行に読み取りエラーの原文が表示されます。ファイルは読み取れたものの内容が規則に合わない場合（例: 指定した実行ファイルがフォルダーにない）は、同じ位置に **tasty-plugin.toml が正しくありません** <!-- en: tasty-plugin.toml is not valid --> というボックスが表示され、下の行に何が誤っているかが表示されます。公式リストにない `com.tasty.*` id も、このボックスで拒否理由を知らせます。下の行に英語原文の `plugin id '<id>' uses the reserved com.tasty. prefix but is not an official Tasty plugin` が表示され、プレビューと追加ボタンは表示されません。パスを修正してから再び **確認** を押してください。
3. カードの下のボックスで署名の判定を知らせます — **信頼された発行者によって署名されています** <!-- en: Signed by a trusted publisher -->、**権限が変更されました** <!-- en: Permissions changed -->、または **未検証のプラグイン** <!-- en: Unverified plugin --> です。未検証のプラグインでは、原因（信頼リストにない鍵、公開鍵ファイルがない、署名がない、署名検証の失敗）とともに、プラグインが自分のアカウント権限で実行され、権限一覧は Tasty に要求できる範囲だけを制限するという警告が表示されます。鍵がある判定の場合は、ボックスにフィンガープリント（fingerprint）が表示され、コピーボタンでコピーできます。長いフィンガープリントは先頭と末尾の 8 バイトだけが表示され、中央は `…` で省略されます。マウスを重ねるかコピーすると、値全体を取得できます。
4. 下の行の左側に、付与する権限の数が表示されます。**プラグインを追加** <!-- en: Add plugin --> を押してください。権限の変更がある場合は同じ位置のボタンが **信頼して追加** <!-- en: Trust & add --> に変わり、押すと新しい権限の組が信頼リストに記録されます。権限はプラグインが Tasty に要求できる範囲だけを制限するもので、プラグインのプログラムを自分のファイル・ネットワーク・ほかのプログラムから隔離するものではありません。未検証のプラグインの場合はボタンが **それでも追加** <!-- en: Add anyway -->（信頼リストにない鍵の場合は **鍵を信頼してそれでも追加** <!-- en: Trust key & add anyway -->）に変わり、最初は **キャンセル** <!-- en: Cancel --> にフォーカスがあるため、Enter・Esc ではインストールせずに戻ります。配布元を信頼する場合にのみ押してください。この選択はマニフェストが変わるかプラグインを削除するまで記憶され、インストール後は一覧の表示以外に別の制限はありません。追加中はボタンが **追加中…** <!-- en: Adding… --> に変わります。
5. すでにインストールされているプラグインの場合は、ボタンが無効のままになり、左側に **インストール済み** <!-- en: Already installed --> と表示されます。

インストールすると、プラグインが要求した権限が許可されます。追加する前に、プレビューで権限一覧を確認してください。

## 権限

プラグインは必要な権限を事前に宣言します。Tasty に送るリクエストに必要な権限がない場合は、そのリクエストを拒否します。

権限は、プラグインが Tasty に要求できる機能の範囲を定めます。プラグインプロセスのすべてのファイル・ネットワークアクセスを隔離するという意味ではありません。インストールするプラグインの配布元と説明を確認してください。

よく見かける名前と意味:

| 権限 | 許可される操作 |
|------|-------------|
| `surface.read` · `surface.write` | サーフェスの一覧 · 状態の読み取り、サーフェスの作成 · 変更 |
| `fs.read` · `fs.write` | ファイルの読み取り · 書き込み |
| `clipboard.read` · `clipboard.write` | クリップボードの読み取り · 書き込み |
| `terminal.spawn` · `terminal.write` · `terminal.read` | ターミナルの作成、キー入力の送信、出力の読み取り |
| `notification` | 通知の表示 |
| `process.spawn` · `network` | 外部プロセスの実行、ネットワーク |
| `ui.tool_item` · `ui.popup` · `ui.settings_page` | ツールメニュー項目、ポップアップ、設定ページの追加 |
| `file_handler.define` · `file_handler.handle:<種類>` | ファイルの種類の識別規則の定義、その種類のファイルを開く処理の担当 |
| `memory.read` · `memory.write` · `memory.secret` | エージェントメモリストアへのアクセス |
| `agent` · `approval` · `telemetry` | エージェントの協業 · 承認ゲート · テレメトリ |
| `agent.turn_report` | エージェントタスクのターンの開始・終了の報告のみ（ほかのエージェント協業機能は使用可能になりません） |
| `completion_strategy.define` | タスクランナーが子エージェントの完了を判定する方法の定義 |
| `ipc.invoke:<prefix>` | 別のプラグインが `<prefix>` という名前で提供するコマンドの呼び出し（例: `ipc.invoke:codex` は Codex プラグインのコマンド） |

標準搭載プラグインに付与される権限:

| プラグイン | 権限 |
|---------|------|
| Markdown Viewer | `surface.read` `surface.write` `fs.read` `file_handler.define` `file_handler.handle:markdown` `ui.settings_page` `ui.popup` |
| Image | `surface.read` `surface.write` `clipboard.read` `fs.read` `fs.write` `file_handler.define` `file_handler.handle:image` |
| HTML Viewer | `surface.read` `surface.write` `file_handler.define` `file_handler.handle:html` `file_handler.handle:svg` `ui.settings_page` |
| Clipboard Viewer | `clipboard.read` `ui.popup` `ui.tool_item` |
| Git Viewer | `ui.popup` `ui.tool_item` `fs.read` |
| Claude Code | `surface.read` `surface.write` `terminal.spawn` `terminal.write` `terminal.read` `fs.read` `fs.write` `notification` `telemetry` `agent` `agent.turn_report` `ui.settings_page` `completion_strategy.define` `memory.read` `ipc.invoke:codex` |
| Codex | `surface.read` `surface.write` `terminal.spawn` `terminal.write` `terminal.read` `fs.write` `notification` `ui.settings_page` `completion_strategy.define` `agent.turn_report` |

権限を個別に取り消したり戻したりする操作は、CLI でのみ行えます（下記）。

## `tasty plugin` コマンド

Tasty の実行中にターミナルで使用します。出力は JSON です。

公式リストにない `com.tasty.*` id は、`--allow-unverified` を指定してもインストールされません。この拒否は署名確認より先に行われ、プラグインフォルダー・権限・信頼リストには何も残しません。

| コマンド | 機能 |
|------|---------|
| `tasty plugin list` | インストール済みプラグインの id · バージョン · 有効かどうか · 実行中かどうか、自動で無効になったかどうか、最後の起動失敗 |
| `tasty plugin show <id>` | マニフェスト · 権限 · コマンド · 実行状態の全体 |
| `tasty plugin install <フォルダー> [--allow-unverified]` | `tasty-plugin.toml` があるフォルダーからインストールします。マニフェストの権限をそのまま許可します。未検証のプラグインは `--allow-unverified` を指定した場合にのみインストールします |
| `tasty plugin remove <id>` | インストール済みプラグインを削除します。**公式プラグインではありません** のフォルダーは削除せず、**要確認** タブを案内するエラーで終了します |
| `tasty plugin enable <id> [--no-wait]` · `disable <id>` | 有効化 · 無効化します。`enable` はプラグインが接続されるまで（最大 15 秒）待ち、起動できない場合は原因とともに失敗として終了します。3 秒が経過しても起動中の場合は、処理中であることを示す案内を 1 回表示します |
| `tasty plugin logs <id> [--follow]` | ログを出力します。`--follow` は新しい行を継続して表示します（`Ctrl+C` で中断） |
| `tasty plugin permissions <id>` | マニフェストが要求する権限と、実際に許可された権限 |
| `tasty plugin grant <id> <権限>` · `revoke <id> <権限>` | 権限を 1 つ許可 · 取り消します。マニフェストに宣言された権限のみ許可できます |
| `tasty plugin doctor <id>` | マニフェストの診断 — このバージョンの Tasty が理解できない規則があるかどうか |
| `tasty plugin upgrade-builtins [--force] [--restore-removed <id>] [--restore-removed-all] [--restart-running]` | 標準搭載プラグインをバンドル版に再び合わせます。`--restore-removed` は削除した標準搭載プラグインを復活させ（複数回指定可能）、`--restore-removed-all` は削除した標準搭載プラグインをすべて復活させます。`--restart-running` は実行ファイルが変わったプラグインを再び起動します（そのプラグインのサーフェスが一時的に閉じます） |
| `tasty plugin extension list` | プラグインが別のプラグインに追加した拡張（extension）とその状態 |
| `tasty plugin grant-agent-permission --agent <id> --permission <権限> [--ttl <秒>]` · `revoke-agent-permission` | 実行中のエージェントセッションに一時的な権限を付与したり取り消したりします。`--ttl` を省略すると、取り消すまで維持されます |
| `tasty plugin list-agent-permissions [--agent <id>]` | エージェントセッションの基本権限と一時的な権限 |
| `tasty plugin request-permission --agent <id> --permission <権限> [--reason <理由>]` | エージェントに権限を付与するかを尋ねる承認ポップアップを事前に表示します。エージェントが直接実行する場合は自分自身だけを対象にでき、このポップアップはユーザーのみが承認・拒否できます |
| `tasty plugin audit-query` · `audit-summary` · `audit-follow` · `audit-clear` | Tasty が受け取ったリクエスト（CLI・プラグイン・エージェント）の許可・拒否記録を照会 · 集計 · リアルタイム確認 · 削除します |

`install` は、id 検査を通過したプラグインのフォルダーをコピーする前に署名を確認します。未検証のプラグインの場合は原因とリスクを警告してインストールせず、配布元を信頼する場合に使用する `tasty plugin install --allow-unverified <フォルダー>` コマンドを案内します。署名確認でインストールを拒否すると、実際の理由（署名がない、信頼していない鍵、公開鍵ファイルがない、または一致しないなど）を知らせ、プラグインフォルダー・権限・信頼リストには何も残しません。問題を修正してから同じコマンドで再インストールできます。登録まで完了した後にプラグインを実行できなかった場合は、インストールしたフォルダーが残ります。この場合は `tasty plugin logs <id>` で原因を確認してください。

プラグインを起動できないと、通知一覧に警告が残ります。短時間に何度も失敗して Tasty がプラグインを自動で無効にすると、エラー通知が別に残り、再び有効にするまで起動しません。自分で再び有効にしていないのに続く同じプラグインの失敗は、1 件にまとめます。自分で有効にするたびに、その結果は個別の通知として残ります。原因は通知の本文と `tasty plugin logs <id>` で確認できます。

**公式プラグインではありません** のフォルダーの id で `tasty plugin remove <id>` を実行すると、フォルダーを削除せずに次のエラーで終了します。`enable` と `disable` も同じ案内で失敗します。

`plugin '<id>' was not registered because its id uses the reserved com.tasty. prefix; remove its folder from Plugins > Attention`

同じ id のフォルダーが複数ある可能性があり、id だけでは削除するフォルダーを特定できません。**プラグイン › 要確認** でフォルダーを選んで削除してください。

`enable` と `disable` はインストール済みプラグインの ID のみを受け付けます。インストールされておらず、上記のようなフォルダーもない id は、エラー理由として `plugin '<id>' not installed` が表示され、設定は変わりません。インストール済みの ID は `tasty plugin list` で確認してください。

`disable` は終了処理を開始し、通常はバックグラウンドで進行します。2 秒の正常終了の猶予が過ぎてもプロセスが残っている場合は、強制終了を試みます。この 2 秒はコマンド全体の時間の上限ではなく、OS でプロセスの終了を確認する間、さらに待つことがあります。その間に `enable` すると、以前のプロセスの終了を待ってから新たに起動します。`tasty plugin enable` は続けて新しいプラグインが接続されるまで（最大 15 秒）待ち、結果を知らせます。すぐに戻るには `--no-wait` を指定してください。この場合と、エージェントが IPC で直接リクエストする場合は、起動を受け付けたという応答だけを受け取るため、結果は `tasty plugin show <id>` で確認してください。実行や接続に失敗した場合は、通知とログを確認してください。

プラグインが停止していて、そのサーフェスを閉じるのに時間がかかっている間も、ほかのコマンドや入力は通常どおり処理されます。閉じるのを待っている間にそのプラグインを `disable` すると、プロセスが終了し次第、閉じる処理が成功として完了します。その間に Tasty を終了すると、終了処理はその閉じる処理が終わるまで（最大 5 秒）待ちます。

```sh
tasty plugin list
tasty plugin permissions com.tasty.git-viewer
tasty plugin disable com.tasty.clipboard-viewer
tasty plugin logs com.tasty.markdown --follow
```

`tasty plugin permissions com.tasty.git-viewer` の出力例:

```json
{
  "granted": ["ui.tool_item", "fs.read", "ui.popup"],
  "id": "com.tasty.git-viewer",
  "manifest": ["ui.popup", "ui.tool_item", "fs.read"]
}
```

## トラブルシューティング

| 症状 | 確認すること |
|------|-----------|
| マークダウン · 画像 · HTML ファイルがターミナル内で開きません | プラグインウィンドウで該当するプラグインが **有効** かどうかです。無効になっていると、サーフェスの種類自体がありません |
| ツールメニューに **クリップボードビューア** · **Git** がありません | 2 つのプラグインが無効になっているか、**要確認** に入っています |
| プラグインの状態が赤くなっています | **ログ** ボタン、または `tasty plugin logs <id>` |
| 削除した標準搭載プラグインを復活させたいです | `tasty plugin upgrade-builtins --restore-removed <id>` |
| 更新後にプラグインが **要確認** に入りました | **権限が変更されました** の場合は、要求する権限が変わっています。一覧を読んで **再承認** してください |
| **プラグイン '&lt;id&gt;' は登録されませんでした** という通知が表示されるか、**要確認** タブに **公式プラグインではありません** の項目が表示されます | 公式プラグイン専用の接頭辞を使用していますが、公式リストにないフォルダーです。登録されないため実行されません。**プラグイン › 要確認** でフォルダーを選び、**削除** してください |
