# CLI와 에이전트

가이드 페이지는 영어, 한국어, 일본어, 중국어 간체로 함께 둔다. 각 페이지의 역할과 범위는 아래와 같다.

## tasty CLI로 터미널 조작하기

- 사이트 소스: [한국어](../../content/agents/cli.md) · [영어](../../content/en/agents/cli.md)
- 역할: 첫 CLI 작업을 완결하기.
- 보여 줄 항목: 연결 조회, ID, 짧은 실습, mark/send/read, 종료 결과 확인, 대상 한정 닫기. CLI 응답 지연 시 셸 timeout을 통한 동일 요청 반복의 위험, 연결 종료와 요청 취소의 차이, 단일 요청 명령의 응답 대기 상한과 실행 시작 전후 만료의 차이를 다루고 재시도 판단은 진단 안내로 연결한다.
- 넣지 않을 항목: 고급 명령 전량, 표를 실습보다 먼저 강요, 포커스 기반 대상 추측.
- 구성: 연결 조회, 대상 ID 확인, 작업 터미널 생성, 명령 전송, 표시 위치 이후 출력과 종료 결과 읽기, 자기 대상 정리 순서로 실습한다. 목적별 참조는 실습 뒤에 둔다.

## CLI 명령 참조

- 사이트 소스: [한국어](../../content/agents/cli-reference.md) · [영어](../../content/en/agents/cli-reference.md)
- 역할: 입문 밖 명령의 목적별 조회.
- 보여 줄 항목: 기존 목적별 절과 help 사용, 실습·진단으로 연결.
- 넣지 않을 항목: 완전한 API 명세라고 주장, 모든 옵션 전사.
- 구성: 세션 토큰, 원격 연결과 거절 조회의 권한, 워크스페이스 목록 조회 권한, 플러그인 명령 권한을 구별한다.

## 백그라운드 작업을 탭으로 가져오기

- 사이트 소스: [한국어](../../content/agents/background-tasks.md) · [영어](../../content/en/agents/background-tasks.md)
- 역할: 숨겨진 PTY에서 가시 탭으로 옮기는 실습.
- 보여 줄 항목: 현재 실습, 실행 상태와 개별 명령 결과 차이, 셸별 줄바꿈, 새 ID, 정리.
- 넣지 않을 항목: headless 앱과 혼용, 끝난 PTY를 탭으로 가져온다는 설명.

## Claude·Codex와 함께 쓰기

- 사이트 소스: [한국어](../../content/agents/claude-codex.md) · [영어](../../content/en/agents/claude-codex.md)
- 역할: 에이전트 실행과 결과 수신 연결.
- 보여 줄 항목: 별도 설치, 플러그인·훅, 한 세션 실행, 수신 채널, spawn/tell, 고급 권한·프로필·재시작. 출력 없음 알림의 기본 시간·설정 범위·재시작 없는 반영·끄기 불가, 작업 출력 파일과 화면 출력의 판정 차이, Monitor 단독 대기 제외와 active 유지·완료 신호 보류, 혼합 대기의 판정 대상, 부모 Claude의 턴 깨움과 수신 조건, Codex 부모의 별도 결과 경로, 오류 직후 고정 시간·재알림 간격·stale 분류와의 구별, 멈춤 확정의 한계, Monitor 구별을 위한 훅 재설치와 새 프로세스 시작.
- 넣지 않을 항목: 부모 종류와 무관한 자동 수신 보장, idle=성공, 가장 넓은 권한을 기본 권장.
- 구성: 단일 세션 실행을 먼저 안내하고, 부모별 완료 수신 경로와 결과 판독을 분리한다. 원격 mirror 연결, 로컬·원격 ID 구별, 목록 조회 권한, 원격 도구·훅·결과 수신 조건과 연결 종료 제약을 보여 준다. 승인·모델·프로필·재시작은 고급 항목으로 둔다.

## 작업 순서 관리 (DAG)

- 사이트 소스: [한국어](../../content/agents/tasks.md) · [영어](../../content/en/agents/tasks.md)
- 역할: 의존 작업 실행과 관찰.
- 보여 줄 항목: 러너→한 작업→결과, 의존·실패, 결과 전달, 관찰 전용 그래프, 동기화는 고급 절.
- 넣지 않을 항목: GUI에서 그래프를 편집해 작업을 만든다는 암시, 협업 충돌 자동 해결.
- 구성: 최소 작업 실행과 결과 확인을 먼저 두고 타입·분기·동기화를 뒤에 둔다. 그래프의 관찰 역할, 실행 상태, 선택된 갈래와 실행되지 않는 경로의 색·선 모양을 보여 준다.

## 훅 · 알림 · 웹훅

- 사이트 소스: [한국어](../../content/agents/hooks-notifications.md) · [영어](../../content/en/agents/hooks-notifications.md)
- 역할: 이벤트·알림·외부 요청 선택.
- 보여 줄 항목: 차이 설명, 서피스·글로벌 훅, 재사용 핸들러, 앱 안 알림, 승인 요청, 웹훅 조건. 출력 없음 이벤트의 일반·오류 직후 기준 시간, Monitor 단독 대기 제외, 상세 판정·수신 조건으로 연결.
- 넣지 않을 항목: 외부 HTTP 접수=실행 성공, 모든 알림이 부모 대화를 깨운다는 주장.
- 구성: 이벤트 동작, 앱 안 알림, 외부 요청의 차이를 먼저 비교하고 설정·접수·실행 결과·승인 조건별 항목으로 연결한다.
