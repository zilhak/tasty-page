# 最初の画面を見てみる

Tasty の最初の画面は、ワークスペースを切り替えるサイドバーと、ターミナルや文書を表示する作業領域で構成されています。ペインごとにタブバーがあり、各タブの中にはターミナルや文書を表示するサーフェスがあります。

## 画面上で直接学ぶ

サイドバーの **ツール** <!-- en: Tools --> > **チュートリアル…** <!-- en: Tutorial… --> で、画面の構造と分割を直接学べます。

分割の練習は、新しい練習用ワークスペースで行います。作業領域をクリックしてから、表示されたショートカットやメニューを使ってください。動作を確認できたら **次へ** を押してください。練習用の領域は完了後も残るので、そのまま使うことも、自分で閉じることもできます。

**一覧** または `Esc` で中断し、後から **再開** を選択できます。完了状況と進行位置は、アプリを開き直しても記憶されます。分割の練習を再開すると、新しい練習用の領域が作成されます。ショートカットの案内は現在の設定に従います。

## 4 つの用語 — ワークスペース・ペイン・タブ・サーフェス

Tasty の画面は、この順序で包含関係を構成しています。各部分を画面上で確認するには、サイドバーの **ツール** <!-- en: Tools --> > **チュートリアル…** <!-- en: Tutorial… --> を開いて、画面上に直接表示される案内に従ってください。

| 用語 | 意味 | 似た概念 |
|------|----|------------|
| **ワークスペース** <!-- en: Workspace --> | タブ・ペイン・サーフェスをすべて含む、最も大きな単位です。サイドバーで切り替えます | tmux の session、iTerm2 の window |
| **ペイン** <!-- en: Pane --> | ワークスペースを物理的に区切った領域です。領域ごとに **独自のタブストリップ** を持ちます | tmux・iTerm2 にはない Tasty 独自の概念 |
| **タブ** <!-- en: Tab --> | ペイン内の 1 つのタブです | tmux の window、iTerm2 の tab |
| **サーフェス** <!-- en: Surface --> | 実際にターミナル・マークダウン・エクスプローラーが描画される面です。1 つのタブ内で複数に分割できます | tmux・iTerm2 の pane |

**分割が 2 段階ある** ことが Tasty の特徴です。

- **ペインを分割** — ワークスペースを左右・上下に分けます。あるペインでタブを切り替えても、ほかのペインはそのままです。例: 左のペインは Claude Code 専用、右のペインにはログ・ビルド用のタブを複数配置します。
- **サーフェスを分割** — 1 つのタブ内を分けます。タブを切り替えると、その分割全体が一緒に切り替わります。

詳しい操作は [ペイン・タブ・分割](../using/panes-tabs-splits.md) を参照してください。

## ウィンドウの構成

<!-- tasty-diagram: window-anatomy -->
```
┌─────────────────────────────────────────────────┐
│ タイトルバー                                    │
├──────────┬──────────────────────────────────────┤
│          │ タブストリップ                       │
│ サイドバー ├──────────────────────────────────────┤
│          │ 作業領域（ペイン・タブ・サーフェス） │
│          ├──────────────────────────────────────┤
│          │ ステータスバー                       │
└──────────┴──────────────────────────────────────┘
```

- **タイトルバー** — ドラッグしてウィンドウを移動し、ダブルクリックで最大化します。Linux・Windows では Tasty が最小化・最大化・閉じるボタンを直接描画し、macOS では左側の信号機型ボタンをそのまま使います。
- **サイドバー** — ワークスペースの一覧と、ツール・プラグイン・設定への入り口です。
- **作業領域** — ターミナルと文書を配置する場所です。以下の 4 つの構成要素に分かれます。
- **ステータスバー** — 現在のターミナルの状態と、すぐに操作できるボタンです。

## サイドバー

上から順に 3 つの領域があります。

- **ヘッダー** — `tasty.` のワードマークと **折りたたむ** <!-- en: Collapse --> ボタンです。折りたたむと、アイコンだけが残る細いレールになります。
- **ワークスペース** <!-- en: WORKSPACES --> 一覧 — カードをクリックすると切り替わり、ドラッグすると順序を変更できます。一番下の **新しいワークスペース** <!-- en: New workspace --> ボタンで追加します。このボタンを右クリックすると、**プリセットからワークスペースを作成...** <!-- en: Create workspace from preset... --> と **リモートワークスペースを追加** <!-- en: Add remote workspace --> が表示されます。カード右側の数字のバッジは 2 種類あります。黄色のバッジは入力を待っているサーフェスの数、青色のバッジはタスクが終わったか通知が届いたサーフェスの数です。両方ある場合は、黄色のバッジが左側に表示されます。
- **下部のボタン** — **ツール** <!-- en: Tools -->（**コマンドパレット…** <!-- en: Command palette… -->・**受信ポート…** <!-- en: Listening ports… -->・**リモート接続…** <!-- en: Remote connections… -->・**プリセット** <!-- en: Presets -->・**チュートリアル…** <!-- en: Tutorial… -->・**タスク DAG** <!-- en: Task DAGs -->・**ファイルを開く…** <!-- en: Open File… --> の順で、その下の区切り線の後にプラグインが追加した項目）、**プラグイン** <!-- en: Plugins -->（インストール・有効化を管理するウィンドウ）、**設定** <!-- en: Settings -->（設定ウィンドウ）です。

ワークスペースが増えたら、**設定** > **一般** <!-- en: General --> > **ワークスペースカテゴリ（フォルダー）** <!-- en: Workspace categories (folders) --> をオンにすると、フォルダーのようにまとめられます。詳しくは [ワークスペース](../using/workspaces.md) を参照してください。

## タブストリップ

各ペインの一番上にあります。

- 各タブには種類のアイコン（ターミナル・マークダウンなど）と名前が表示されます。名前は、自分で指定した名前 → プログラムが設定したターミナルタイトル → シェルの現在のディレクトリ名 → 既定の名前の順で決まります。右クリック > **タブ名を変更** <!-- en: Rename Tab --> で名前を指定すると、ほかの名前に変わらなくなります。
- プログラムが出力している間は **緑色の点** が付き、入力を待っているときやタスクが終わったときは名前の色が変わります（[名前と表示](../using/panes-tabs-splits.md#名前と表示)）。
- `+` は新しいタブです。右クリックするとプリセットから作成できます。その隣の分割・検索アイコンは、このペインを分けるか、現在のサーフェス内を検索します。
- タブが収まりきらなくなると、左右の矢印が表示されます。ドラッグで順序を変更できます。
- 空いている場所を右クリックすると、**新規ターミナル** <!-- en: New Terminal -->・**新規マークダウン...** <!-- en: New Markdown... -->・**新規HTML...** <!-- en: New HTML... -->・**新規画像** <!-- en: New Image --> で新しいタブを作成できます。**新規HTML...** は、ファイル選択ウィンドウで HTML・SVG ファイルを選ぶと、そのペインにタブを開きます。同じメニューで **ペインプリセットとして保存** <!-- en: Save as pane preset --> と **プリセットからタブを作成...** <!-- en: Create tab from preset... -->・**プリセットからペインを作成...** <!-- en: Create pane from preset... --> も選べます。種類ごとの説明は [ファイルの管理と表示](../using/files.md) を参照してください。

ペインに最後に残った 1 つのタブは、タブを閉じる操作では閉じられません。サーフェスを閉じる操作は異なります。タブに残った最後のサーフェスを閉じると、そのタブが閉じます。そのタブがペインの最後のタブならペインも、そのペインがワークスペースの最後のペインならワークスペースも一緒に閉じます。

<details>
<summary>ステータスバー</summary>

作業領域の一番下にある 1 行です。左側は現在フォーカスされているサーフェスの情報、右側はボタンです。

- **git ブランチ** — シェルの現在のディレクトリが git リポジトリの場合、枝のアイコンとブランチ名が表示されます。反映には最大 1 秒の遅れがあります。リポジトリでない場合、この項目は **一切表示されません**。特定のコミットを直接参照している場合（detached HEAD）は、名前の代わりに `@` と短いコミット番号が表示されます。
- **サーフェス ID** — `s3·p1` のように、サーフェス番号と、そのサーフェスを含むペインの番号です。先頭の数字は、`tasty` CLI でこのターミナルを指定するときに使う値です（[tasty CLI](../agents/cli.md)）。
- **シェル** — 実行中のプログラム名です。
- **グリッドサイズ** — `列×行` です。
- **パレットのショートカット** — キーの形で表示されます。クリックするとコマンドパレットが開き、表示されるキーは設定に従います。ショートカットを空にすると、この項目も消えます。
- **テーマアイコン** — クリックするたびに、明るいテーマ（latte）と暗いテーマ（mocha）が切り替わります。アイコンの形で現在どちらかが分かります — 明るいテーマなら太陽です。

**値がない項目は、空白を残さずに消えます。** ウィンドウが狭くなると、グリッドサイズ → シェル → サーフェス ID → パレットのショートカット → ブランチ名の順に非表示になり、テーマアイコンは最後まで残ります。

</details>

## 最初に覚えておくショートカット

既定のプリセット（**Tasty**）の値です。表記の `Alt` は macOS では `Cmd(⌘)`、`Ctrl` は `Control(⌃)` です。変更方法と全体の表は [キーバインド](../customize/keybindings.md) を参照してください。

| 操作 | Windows · Linux | macOS |
|---------|-----------------|-------|
| 新しいワークスペース | `Alt+N` | `Cmd+N` |
| 新しいタブ | `Alt+T` | `Cmd+T` |
| ペインを分割（左右 / 上下） | `Alt+E` / `Alt+Shift+E` | `Cmd+E` / `Cmd+Shift+E` |
| サーフェスを分割（左右 / 上下） | `Alt+D` / `Alt+Shift+D` | `Cmd+D` / `Cmd+Shift+D` |
| コマンドパレット | `Ctrl+Shift+P` | `Ctrl+Shift+P` |
| 設定 | `Ctrl+,` | `Ctrl+,` |

macOS で iTerm2 のような `⌘` 中心の組み合わせを使いたい場合は、**設定** > **キーバインド** <!-- en: Keybindings --> で **Mac** プリセットを選んでください。

## ウィンドウを閉じた場合

ウィンドウが複数ある場合、閉じるボタンを押したウィンドウだけが閉じます。最後に残ったウィンドウの閉じるボタンを押すと、**終了** <!-- en: Quit --> するか **最小化** <!-- en: Minimize --> するかを尋ねられます。最小化を選ぶと Tasty はシステムトレイ（メニューバー）に入り、トレイアイコンのメニューにある **ウィンドウを表示** <!-- en: Show Window --> で戻れます。毎回尋ねられないようにするには、**設定** > **一般** > **閉じるときの動作** <!-- en: Close behavior --> を変更してください。

Linux で `GDK_BACKEND` が X11 の使用を妨げる場合や GTK の初期化に失敗する場合は、トレイアイコンを使えません。[Linux のドキュメント表示・トレイのトラブルシューティング](../help/troubleshooting.md#linux-gdk-backend)を参照してください。

終了を確定すると、すべてのウィンドウのウェブページとマークダウン文書が隠され、終了待ちがある場合は進行画面が表示されます。終了の確認をキャンセルするか、バックグラウンドに最小化してから戻ると、文書を引き続き使えます。

再度起動するときに、配置とターミナル履歴を [復元](../using/workspaces.md#再起動後の復元) できます。実行中だったプログラムの復元とは異なり、設定と、プログラムごとのセッション再開への対応によって変わります。
