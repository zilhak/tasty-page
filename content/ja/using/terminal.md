# ターミナルを使う

コマンドを実行しながら、必要な出力のコピーや検索、ファイルパスを開く操作ができます。マウスを使わずに選択するコピーモードや、タスク完了の通知も利用できます。

以下のショートカットは、標準の **Tasty** プリセットを基準にしています。macOS では `Alt` を `Cmd` と読み替えてください。

## シェル

**設定** > **ターミナル** <!-- en: Terminal --> で設定します。

- **シェル** <!-- en: Shell --> — 実行するシェルです。Windows では Git for Windows の bash を探し、見つからなければパスを直接指定するよう案内します。
- **起動コマンド** <!-- en: Startup command --> — 新しいターミナルごとに、最初に入力する 1 行です。
- **作業ディレクトリを継承** <!-- en: Inherit working directory --> — 新しいターミナルを現在のターミナルのディレクトリで開始します（標準でオン）。
- **実行中のプロセスを閉じる際に確認** <!-- en: Confirm close running process --> — プログラムが動作しているターミナルを閉じる際に確認します。

bash（4.4 以上）と zsh は、追加設定なしでシェル統合が有効になります。タブ名が現在のディレクトリに追従し、ステータスバーに git ブランチが表示され、コマンド終了時にフックを実行できます（[フック・通知](../agents/hooks-notifications.md)）。fish などの他のシェルは手動で設定する必要があり、その場合は **シェル統合が検出されませんでした** <!-- en: Shell integration not detected --> バナーが表示されることがあります。リモートの Tasty にアタッチして表示しているターミナルでは、このバナーは表示されません。このバナーは 10 秒後に自動で閉じますが、マウスを重ねている間は閉じずに待機します。

プログラムが終了してシェルが終了すると、そのサーフェスは自動で閉じます。

## 矢印キーと修飾キー

ターミナル内のプログラムは、`Shift`・`Ctrl`・`Alt` と一緒に押した矢印キーを、通常の矢印キーと区別して受け取ります。**この組み合わせで使う macOS のキーは、`Cmd` ではなく実際の `Option` です。** たとえば、プログラムが `⌥ + ↑` と案内した場合は `Option+↑` を押してください。動作はターミナル内のプログラムが決めます。

矢印キーの組み合わせは、**Option を Meta として使用** の設定がオンでもオフでも送信されます。この設定は、macOS の Option+文字を特殊文字として入力するか、Meta キーとして送信するかだけを決めます。Tasty のショートカットとして登録された組み合わせや、コピーモード・入力を受け取るオーバーレイが処理するキーは、プログラムには送信されません。

## アプリ別の Shift+Enter 設定

**設定 → ターミナル → 入力** で実行ファイル名（例: `claude`）を追加し、**Shift+Enterで改行文字を送信** をオンまたはオフにできます。オンにすると改行文字（LF）を送信し、オフにするかルールを削除するとプラットフォーム標準のキー送信方式を使います。変更後、設定を保存すると適用されます。

Claude Code プラグインは、インストール後に初めて有効になる際、`claude` の改行ルールを自動で追加します。すでにインストールされている場合も、更新後に初めて有効になる際に登録されます。既存の設定値と、その後に変更・削除したルールは維持されます。

実行ファイル名は、大文字と小文字の違いと `.exe` を除いて完全に一致する必要があります。アプリの切り替え検出には最大 1 秒かかることがあります。`node` などのランチャーだけが検出される場合は、その実行ファイル名でルールを追加してください。この設定は、貼り付けや通常の Enter には適用されません。

Windows 用 Codex CLI は、標準のキー送信方式では `Shift+Enter` または `Ctrl+J` で改行し、`Enter` で送信します。

## コピー・貼り付け

| 操作 | ショートカット |
|---------|--------|
| コピー | `Ctrl+C` · `Alt+C` · `Ctrl+Shift+C` |
| 貼り付け | `Ctrl+V` · `Alt+V` · `Ctrl+Shift+V` |
| コピーモードに入る | `Ctrl+Shift+Space` |

- `Ctrl+C` は選択範囲があればコピーし、なければ通常どおりプログラムを中断します。
- 貼り付け直後の 0.5 秒以内の `Ctrl+C` は無視されます — `Ctrl+V` の隣のキーを誤って押して入力を失うことを防ぎます。無視された場合はトーストで知らせます。
- クリップボードにテキストがなく画像がある場合は、PNG ファイルとして保存してから、そのパスを貼り付けます。エージェントにスクリーンショットを渡す際に使います。保存は画面を止めずにバックグラウンドで行い、保存が終わると、貼り付け操作をしたターミナルにパスが入力されます。その間に入力した文字は、パスより先に入力されることがあります。その間にターミナルを閉じた場合は、パスを入力せずにファイルを削除します。
- ウィンドウの幅によって折り返された行は、コピー時に 1 行にまとめられます。
- 右クリックメニューからコピーすると、「Copied」通知の右側にコピーのショートカットも表示されます。エクスプローラーの右クリックメニューからパスをコピーした場合も、パスコピーのショートカットが表示されます。ショートカットでコピーした場合や、ショートカットを空にしている場合は表示されません。

### スクリーンショットをクリップボードへ

`Ctrl+Alt+S` を押して画面の範囲を選ぶと、PNG ファイルを `~/.tasty/screenshots/` に保存し、そのパスと画像の両方をクリップボードに入れます。ターミナルに貼り付けるとパスが、画像エディターのように画像を受け取るアプリに貼り付けると画像が入力されます。リモートミラーのワークスペースで押した場合、ファイルはリモートコンピューターに保存され、リモートのクリップボードに入ります。

- **macOS**: `screencapture` で範囲を選びます。画面収録の権限が必要です。
- **Linux**: Wayland では `grim`・`slurp` を使い、なければ `gnome-screenshot` を使います。X11 では `gnome-screenshot` → `scrot` → ImageMagick の `import` の順に、インストール済みのツールを使います。あるツールが失敗すると、次のツールに進みます。
- 画像をクリップボードに入れられない場合（画像を読み取れない場合など）は、パスだけを入れます。
- Esc で範囲選択をキャンセルすると、別のツールを開き直さず、クリップボードもそのままにします。ツールがファイルを残さずに終了した場合も同様です。
- 結果は、ショートカットを押したウィンドウに通知として表示されます。画像とパスの両方を入れた場合は成功、パスだけを入れた場合は警告、ツールがない、失敗した、保存・コピーできなかった場合はその理由を知らせます。Esc でキャンセルした場合は通知せず、ツールがファイルを残さずに終了した場合（一部のツールはキャンセル時もこのように終了します）は「スクリーンショットを撮影しませんでした」とだけ知らせます。範囲選択中に別のウィンドウへ移動しても、通知は最初のウィンドウに表示され、そのウィンドウを閉じていた場合は表示されません。

### 選択

ドラッグ（文字）・ダブルクリック（単語）・トリプルクリック（行）で選択します。選択はスクロールバックまで続きます。選択後に右クリックすると、**コピー** <!-- en: Copy -->・**改行なしでコピー** <!-- en: Copy Without Line Breaks -->・**ターミナルIDをコピー** <!-- en: Copy Terminal ID --> メニューが表示されます。選択した文字列が実在するファイル・フォルダーのパスであれば、**ファイルを開く** <!-- en: Open File --> / **フォルダを開く** <!-- en: Open Folder --> も表示されます。

シェルでコマンドを入力しているときに入力行を 1 回クリックすると、カーソルがその位置に移動します。シェル以外のプログラム、スクロールバックを表示している状態、マウスをキャプチャするプログラムでは移動しません。この動作をオフにするには、`config.toml` の `[general]` に `click_to_move_cursor = false` を追加してください（[設定](../customize/settings.md)）。

### コピーモード（vi）

マウスを使わずに画面とスクロールバックを移動してコピーします。ターミナルをクリックしてから `Ctrl+Shift+Space` を押して入ってください。macOS でも `Cmd` ではなく `Control` キーです。ショートカットを変更した場合は、変更したキーを押してください。

入ると、ターミナルの右下に移動・選択・コピー・終了のキーを案内する通知が表示され、現在の画面の先頭行の最初のマスにコピー用のカーソルが現れます。コピーモードで押したキーは、シェルやプログラムには送信されません。

入れない場合は、その理由を通知で知らせます。

- vim・less のようにターミナルの **代替画面** を使うプログラムが起動している間は入れません。ウィンドウの最大化や OS の全画面への切り替えとは関係ありません。プログラムを終了してから、もう一度試してください。
- エクスプローラーのように、ターミナル以外のサーフェスでは入れません。Markdown・HTML サーフェスがキー入力を受け取っているときも入れませんが、この場合は理由の通知がそのサーフェスの画面に隠れて見えないことがあります。
- すでにコピーモードの場合は、入り直さずにそのことを知らせます。

モーダルやポップアップがキーボード入力を受け取っている場合は、ショートカットがそちらに送られるため、コピーモードも通知も表示されません。ターミナルをクリックしてから、もう一度押してください。

たとえば、シェルで `printf '\033[2J\033[HABCDE\n'` を実行すると、画面の一番上に `ABCDE` が残ります。コピーモードに入り、`A` の上にカーソルがあることを確認してから、`Ctrl`・`Shift` を離して `v` `l` `l` `y` を順に押すと、`ABC` がクリップボードにコピーされ、コピーモードが終了します。

| キー | 動作 |
|----|------|
| `h` `j` `k` `l` | 移動します。前に数字を付けると繰り返します |
| `w` `b` `e` / `W` `B` `E` | 単語単位で移動します |
| `0` `^` `$` | 行頭 / 最初の文字 / 行末 |
| `gg` `G` / `H` `M` `L` | 一番上 / 一番下 / 画面の上・中央・下 |
| `v` / `V` | 文字 / 行の選択を開始します |
| `y` | コピーに成功すると終了します。失敗すると選択を維持します。選択せずに押すと、コピーせずに終了します |
| `/` `?` `n` `N` | 下・上に検索、次・前の結果 |
| `"+` `"*` | 次のコピー先のクリップボードを指定します |
| `q<文字>` … `q` / `@<文字>` | マクロの記録 / 再生 |
| `Esc` | 選択を解除します。選択がなければ終了します。選択中の場合は、最初の `Esc` で選択を解除し、2 回目の `Esc` で終了します |

クリップボードへの書き込みに成功したときだけ、コピー通知が表示されます。アクセスできない場合や転送に失敗した場合は、案内を表示して選択を維持します。選択範囲があるときに Ctrl+C でのコピーに失敗しても、プログラムは中断しません。貼り付けに失敗した場合は入力を送信せず、クリップボードが空の場合は何もしません。

### プログラムによるクリップボードへのアクセス（OSC 52）

ターミナル内のプログラム（tmux、リモートの vim など）は、クリップボードへの **書き込み** を要求できます。書き込みに成功してからコピー通知を表示し、アクセスできない場合や失敗した場合も知らせます。**読み取る** には、**設定** > **ターミナル** > **クリップボードの読み取りを許可（OSC 52）** <!-- en: Allow clipboard read (OSC 52) --> をオンにする必要があります。標準ではオフです。オンにすると SSH の先のプログラムもクリップボードの内容を取得できるので、注意してください。

### スクリプトからクリップボードに書き込む

スクリプトやエージェントから、クリップボードにテキストを直接入れられます。

```sh
tasty clipboard set-text "コピーしておく内容"
```

## 検索

`Ctrl+F` または `Alt+F`、またはタブストリップの検索アイコンを使います。サーフェスの上部中央に検索バーが表示されます。

通常のターミナルでは、スクロールバックと画面全体を検索します。vim・less のように代替画面を使うプログラム内では、現在の画面だけを検索します。それ以前のシェルの履歴は、プログラムを終了してから検索できます。

- `Enter` / `Shift+Enter` / `↑` `↓` — 次 / 前の結果です。結果数が `3/42` と表示され、画面が追従します。
- 結果は薄い黄色、現在の結果は濃い黄色で塗られます。現在の結果内の文字は、プログラムが指定した色に関係なくテーマの強調文字色で描画され、どのテーマでも読めるようになります。他の結果は元の文字色を維持します。
- 右側のトグル — **大文字と小文字を区別** <!-- en: Match case -->・**正規表現** <!-- en: Regular expression -->・**単語単位で一致** <!-- en: Match whole word -->。
- 検索バーにカーソルがあるときの `Esc` または `×` — 閉じます。検索バーが表示されていても、ターミナルにカーソルがあればキー入力はそのままターミナルに送られます。`Ctrl+F` をもう一度押すと、検索バーとターミナルの間を移動します。
- 検索語の入力欄は、フォーカスがなくても背景と枠線で区別されます。無効な正規表現を入力すると欄の枠線が赤く表示され、カーソルをターミナルに移してもエラー表示が残ります。
- 検索バーは、現在カーソルがあるサーフェスに表示されます。別のタブや隣の分割サーフェスで検索バーが開いている場合は、その検索を消去して現在のサーフェスに移動します。

## リンクとパスを開く

`Ctrl` を押しながら URL やパスにマウスを重ねると青い下線が現れ、クリックするとブラウザーまたは関連付けられたプログラムで開きます。ブラウザーや関連付けられたプログラムを起動できない場合は、そのターミナルの右下に、開けなかったことを知らせる通知が表示されます。パスは `src/main.rs` のような相対パスでも使えますが、現在のディレクトリを基準に実在するものだけがリンクになります。

下線が表示されたリンクを右クリックすると、リンク専用のメニューが表示されます。

- **選択** <!-- en: Select --> — リンクのテキスト全体を選択します。
- **コピー** <!-- en: Copy --> — 画面に表示されているリンクのテキストをコピーします。キーバインド設定で **リンクをコピー** にキーを割り当てておくと、「Copied」通知の右側にそのキーが表示され、リンク上でそのキーを押すとメニューを使わずにコピーできます。標準のキーはありません。
- **プログラムから開く** <!-- en: Open With… --> — すぐに開かずに、どのプログラムで開くかを選ぶ一覧を表示します。`http(s)://` のアドレスでも選べるため、たとえば HTML ビューアを選ぶと、ブラウザーの代わりに Tasty 内のタブで開きます。リモートでアタッチしたターミナルのパスはこのコンピューターでは開けないため、空の一覧だけが表示されます。

マウスを使うプログラム（vim・tmux など）が動作していても、リンク上の右クリックはそのプログラムに送られず、このメニューが表示されます。リンク以外の場所での右クリックは従来どおりです。

**設定** > **ターミナル** > **リンククリックの修飾キー** <!-- en: Link click modifier --> で、`Ctrl`・`Alt`・**左クリックで開く：オフ** <!-- en: Disable left-click opening --> から選んでください。**左クリックで開く：オフ** を選ぶと、左クリックではリンクを開きません。修飾キーなしでリンクにマウスを重ねて表示でき、リンク上の右クリックメニューも引き続き使えます。ポップアップやバナーの上では、リンクの表示がブロックされることがあります。

ファイルの開き方（Markdown・画像・エクスプローラー）は、[ファイルの管理と表示](files.md)を参照してください。ファイルをターミナル上にドラッグしてドロップすると（**ドロップして開く** <!-- en: Drop to open -->）、同じルールで開きます。

## スクロール

- マウスホイール、または `PageUp` / `PageDown`（1 画面ずつ）でスクロールバックを表示します。文字を入力すると一番下に戻ります。
- vim・less・htop のように画面全体を使うプログラム内では、ホイールと `PageUp` / `PageDown` がプログラムに送られます。
- 保持する行数は **設定** > **ターミナル** > **スクロールバックの行数** <!-- en: Scrollback lines --> で設定します（標準 10,000、最大 100,000）。`clear` はスクロールバックも消去します。
- 再起動後もスクロールバックは引き継がれます — [ワークスペース](workspaces.md#再起動後の復元)。

文字サイズは `Ctrl+=` / `Ctrl+-` で拡大・縮小し、`Ctrl+0` で元に戻します。フォーカスされているサーフェスに適用され、ターミナル・エクスプローラー・Markdown が対象です。

## マウスをキャプチャするプログラム

vim（`:set mouse=a`）・htop・Claude Code のようにマウスを直接使うプログラムが起動すると、クリックとドラッグはそのプログラムに送られます。最初のクリック時にバナーが表示されます。

> **マウス入力をキャプチャ中** <!-- en: Mouse input captured --> — このアプリがマウスをキャプチャしています。テキスト選択には Shift+ドラッグ、tasty メニューには Shift+右クリックを使ってください。

- `Shift+ドラッグ` — テキストを選択します。`Shift+ダブルクリック` は単語を選択します。
- `Shift+右クリック` — Tasty のコピーメニューです。
- バナーはプログラムが終了すると自動で閉じます。`×` ですぐに閉じることもできます。
- バナーにマウスを重ねると現れる **その他のオプション** <!-- en: More options --> で、**{プログラム}では今後表示しない** または **{プログラム}のクリックを Tasty で処理** を選んでください。Tasty がクリックを処理すると、そのプログラム上ではクリックが通常どおり選択として動作し、ホイールだけがプログラムに送られます。リモートの Tasty にアタッチして表示しているターミナルのように、実行中のプログラムを確認できない場合は、両方の項目が薄く表示され、選択できません。メニュー上部の案内がその理由を知らせます。

同じ項目は **設定** > **ターミナル** > **マウスキャプチャ** <!-- en: Mouse Capture --> にあります — **マウスキャプチャの案内を表示** <!-- en: Show mouse-capture hint --> トグル、**クリックを Tasty で処理するプログラム** <!-- en: Let Tasty handle clicks in these programs --> の一覧、**キャプチャ通知を表示しないプログラム** <!-- en: Don't show the capture notice for these programs --> の一覧です。名前は部分一致で、`ht*` のようなワイルドカードを使えます。

## 実行中・要確認の表示

- タブの **緑の点**、サイドバーカードの点 — シェル以外のプログラムが出力していることを示します。入力待ちで停止している場合は消えます。ターミナルのタイトルだけを変更する出力は、出力として扱いません。
- サーフェスの **黄色い枠線** — プログラムが応答を待っています（エージェントが質問した場合）。**青い枠線** — コマンドが終了したか、通知が届いたことを示します。そのサーフェスをクリックすると消えます。タブ名とサイドバーのバッジも同じ色を使います。

## 通知

ターミナルベル（`\a`）と、プログラムが送る通知シーケンス（OSC 9・99・777）をまとめて表示します。

- `Ctrl+Shift+I` — **通知** <!-- en: Notifications --> パネルです。新しい順の一覧と **移動** <!-- en: Jump --> ボタン、**すべて既読** <!-- en: Mark all read --> があります。開くとすべて既読になります。タイトルバーの全画面ボタンで大きく表示できます（[全画面](panes-tabs-splits.md#全画面)）。
- OS の通知センターには送信しません。ウィンドウが背面にある場合も、このパネルとサーフェスの枠線、サイドバーのバッジで通知を確認します。
- **設定** > **一般** > **通知** <!-- en: Notifications --> — **通知を有効化** <!-- en: Notifications enabled -->・**サウンド** <!-- en: Sound -->・**通知の統合間隔（ms）** <!-- en: Coalesce interval (ms) -->（同じ場所から連続して届いた通知を 1 つにまとめる間隔、標準 500）。
- ベルだけをオフにするには、**設定** > **ターミナル** > **ベル通知を表示** <!-- en: Show bell notification --> をオフにしてください。

スクリプトから直接通知を表示するには、`tasty notify "ビルド完了" --title build` を使ってください。

## プラットフォーム別の補足

- **macOS** — **設定** > **ターミナル** > **Option を Meta として使用** <!-- en: Use Option as Meta --> をオンにすると、`Option+F` のような組み合わせが特殊文字の代わりに readline・Emacs の Meta キーとして入力されます（標準でオフ）。
- **Windows** — スリープから復帰した後、ターミナルが応答しなくなることがあります。Tasty が復帰を試み、それでも停止しているように見える場合は通知で知らせます。その場合は、そのターミナルを新しく開いてください。
- 画面全体が点滅するプログラム（readline の visible bell など）が気になる場合は、**設定** > **ターミナル** > **画面反転フラッシュ（DECSCNM）** <!-- en: Reverse-screen flash (DECSCNM) --> をオフにしてください。

## さらに詳しく

- 色とフォントは、[テーマ](../customize/themes.md)と **設定** > **外観** <!-- en: Appearance --> で設定します。フォントは D2Coding が内蔵されているため、別途インストールする必要はありません。
- Sixel・Kitty 画像プロトコルには対応していません。画像は[画像サーフェス](files.md#画像)で表示します。
- スクリプトやエージェントがこのターミナルにコマンドを送り、出力を読み取る方法は、[tasty CLI](../agents/cli.md)を参照してください。ステータスバーの数字が、そのターミナルの ID です。
