# 원격 연결·플러그인·도움말

가이드의 한국어·영어 페이지를 함께 둔다. 각 페이지의 역할과 범위는 아래와 같다.

## 원격 작업 이어가기 (attach)

- 사이트 소스: [한국어](../../content/remote/attach.md) · [영어](../../content/en/remote/attach.md)
- 역할: 원격 Tasty 워크스페이스 연결.
- 보여 줄 항목: 원격 실행·SSH 조건, 프로필, GUI/CLI, 미러의 범위, 점유·연결 끊기·닫기, 실패 안내.
- 넣지 않을 항목: 일반 SSH 셸 생성과 동일시, 동시 공동 편집·충돌 병합 보장.
- 구성: 원격 실행·SSH·점유 조건을 먼저 둔다. 터미널 attach, 실행 중인 윈도우에 mirror 연결, 자동 연결을 구분한다. 기존·신규 워크스페이스의 JSON 결과와 대기, mirror ID·권한, 무응답 시간, 파일·클립보드 전송, 재연결, 원격 닫기와 GUI 연결 끊기 및 CLI 제약을 보여 준다.

## 플러그인

- 사이트 소스: [한국어](../../content/plugins/index.md) · [영어](../../content/en/plugins/index.md)
- 역할: 제공 기능 선택과 설치·권한 관리.
- 보여 줄 항목: 현재 번들 목록, 활성화·비활성화·설치·업데이트, 권한 표시와 한계. Claude Code의 자식 출력 없음 알림 설정 위치·라벨·키·기본값·허용 범위, 상세 동작 가이드로 연결. `com.tasty.` 예약 id와 공식 목록의 관계, 서명 확인 전 거부 및 미검증 설치 선택의 한계, 추가 화면의 거부 표시를 다룬다.
- 넣지 않을 항목: 실행 중 모든 악성 동작 차단·인증 완료 보장, 탐색기를 번들 플러그인으로 소개.
- 구성: 번들 목록, 활성화·설치·업데이트, 서명·신뢰 선택, 호스트 요청 권한의 범위와 프로세스 격리의 차이를 보여 준다.

## 문제 해결

- 사이트 소스: [한국어](../../content/help/troubleshooting.md) · [영어](../../content/en/help/troubleshooting.md)
- 역할: 증상에서 조치·신고로 연결.
- 보여 줄 항목: 증상별 분기, 안전한 현재 저장 위치, 권한·연결·복원·플러그인, 신고 정보. CLI 응답 지연 시 셸 timeout을 통한 동일 요청 반복의 위험, 연결 종료와 요청 취소의 차이, 단일 요청 명령의 응답 대기 상한과 실행 시작 전후 만료의 차이를 다루고 재시도 판단은 진단 안내로 연결한다.
- 넣지 않을 항목: 첫 화면부터 파일 목록 암기, 자료 삭제로 해결을 기본 권장, 낡은 legacy 직접 수정.
- 구성: 설치·입력·복원·알림·플러그인·신고 순서로 증상을 먼저 보여 주고 로그·설정 위치는 뒤에 둔다. 닫기 때 기록 생략과 실행 중 저장 중단의 적용 범위 및 안전한 조치를 구별한다.

## CLI 응답 지연과 연결 진단

- 사이트 소스: [한국어](../../content/help/cli-diagnostics.md) · [영어](../../content/en/help/cli-diagnostics.md)
- 역할: CLI 전문 진단 참조.
- 보여 줄 항목: 현재 오류 코드·대기 상한·지원 기능 조회·pressure 필드 참조.
- 넣지 않을 항목: 대기 시간 연장만을 만능 해결로 제시, 진단 필드를 랜딩에 열거.
- 구성: 응답 대기와 작업 대기를 구분하고 오류별 조치, 지원 기능 조회와 연결·요청 큐·저장소 상태를 보여 준다.
