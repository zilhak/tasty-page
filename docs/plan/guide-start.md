# 가이드 홈과 시작하기

가이드의 한국어·영어 페이지를 함께 둔다. 각 페이지의 역할과 범위는 아래와 같다.

## Tasty 가이드

- 사이트 소스: [한국어](../../content/index.md) · [영어](../../content/en/index.md)
- 역할: 전체 가이드의 길찾기.
- 보여 줄 항목: 제품 한 문단, 처음 시작, 목적별 링크, 어려울 때 갈 곳.
- 넣지 않을 항목: 모든 페이지의 긴 기능 열거, 내부 구조, 에이전트 설치 전제.
- 구성: 설치에서 첫 화면과 배치 실습으로 이어지는 진입점과 프로젝트·출력·파일·설정·자동화·에이전트·원격·문제 해결 목적별 링크를 둔다.

## 설치

- 사이트 소스: [한국어](../../content/getting-started/install.md) · [영어](../../content/en/getting-started/install.md)
- 역할: 설치 파일 선택부터 첫 실행까지.
- 보여 줄 항목: OS·아키텍처, 지원 조건, 파일 종류, 첫 실행, 업데이트·제거, headless의 별도 목적.
- 넣지 않을 항목: 패키지 매니저 저장소 제공 약속, Intel Mac 지원 약속, 기본 사용자에게 빌드 지시.
- 구성: 설치 파일 표, GPU 요구사항, OS별 첫 실행, Windows ARM 지원과 검증 범위, headless의 용도를 보여 준다.

## 첫 화면 둘러보기

- 사이트 소스: [한국어](../../content/getting-started/first-look.md) · [영어](../../content/en/getting-started/first-look.md)
- 역할: 화면의 이름과 첫 조작 연결.
- 보여 줄 항목: 화면 구성, 두 단계 분할, 튜토리얼 진입, 짧은 첫 조작, 다음 실습 링크.
- 넣지 않을 항목: 상태바 축소 우선순위·모든 단축키를 초반 필수 암기로 제시.
- 구성: 튜토리얼, 네 가지 화면 구성 단위와 두 단계 분할, 최소 조작을 먼저 보여 준다. 상태바 세부 정보는 접힌 참조로, 전체 단축키와 복원 상세는 해당 가이드로 연결한다.
