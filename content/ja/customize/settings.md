# 設定

Tasty のシェル、フォント、言語などは、設定ウィンドウで変更するか、`~/.tasty/config.toml` を直接編集して設定できます。キーバインドとテーマは、それぞれのガイドで詳しく説明します。

## 設定ウィンドウを開く

サイドバーの一番下にある **設定** <!-- en: Settings --> ボタンを押すか、`Ctrl+,` を押してください。
同じショートカットをもう一度押すと、設定ウィンドウが閉じます。 <!-- en: Press the same shortcut again to close the settings window. -->

<!-- tasty-diagram: settings-window -->
```
┌─────────────────────────────────────────────────────────────┐
│ [一般] [ターミナル] [外観] [キーバインド] [ハンドラ] [その他] [プラグイン]  │  上部のタブ
├──────────────┬──────────────────────────────────────────────┤
│ セクションを絞り込み…   │                                              │
│ ▸ 一般       │   選択したセクションの設定項目                    │
│   通知       │                                              │
│   アクセシビリティ     │                                              │
├──────────────┴──────────────────────────────────────────────┤
│                                        [ キャンセル ]  [ 保存 ]   │
└─────────────────────────────────────────────────────────────┘
```

- 上部のタブは 7 個です: **一般** <!-- en: General --> · **ターミナル** <!-- en: Terminal --> · **外観** <!-- en: Appearance --> · **キーバインド** <!-- en: Keybindings --> · **ハンドラ** <!-- en: Handler --> · **その他** <!-- en: Misc --> · **プラグイン** <!-- en: Plugins -->。
- 左側の一覧は、そのタブのセクションです。上の **セクションを絞り込み…** <!-- en: Filter sections… --> に文字を入力すると、一覧が絞り込まれます。タブを切り替えると、検索語は消去されます。
- **保存** <!-- en: Save --> を押すと、変更した設定を画面に適用し、ファイルへの保存を開始します。ファイルへの書き込み中も作業を続けられます。**キャンセル** <!-- en: Cancel --> すると、編集した内容は破棄されます。ヘッダーに閉じるボタンはありません。
- 設定ウィンドウを開いている間にエージェントがコマンドで変更した設定（入力ルール、リモート転送、外部からの webhook の許可など）は、**保存** してもそのまま残ります。保存では、このウィンドウで変更した項目だけを上書きします。同じ項目を両方で変更した場合は、このウィンドウの値が残ります。
- 保存した設定を適用できない場合は、エラー通知が表示され、設定はそのままです。画面には適用されたものの `config.toml` に書き込めなかった場合は、警告通知が表示されます。この場合、変更した設定は Tasty を再起動すると失われます。
- Tasty が読み込んだ後に別のプログラムが `config.toml` を変更すると、そのファイルを上書きせず、保存の失敗を通知します。外部で変更した設定を読み込むには、Tasty を再起動してください。
- 初回起動時に補正した設定と、確認したシェルのパスはまとめて保存します。保存結果を待つ間も、読み込み画面は更新され続けます。実行中に保存が待機状態でも、新しいウィンドウは今回の実行で適用された最新の設定を使用します。
- **言語** <!-- en: Language --> は、保存後に Tasty を再起動すると適用されます。パフォーマンス設定は、保存後に新しく開くターミナルから適用され、すでに開いているターミナルはすぐには変わりません。
- 数値欄は **入力** して変更します。ドラッグして値を増減する欄はありません。入力中は値を自動補正せず、欄から移動するか `Enter` を押すと、許容範囲内に調整されます — 範囲外の値を入力すると、欄の枠線が警告色に変わり、その下に許容範囲と実際に保存される値が 1 行で表示されます。
- 整数欄は値全体が見えるように値の長さに合わせて広がり、入力中も文字ごとに広がります。単位は欄の後ろに表示されます。設定ファイルに範囲を超える値が書かれている場合、そのまま表示する項目もあります。ただし、`[remote_attach] heartbeat_timeout_secs` が 10~600 の範囲外の場合は、読み込み時にデフォルト値の 30 に戻して設定ファイルに保存し直し、警告はログにだけ残します。
- 設定ウィンドウを非常に狭くして項目の欄が名前の横に収まらなくなると、その項目だけ欄が名前の下の行に移動します。再び広げると横に戻ります。

**再起動時にサーフェスの内容を復元** をオフにすると、次回起動時から以前のターミナルの内容は戻りません。すでに保存されている以前の内容も復元されませんが、タブの配置と作業ディレクトリはそのまま復元されます。閉じたタブを復元するとき（`Ctrl+Shift+T`）も、設定がオフの間はターミナルの内容を入れません。

**リモート転送** の保存フォルダ横の **参照…** は、設定内の Tasty フォルダーピッカを開きます。選択したサブフォルダーまたは現在のフォルダーを **フォルダーを選択** で確定すると、入力欄だけが変わります。設定の **保存** を押して適用してください。キャンセルするか Esc を押すと、フォルダーの値はそのままです。

**設定** <!-- en: Settings --> › **一般** <!-- en: General --> › **リモートアタッチ** で **切断までの待機時間** を変更します。範囲外の数値は、Enter を押すか別の欄に移動して入力を確定すると、10 秒未満なら 10 秒、600 秒超なら 600 秒に調整されます。保存した値は再起動せずに新しい接続から適用され、すでに開いている接続はそのままです。両側の Tasty はそれぞれ自分の値を使用するため、相手が先に切断することがあります。設定ファイルを読み込まない CLI アタッチは 30 秒を使用します。

フォント設定は、**一般** のデフォルト値がターミナル・Markdown・エクスプローラーに一括適用され、各セクションで **デフォルトを使用** <!-- en: Use default --> をオフにすると、その種類だけ別の値を使用します。**フォントDPIスケーリング** が **自動** の場合は、モニターが異なっても文字の物理的な大きさが同じになり、**固定** の場合はピクセルサイズが同じになるため、高解像度のモニターでは文字が小さくなります。

**フォント** の一覧を開くと、最上部の検索欄に名前の一部を入力して絞り込めます。一覧を閉じると、検索語は消去されます。**monospace (既定)** <!-- en: monospace (default) --> 項目は検索語に関係なく最上部にあるため、いつでもデフォルトのフォントに戻せます。

**フォント** や **カスタムフォントファイル** の値が使用できない場合は、その入力欄の下にエラーが表示されます。このコンピューターにインストールされていないフォント名もエラーとして表示されます。入力欄にフォーカスがあるときやフォントの一覧が開いているとき、入力した値を確認している間は、エラーメッセージと赤い表示が非表示になります。使用できない値も **保存** でき、値はそのまま保存され、画面は別のフォントで表示されます。**保存** を押した直後に、使用できない値ごとにメインウィンドウに警告通知が 1 件ずつ表示され、通知本文にその値が表示されます。同じ値を再び保存しても通知は増えず、設定ウィンドウで入力している間は通知が表示されません。メインウィンドウが複数ある場合は、フォーカスされているメインウィンドウに表示され、表示時間は **一般** タブの **オーバーレイ** にある **トースト表示時間** の設定に従います。

### ハンドラ

ファイルを開く際に「どのようなファイルかを識別する」ルールと、「何で開くか」を決める表です。デフォルトでも Markdown・画像・HTML は自動で開くため、通常は変更する必要はありません。

- **ファイル拡張子マッピング** <!-- en: File Extension Mapping --> — 同じ拡張子を複数のディテクターが扱う場合の優先順位です。
- **ファイルディテクター** <!-- en: File Detectors --> — 拡張子・パスパターンでファイルの種類を識別するルールです。一覧はディテクターを試す順に表示されます。ユーザールールを追加でき、既存のディテクター id で追加すると、そのディテクターに自分のルールを追加します。削除では自分が追加した部分だけを消し、組み込み・プラグインのルールは残ります。変更は保存時に適用され、それまでは行ごとの元に戻す操作で取り消せます。
- **ファイルハンドラー** <!-- en: File Handlers --> — 識別した種類をどのサーフェスで開くか、または OS のデフォルトアプリに渡すかを決めます。一覧は実行順です。priority が低いものが先で、同じ場合はユーザー・プラグイン・組み込みの順です。
- **フックハンドラー** <!-- en: Hook Handlers --> — フック・webhook イベントを受け取ったときに実行するシェルコマンドと内部動作の一覧です。[フック・通知・webhook](../agents/hooks-notifications.md)。

この表は `config.toml` ではなく、`~/.tasty/file-handlers.toml` と `~/.tasty/hook-handlers.toml` に保存されます。

### その他

- **スクリプト** <!-- en: Scripts --> — ショートカットやイベントで実行する Lua スクリプトを登録します（[Lua スクリプト](scripts.md)）。ファイルパス（例: `~/.tasty/scripts/my-script.lua`）と表示名を入力し、ショートカットは **キーバインド** > **スクリプト実行** で割り当ててください。登録後にファイルが変更されると **変更あり** <!-- en: changed --> と表示され、次回実行時に確認を求められます。
- **タスクパイプライン** <!-- en: Task pipeline --> — タスクグラフの report に残す記録のサイズ上限です。**記録 1 件の上限** <!-- en: Note size limit --> を超える記録は切り詰められ、**試行 report 上限** <!-- en: Attempt report limit --> を超える記録は保存せず、件数だけを数えます。前の値は常に後の値より小さくなければなりません（[タスク report](../agents/tasks.md)）。
- **異常検出** <!-- en: Anomaly detection --> — メモリ増加・繰り返し呼び出し・呼び出しの急増について、通知の表示としきい値を変更します。正常なタスクでも検出されることがある候補のシグナルです。繰り返し呼び出しは、応答の遅延ではなく同じ呼び出しの繰り返し回数を数えます。通知をオフにしても検出と記録は続き、数値も編集できます。保存した値は次の判定から適用されます。範囲外の数値は Enter を押すか別の欄に移動すると補正され、キャンセルすると編集内容を破棄します。

## 言語を追加する（言語パック）

Tasty に組み込まれている言語は English · 한국어 · 日本語 の 3 言語です。それ以外の言語は **言語パック** を
自分で配置すると、言語一覧に一緒に表示されます。

### 言語パックを作成する

`~/.tasty/lang/` の下に **言語コード名のフォルダー** を作成し、その中に `pack.toml` を置いてください。
たとえばフランス語なら `~/.tasty/lang/fr/pack.toml` です。

```toml
[meta]
name = "Français"          # 言語一覧に表示する名前 (省略するとフォルダー名)

[font]                     # 必須 — 以下の 4 つから 1 つだけ
builtin = true             # Tasty のデフォルトフォントで十分な文字だけ
# file = "fonts/x.ttf"     # パックのフォルダー内に同梱したフォントファイル
# family = "Noto Sans"     # コンピューターにインストールされたフォント名
# candidates = ["fonts/x.ttf", "Noto Sans"]   # 上から順に試す

[button]                   # ここからは翻訳する文言
ok = "OK"
cancel = "Annuler"
```

- **`[font]` は省略できません。** 文言だけでフォントの指定がないと、画面上の文字が □ に
  文字化けすることがあるため、パックの作成者がどのフォントで表示するかを明示するようにしています。
- **宣言したフォントは UI 全体に適用されます。** `file` · `family` · `candidates` で指定した
  フォントがデフォルトフォントの後に追加され、設定・ポップアップはもちろん、プラグイン画面（クリップボードビューア・
  Markdown など）にも、その言語の文字が表示されます。`builtin = true` は「デフォルトフォントで十分なので
  追加しない」という意味です。
- **すべて翻訳する必要はありません。** 記載していない文言は英語で表示されます。値を空文字列
  （`""`）にすることも「未翻訳」と見なされ、英語で表示されます — 画面に空欄は
  生じません。
- 文言の名前（`[button] ok` など）は、Tasty に組み込まれている言語ファイルと同じ構成です。
  既存の言語ファイルをコピーして始めると早く作成できます。
- `{}` が含まれる文言は、実行時に値が入る箇所です。**個数をそのままにして
  ください** — 削除するとその値が消え、追加すると `{}` が画面にそのまま表示されます。

### ターミナルコマンドのヘルプも翻訳されます

`tasty --help` のようにターミナルで見るヘルプも、選んだ言語で表示されます。言語パックでは
`[cli.help]` の下の文言が該当します。

```toml
[cli.help._root]
about = "Émulateur de terminal accéléré par GPU"

[cli.help._root.new]
about = "Créer une ressource"
```

- ここでも **すべて翻訳する必要はありません。** 記載していないコマンドは英語の説明がそのまま表示され、
  翻訳したものと混在します。
- ヘルプの使用方法・コマンド・オプションの見出し、デフォルト値の案内、引数エラーも選んだ言語で表示されます。
  `tasty help help` とプラグインの `help help` も同じ言語を使用します。引数の説明が
  ないプラグインでも、デフォルト値の案内は表示されます。
  コマンド名・オプション・許容値はそのまま使用します。下位のパーサーが提供する詳細エラーと、サーバーの
  エラー原文は英語のままの場合があります。
- プラグインコマンドの説明と引数のヘルプも、下記のプラグイン翻訳ファイルで変更できます。
  たとえば韓国語の Codex ヘルプの見出しは、`~/.tasty/lang/plugins/com.tasty.codex/ko.toml` に
  `[codex.cli]` と `desc = "私の Codex コマンド"` を入れて変更します。翻訳キーのない以前の
  プラグインは、既存の説明を維持します。

### 選択

設定ウィンドウ › **一般** › **言語** の一覧にパックが一緒に表示されます。選んで **保存** した後、Tasty を
再起動すると適用されます。

### プラグインの文言を変更する

プラグインのインストールフォルダーを変更しなくても、文言を上書きできます。韓国語なら
`~/.tasty/lang/plugins/com.tasty.clipboard-viewer/ko.toml` に、次のように記述してください。

```toml
[clipboard_viewer.command]
open_viewer = "내 클립보드 열기"

[clipboard_viewer.popup]
title = "내 클립보드"
```

プラグインのツール項目と内部画面は、同じファイルを読み込みます。フォルダー名はプラグイン ID です。
別のプラグインを変更するには、そのプラグインの ID と翻訳項目名を使用してください。新しい言語パック
`fr` では `~/.tasty/lang/fr/plugins/com.tasty.clipboard-viewer.toml` に置きます。
先に `fr/pack.toml` を作成し、その言語を選択する必要があります。

インストール済みの英語 → インストール済みの選択言語 → ユーザーファイルの順に上書きします。空の値や欠けている項目は、
前の段階の文言を維持します。ファイルが不正な TOML であるか 2 MiB を超える場合は無視し、警告を
残します。修正後は Tasty を再起動してください。このファイルは、プラグインをアップグレードしても
保持されます。同じプラグイン項目を、本体の `ko.toml` や `pack.toml` にも重複して入れないでください。

`TASTY_HOME` を相対パスで指定して実行しても、プラグインは Tasty を実行したディレクトリを基準にユーザー翻訳を読み込みます。
標準のバンドルプラグインもこのホームから起動し、ユーザー翻訳にない文言はインストール済みの翻訳で表示されます。

### 組み込み言語の文言だけを変更したい場合

フォルダーではなく **ファイルを 1 つ** 置いてください — `~/.tasty/lang/ko.toml` などです。記載した文言だけデフォルトを
上書きし、`[font]` も不要です。この方式は English · 한국어 · 日本語 の 3 言語にだけ使用します。
新しい言語をこの方式で置いても、一覧には表示されません。

値を空文字列（`""`）にすると、言語パックと同じく「変更しない」と見なされます — 元から入って
いたその言語の文言がそのまま表示され、画面に空欄は生じません。

### うまく動作しない場合

- **一覧に表示されません** — フォルダー名が言語コードになっているか、その中のファイル名が正確に
  `pack.toml` になっているか、`[font]` があるかを確認してください。設定ウィンドウを閉じてから開き直してください
  （一覧はウィンドウを開くときに 1 回読み込みます）。`pack.toml` は **2 MiB を超えることはできません** — 組み込みの
  言語ファイルも 400 KiB 未満なので、通常の翻訳はこの制限にかかりません。
- **英語で表示され、警告が出ます** — 選んだ言語のパックが見つからなかったか、ファイルが不正であることを
  意味します。警告には、どのパスを探したかが表示されます。**設定はそのまま残るため**、パックを修正して
  再起動すると、その言語に戻ります。
- **文字が □ で表示され、フォントの警告が出ます** — パックと文言は読み込まれましたが、`[font]` が
  指すフォントが見つからないか、開けないことを意味します。文言はそのまま表示され、フォントだけが
  追加されません。`file` のパス（パックのフォルダー基準）または `family` の名前を確認し、再起動してください。
- 詳しい理由は `~/.tasty/debug.log` に 1 行で記録されます。

## 設定ファイル `~/.tasty/config.toml`

一般設定はこのファイルに保存されます。ハンドラの表やテーマファイルなどは、上で説明した別のパスを使用します。存在しないキーはデフォルト値として読み込まれるため、必要なものだけを記述できます。

`[remote_attach]` の `heartbeat_timeout_secs` は、リモートアタッチ接続で相手の応答なしに待つ時間です。単位は秒で、デフォルト値は 30、範囲は 10~600 です。ファイルの値が範囲外の場合は、デフォルト値の 30 に戻して設定ファイルに保存し直し、警告はログにだけ残します。設定ファイルを直接編集した内容は、次回 Tasty を起動するときに読み込みます。再起動せずに新しい接続に適用するには、設定ウィンドウで変更して保存してください。

設定ファイルに記載したフォントの値（`[appearance.default_font]` の `font_family` など）が使用できない場合は、Tasty を起動した後、メインウィンドウに値ごとに警告通知が 1 件ずつ表示されます。通知本文にはその値が表示され、画面は別のフォントで表示されます。通知が表示されるウィンドウと表示時間は、上記の外観の説明に従います。エージェントがコマンドで適用したフォントの値は、使用できなくても警告通知は表示されず、ログにだけ残ります。

```toml
[general]
language = "ko"                  # "en" | "ko" | "ja"
close_behavior = "ask"           # "ask" | "minimize" | "quit"
wheel_line_scroll = 50.0         # ホイール 1 目盛りでスクロールする距離(pt)、10~200
restore_layout = true
restore_surface_content = true
scrollback_lines = 10000
inherit_cwd = true
confirm_close_running = true
link_click_modifier = "ctrl"     # "ctrl" | "alt" | "none"
click_to_move_cursor = true      # シェルの入力行をクリックするとカーソルをその位置に移動
allow_clipboard_read = false
bell_notification = true
workspace_categories_enabled = false
explorer_refresh_file_details = false  # エクスプローラーが開いているフォルダー内のファイルのサイズ・更新日時の変更も自動反映
explorer_props_time_format = "minutes"  # "minutes" | "seconds" | "seconds_offset" — プロパティウィンドウの日時形式
mouse_capture_blacklist = ["htop"]
shell = ""                       # 空なら自動検出
startup_command = ""

[appearance]
theme = "mocha"                  # ~/.tasty/themes/<id>.toml
ui_scale = "medium"              # "small" | "medium" | "large" — サイドバーの幅もこの値に従う
ligatures = true
background_opacity = 1.0
active_tab_indicator = "underline"   # "underline" | "fill" | "dot"

[appearance.default_font]
font_family = ""
font_size = 14.0
line_height = 1.0
font_scale_mode = "auto"         # "auto" | "fixed"

[appearance.terminal_font]       # 空なら default_font に従う
font_size = 15.0

[notification]
enabled = true
sound = false
coalesce_ms = 500

[accessibility]
reduced_motion = false

[modifier_hint]
enabled = true

[overlay]
toast_duration_ms = 2000

[performance]
targeted_pty_polling = true
scrollback_disk_swap = false
scrollback_disk_lines = 10000     # ディスクに残す行数、-1 なら無制限

[remote_transfer]
dir = ""                         # 空なら ~/.tasty/transfers/
max_mb = 500

[remote_attach]
heartbeat_timeout_secs = 30      # 相手の応答なしに待ってから切断する時間(秒)、10~600、新しい接続から適用

[webhook]
allow_external = false           # true なら他のコンピューターからの webhook 呼び出しも受け付ける(次回起動時から)

[task_pipeline]
report_append_bytes = 1024       # 記録 1 件の上限、64~65536
report_block_bytes = 16384       # 試行 report 上限、128~131072、記録 1 件の上限より大きい必要がある

[anomaly_detection]
rss_surge_notify = true
rss_surge_samples = 5            # 3~20
rss_surge_min_mib = 256          # 0~65536 MiB
slow_loop_notify = false
slow_loop_window_secs = 300      # 30~3600
slow_loop_threshold = 20         # 2~10000
call_burst_notify = true
call_burst_window_secs = 60      # 1~600
call_burst_threshold = 1000      # 10~100000

[keybindings]
new_tab = ["alt+t"]              # その他は keybindings.md
```

異常検出のしきい値は、このファイルで変更します。通知をオフにしても、検出記録は残ります。SlowLoop は応答時間を測定せず、正常なポーリングでも検出されるため、デフォルトでは記録だけを残します。RSS 増加のシグナルは、最後のサンプルが最小サイズに達している必要があります。継続する RSS 増加傾向と SlowLoop の繰り返し呼び出しは 1 回だけ記録し、通知を再びオンにしても以前の記録をさかのぼって通知しません。実行中にしきい値を変更しても、観測状態を維持します。参照期間やサンプル数を減らすと、次の確認で履歴を切り詰め、増やしてもすでに破棄した履歴は戻りません。ファイルの値が範囲外の場合は、このセクション全体をデフォルト値に戻し、実行中の不正な変更は拒否します。

- `[terminal_input]` には、アプリごとの Shift+Enter の動作が保存されます。**ターミナル → 入力** で設定してください。たとえば `[[terminal_input.rules]]` に `app = "claude"`、`shift_enter_newline = true` を指定すると、Claude Code に改行文字を送信します。`initialized_defaults` はプラグインのデフォルト値を適用した記録なので、直接変更する必要はありません。
- `[appearance]` の下には、このほかにテーマの色全体（`theme_base`）と、色タブで上書きした値（`theme_overrides`）も保存されます。手動で変更するより、設定ウィンドウを使うほうが安全です。
- `[plugin_settings."com.tasty.html"]` のように、プラグイン設定ページの値は、プラグイン id をキーにしたセクションに入ります。
- Tasty は実行中にこのファイルを監視しません。手動で変更した値は、次回起動時に読み込みます。実行中に外部の変更を検出すると、保存を拒否してファイルを保持します。ファイルを直接編集するときは、Tasty を終了してから行ってください。

リモート転送の項目だけは、CLI でも読み書きできます。

```sh
tasty settings get-remote-transfer
tasty settings set-remote-transfer --dir ~/incoming --max-mb 1000
```

設定を変更するコマンド（`set-remote-transfer`、`set-input-rule`、`tasty webhook allow-external` など）は、設定を適用して `config.toml` に保存した後に結果を出力します。保存できなかった場合は、成功ではなくエラーで終了します。この場合、値は今回の実行にだけ適用されます。

## `~/.tasty` フォルダーにあるもの

`~/.tasty/config.toml` は設定ファイルです。配置の保存先とプラグインのデータは別に管理します。配置の復元の問題を解決するために、保存先のファイルを直接編集したり削除したりしないでください。

| パス | 内容 |
|------|------|
| `config.toml` | 上記の設定 |
| `themes/` | テーマファイル — [テーマ](themes.md) |
| `lang/` | 言語パックと言語の上書きファイル — [言語を追加する](#言語を追加する言語パック) |
| `plugins/` · `plugins-logs/` | インストール済みのプラグインとログ — [プラグイン](../plugins/index.md) |
| `file-handlers.toml` · `hook-handlers.toml` | ハンドラタブのユーザー項目 |
| `remote-profiles.toml` | リモート接続プロファイル — [リモート作業を続ける](../remote/attach.md) |
| `scripts/` | Lua スクリプトを置く慣例的な場所 — [Lua スクリプト](scripts.md) |
| `transfers/` | リモートから受信したファイルのデフォルト保存フォルダー |
| `tasty.port` · `debug.log` | 実行中のインスタンスのポート、警告以上のログ — [トラブルシューティング](../help/troubleshooting.md) |
